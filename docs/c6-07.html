RAID — 여러 디스크를 묶어 하나처럼 ★★★

디스크 하나의 용량에는 한계가 있고, 서버나 데이터센터는 수백 TB가 필요해요. 20TB 디스크 25개를 묶으면 500TB짜리 시스템이 돼요. 이렇게 여러 개의 작은 디스크를 연결해 하나의 큰 논리적 저장장치로 만드는 기술이 RAID(레이드)예요. 원래 뜻은 Redundant Array of Inexpensive Disks(값싼 디스크의 중복 배열)였고, 지금은 Independent(독립적인) Disks라고도 해요.

RAID가 주는 이점은 용량 확대뿐이 아니에요. 데이터를 나눠 저장하면 동시에(병렬로) 읽고 쓸 수 있어 속도가 빨라지고, 복사본이나 검산용 정보를 두면 디스크 하나가 고장 나도 복구할 수 있어요. 대신 디스크 개수가 늘어서 어딘가 고장 날 가능성은 올라가요. 개인 PC는 RAID를 쓰지 않고, 회사 서버를 관리하게 되면 대부분 RAID를 구성해요.

RAID에 쓰이는 핵심 기술은 세 가지예요.

기술뜻비유
스트라이핑
striping, 분산		데이터를 여러 디스크에 나눠서 저장 (라운드 로빈 방식으로 골고루)일을 여러 직원에게 나눠 맡기기
미러링
mirroring, 중복		같은 데이터를 두 디스크에 똑같이 복사거울에 비춘 사본
패리티
parity, 무결성		여러 비트의 합(XOR)을 따로 저장해 두었다가, 고장 나면 복원에 사용합계 검산표

교수님이 설명한 RAID 종류 중 시험에서 알아 둘 것을 표로 정리했어요.

종류기술특징
RAID-0스트라이핑디스크 여러 개를 이어 붙여 큰 하나처럼. 병렬 접근으로 속도가 빨라요. 복제나 패리티가 없어서(비중복) 디스크 하나가 고장 나면 데이터를 잃을 수 있어요
RAID-1미러링모든 데이터를 짝 디스크에 복사. 거의 완벽한 결함 허용(안전), 단점은 높은 가격(용량 이득 없음). 중요한 파일, 시스템 소프트웨어에 써요
RAID-2, 3, 4해밍코드, 패리티문제점(검사 디스크 많음, 쓰기마다 패리티 갱신, 패리티 디스크 병목)이 있어서 거의 안 써요
RAID-5스트라이핑 + 분산 패리티패리티를 디스크마다 돌아가며(라운드 로빈) 분산 저장해서 RAID-4의 병목을 해결. 현재 가장 널리 쓰이는 방식. 속도, 용량, 복구력의 절충
RAID-62종 패리티 (P, Q)디스크 2개가 고장 나도 복구 가능. 용량은 더 줄고 쓰기 성능은 RAID-5보다 못해요
RAID-10 / 01스트라이핑 + 미러링속도와 안정성을 함께. 전체 용량의 50%만 써서 비싸요. 디스크 하나 고장 시 RAID-10은 짝 하나만 복사하면 돼서 RAID-01보다 유리해요
패리티 비유 — 합계 검산

친구 4명이 숫자 카드를 한 장씩 갖고, 나는 "1이 홀수 개면 1, 짝수 개면 0"이라는 검산표를 적어 둬요. 한 명의 카드가 사라져도 나머지 카드와 검산표로 알아낼 수 있어요.

패리티 복구 손계산이에요. 네 디스크의 같은 자리 비트가 b0=1, b1=0, b2=1, b3=1이라고 해요. 패리티 p는 모두 더해서(XOR) 1의 개수가 홀수면 1, 짝수면 0이에요. 1이 3개(홀수)이므로 p = 1이에요.

  • b3 디스크가 고장 났을 때 : 남은 b0, b1, b2와 p로 구해요. 남은 데이터 비트에 1이 두 개(b0, b2)인데 p=1(홀수)이니 b3이 1이어야 홀수가 돼요. → b3 = 1 (원래 값과 같아요).
  • 식으로는 b3 = p ⊕ b0 ⊕ b1 ⊕ b2 = 1 ⊕ 1 ⊕ 0 ⊕ 1 = 1이에요.
  • 디스크 2개가 고장 났을 때 (예 b2, b3) : 남은 b0=1, b1=0, p=1로는 (b2, b3)가 (0,0)이든 (1,1)이든 모두 맞아서 알 수 없어요. 그래서 RAID-5는 2개 고장을 복구하지 못하고 RAID-6이 필요해요.

용량 계산도 알아 두세요. 4TB 디스크로 구성할 때 이래요.

구성쓸 수 있는 용량이유
RAID-0, 4TB × 4개16TB전부 데이터로 써요 (4 × 4)
RAID-1, 4TB × 2개4TB하나는 복사본이라 용량 이득 없음
RAID-5, 4TB × 5개16TB패리티 한 개 몫(4TB)을 빼요: (5 − 1) × 4. 교수님이 든 예예요
RAID-6, 4TB × 5개12TB패리티 두 개 몫을 빼요: (5 − 2) × 4

교수님이 정리한 선택 기준은 이래요. 용량이 최우선이면 RAID-0, 안전이 최우선이면 RAID-1, 절충(용량 + 성능 + 복구력)이면 RAID-5예요. 그리고 데이터센터에서는 RAID-0, 1, 5, 6을 많이 써요.

외우기 팁

RAID-0은 복구력 0(속도만), RAID-1은 1(복사본 하나, 안전), RAID-5는 패리티(5가 가장 인기), RAID-6은 패리티 2개(디스크 2개 고장까지)예요.

시험엔 이렇게 써요

RAID는 보조기억장치 여러 개를 연결하여 하나의 논리적 저장장치로 구성함으로써 용량과 성능을 개선하는 기술이다. 스트라이핑(분산), 미러링(중복), 패리티(무결성)를 이용한다. RAID-0은 분산 저장으로 속도를 높이고, RAID-1은 미러링으로 높은 신뢰성을 제공하며, RAID-5는 패리티를 디스크에 분산 저장하여 속도와 안정성을 절충하고 현재 널리 사용된다.

잠깐 확인 — 4TB 디스크 5개를 RAID-5로 묶으면 쓸 수 있는 용량은?

(5 − 1) × 4TB = 16TB예요. 패리티 한 개 몫을 제외해요.
