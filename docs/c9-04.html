CPU 5단계와 레지스터 (기출 Q6·Q7, 교수님이 꼭 복습하라고 한 곳)

교수님이 CPU 구성 요소와 명령 실행 5단계를 복습하라고 따로 말했고, 기출 7번이 이 그림에서 나왔어요. 가장 오래 투자할 소단원이에요.

① 빈칸 채우기 문장을 읽고 ____에 들어갈 말을 먼저 말하거나 써 본 뒤 눌러서 맞춰 보세요.

1) CPU의 필수 구성 요소 3가지는 계산을 하는 ____, 명령을 해독하고 제어신호를 내는 ____, CPU 안의 작고 빠른 메모리인 ____이다.

ALU(산술논리연산장치), 제어장치(CU), 레지스터 세트예요. 계산기, 지휘자, 손에 든 메모지에 비유해요.

2) 다음에 가져올 명령이 메모리 몇 번지에 있는지 적어 두는 레지스터는 ____이고, 지금 실행하려고 가져온 명령 한 줄을 담는 레지스터는 ____이다.

PC(프로그램 카운터), IR(명령 레지스터)이에요. PC는 책갈피, IR은 지금 읽는 문장이에요.

3) 메모리의 몇 번지를 읽고 쓸지 적어 두는 레지스터는 ____이고, 메모리에서 읽어 온 값이나 쓸 값을 잠깐 담는 레지스터는 ____이다.

MAR(메모리 주소 레지스터), MBR(메모리 버퍼 레지스터)이에요. MBR은 MDR이라고도 불러요.

4) ALU 입구의 X, Y에 계산할 두 값이 들어가고, 계산 결과는 ____(누산기)에 잠깐 담긴다.

AC예요. Accumulator의 약자이고 계산기 화면에 비유해요. 기출 Q7에서 AC에 12가 들어갔어요.

5) 명령 실행 5단계 중 PC가 가리키는 번지의 명령을 메모리에서 IR로 가져오는 첫 단계는 ____, ALU가 계산하는 단계는 ____, 결과를 레지스터에 적는 마지막 단계는 ____이다.

인출(fetch), 실행(execute), 기록(write back)이에요. 도서관에서 쪽지를 가져오고, 계산기를 두드리고, 공책에 적는 순서예요.

6) 제어장치(CU)가 IR의 명령을 풀어 제어신호를 정하는 단계는 ____이고, 메모리를 읽거나 쓰는 명령에서만 일하는 단계는 ____이다.

해독(decode), 데이터(data)예요. 데이터 단계에서는 MAR 번지와 MBR 사이에서 값을 읽거나 써요.

7) ADD 같은 레지스터 계산 명령은 ____ 단계가 No action이고, LOAD·STORE 같은 메모리 접근 명령은 ____ 단계가 No action이다.

데이터, 실행이에요. 계산 명령은 1-2-3-5단계, 메모리 접근 명령은 1-2-4-5단계로 움직여요.

8) 기계어 명령은 무슨 계산을 할지 나타내는 ____(동작 코드)와 계산의 대상을 나타내는 ____(피연산자)로 이루어진다.

opcode, operand예요. opcode는 문장의 동사, operand는 목적어예요. ADD R3 R1 R2에서 ADD가 opcode, R3·R1·R2가 operand예요.

9) 이 수업의 가상 CPU에서 opcode는 MOVE = ____, LOAD = ____, STORE = ____, ADD = ____, MUL = ____이다.

MOVE 1000, LOAD 1001, STORE 1010, ADD 1100, MUL 1101이에요. 기출 Q6.1은 그림에 이미 나온 줄에서 이 값을 사전처럼 베껴 오는 문제였어요.

10) 레지스터 번호는 4비트 이진수라서 R1은 0001, R3은 ____, R5는 ____이고, 16진수 주소 CC는 이진수로 ____이다.

R3 0011, R5 0101, CC 1100 1100이에요. 16진수 C가 12이고 이진수 1100이라서 CC는 1100 1100이고, 다음 번지 CD는 1100 1101이에요.

② 순서대로 써 보기 명령 한 줄이 실행되는 5단계를 순서대로 써 보세요.

  • 가) 기록
  • 나) 인출
  • 다) 실행
  • 라) 해독
  • 마) 데이터
순서대로 써 보기 — 답 열기

나 → 라 → 다 → 마 → 가 (인출 → 해독 → 실행 → 데이터 → 기록)

그림 문제는 어느 부품에 화살표가 있는지로 알아봐요. PC·MAR·IR이 보이면 인출, ALU·X·Y·AC가 보이면 실행이에요.

② 순서대로 써 보기 (하나 더) 인출 단계 안에서 일어나는 일을 순서대로 써 보세요.

  • 가) 메모리에서 읽은 명령이 MBR을 거쳐 IR에 들어간다
  • 나) PC 값이 MAR로 간다 (제어신호 Read)
  • 다) PC가 다음 명령의 번지로 바뀐다
순서대로 써 보기 — 답 열기

나 → 가 → 다

PC 값을 MAR로 보내 메모리의 그 번지를 읽고, 명령이 MBR을 거쳐 IR로 오면, PC를 다음 번지로 바꿔요.

③ 계산 메모리 04번지에 ADD R3 R1 R2가 있고, R1 = 5, R2 = 7이며, 명령 하나가 메모리 2칸을 차지해요. 5단계마다 무슨 일이 일어나는지 써 보세요. (기출 Q7)

단계 풀이 보기 (종이에 먼저 풀어 본 뒤 열기)

인출 단계 MAR ← 4, IR ← ADD R3 R1 R2, PC ← 6이에요. 04, 05번지를 읽었으니 다음 명령은 06번지예요.

해독 단계 X ← 5, Y ← 7이고 ALU 제어신호는 +예요.

실행 단계 ALU가 5 + 7을 계산해서 AC ← 12가 돼요.

데이터 단계는 메모리를 안 쓰는 명령이라 No action이에요.

기록 단계 AC의 12를 R3에 적어요. R3 ← 12예요.

정리하면 PC는 4에서 6으로, AC는 12, 마지막에 R3는 12가 돼요.

시험엔 이렇게 써요

CPU는 하나의 기계어 명령을 인출(fetch), 해독(decode), 실행(execute), 데이터(data), 기록(write back)의 5단계로 나누어 실행한다. 인출에서는 PC의 주소를 MAR에 넣고 메모리에서 읽은 명령을 MBR을 거쳐 IR에 가져오며 PC는 다음 명령의 주소로 바뀐다. 해독에서는 제어장치가 제어신호를 정하고, 실행에서는 ALU가 계산해 AC에 두며, 데이터는 메모리 접근 명령에서만 일하고, 기록에서는 결과를 레지스터에 적는다.

잠깐 확인 — LOAD R5 CC 명령에서 No action인 단계는 어느 단계인가요?

실행 단계예요. 계산이 없어서 3단계가 비고, 데이터 단계에서 Read로 MBR ← MEM[CC]를 하고, 기록 단계에서 R5 ← MBR이 돼요.
