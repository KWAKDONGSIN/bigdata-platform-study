먼저 큰 그림 한 줄

이 과목은 결국 이거예요. 프로그램은 SSD에 있다가, 실행하면 RAM으로 올라오고, CPU가 한 줄씩 가져가 계산해요.

시험지 여백에 먼저 쓰기

SSD(보관) → RAM(실행 중) → CPU(계산) → 결과는 RAM

외우는 요령 — 창고(SSD)에서 조리대(RAM)로 꺼내 놓고, 요리사(CPU)가 한 줄씩 요리해요.

꼭 알아야 할 10개

1. 폰노이만 구조

컴퓨터는 레시피(프로그램)를 기억장치에 넣어 두고, 요리사(CPU)가 한 줄씩 꺼내 실행해요. 실행 중인 것은 RAM, 다 쓰고 오래 두는 것은 보조기억장치(SSD, HDD)예요.

시험엔 이 한 문장

폰노이만 구조는 프로그램과 데이터를 기억장치에 저장하고 명령어를 하나씩 CPU로 가져와 실행하는 구조이며, 실행 중인 것은 RAM에, 영구 보관은 보조기억장치에 둔다.

확인 — 실행 중인 프로그램이 올라가는 곳은?

RAM(주기억장치).

2. 컴퓨터 부품 6개

CPU는 두뇌, RAM은 조리대, SSD는 창고, 메인보드는 부품이 꽂히는 바닥판이자 길, 그래픽카드(GPU)는 계산을 한꺼번에 하는 조수 부대, 파워는 교류를 직류로 바꿔 전기를 주는 설비예요.

시험엔 이 한 문장

메인보드는 부품 간 데이터 통로, CPU는 대부분의 계산, SSD/HDD는 비휘발성 영구 저장, RAM은 휘발성으로 실행 중 데이터 보관, GPU는 행렬 연산 병렬 처리, 전원공급장치는 교류를 직류로 변환한다.

확인 — "교류를 직류로 바꿔 전원을 공급"하는 부품은?

전원공급장치(파워).

3. 이진수 변환 (손계산)

8칸의 자릿값은 128 64 32 16 8 4 2 1이에요. 큰 것부터 "들어가면 1, 안 들어가면 0"으로 채워요. 137 = 128 + 8 + 1이라 1000 1001이에요.

시험엔 이 한 문장

십진수는 128, 64, 32, 16, 8, 4, 2, 1의 자릿값으로 나누어 해당 자리에 1을 써서 8비트 이진수로 바꾼다. 예) 77 = 64 + 8 + 4 + 1 = 0100 1101.

확인 — 7을 8비트 이진수로?

0000 0111 (4 + 2 + 1).

4. 문자는 ASCII 번호로

문자도 번호(ASCII)로 바꾼 뒤 이진수로 써요. 대문자 A는 65, 소문자 a는 97이에요. 표를 주니까 찾아서 번호를 이진수로 바꾸면 돼요. 예) R = 82 = 0101 0010.

시험엔 이 한 문장

문자는 ASCII 표에서 번호를 찾아 1바이트(8비트) 이진수로 바꿔 메모리에 한 칸씩 저장한다.

확인 — 글자 하나(영어)는 몇 바이트로 저장되나?

1바이트(8비트).

5. 논리 게이트와 가산기

AND는 둘 다 1이어야 1, OR는 하나라도 1이면 1, NOT은 뒤집기, XOR은 다르면 1이에요. 덧셈 회로는 1의 개수로 풀어요. 1이 1개면 합 1, 2개면 합 0에 올림 1, 3개면 합 1에 올림 1이에요.

시험엔 이 한 문장

반가산기는 두 비트를 더해 합(S=A XOR B)과 올림(Cout=A AND B)을 내고, 전가산기는 아랫자리 올림(Cin)까지 더하며, 8개를 이어 8비트 덧셈기를 만든다. 맨 아래 Cin은 0이다.

확인 — 반가산기에 1과 1을 넣으면 S와 Cout은?

S=0, Cout=1.

6. CPU 부품과 레지스터

CPU 안에는 ALU(계산), CU(해독·제어), 레지스터(빠른 메모장)가 있어요. 특수 레지스터는 PC(다음 명령 주소), IR(지금 명령), MAR(메모리 주소), MBR(메모리 값), AC(계산 결과)예요.

시험엔 이 한 문장

CPU는 계산을 하는 ALU, 명령을 해독하고 제어신호를 내는 제어장치, 빠르고 작은 레지스터로 이루어지며, PC는 다음 명령 주소, IR은 현재 명령, MAR는 메모리 주소, MBR는 메모리 값, AC는 계산 결과를 담는다.

확인 — 다음에 읽을 명령의 주소를 가진 레지스터는?

PC(프로그램 카운터).

7. 명령 실행 5단계 (교수님이 복습하라고 한 것)

명령 하나는 인출 → 해독 → 실행 → 데이터 → 기록 순서로 실행돼요. 도서관에서 책 번호를 보고 가져오고, 뜻을 알아보고, 계산하고, 서랍을 확인하고, 공책에 적는 거예요. ADD는 메모리를 안 쓰니까 데이터 단계가 비어요.

예) PC가 4이고 명령이 2칸이면 인출에서 MAR ← 4, PC ← 6, IR ← ADD R3 R1 R2이고, 실행에서 X=5, Y=7, 제어신호 +, AC=12예요.

시험엔 이 한 문장

명령은 인출(PC 주소의 명령을 IR로 가져오고 PC 증가), 해독(제어장치가 제어신호 결정), 실행(ALU 계산), 데이터(메모리 접근 명령만), 기록(결과를 레지스터에 쓰기)의 5단계로 실행된다.

확인 — ALU가 실제로 계산하는 단계는?

실행(execute).

8. 기계어와 ALU 입력값

기계어는 어셈블리어와 1대1로 대응돼요. 그림에 나온 줄에서 opcode와 레지스터·숫자를 사전처럼 베껴 와요. ALU에서 ADD R3 R1 R2(R1=2, R2=3)는 A=0000 0010, B=0000 0011, C=1000 0000, Y=0000 0101이에요. 제어신호 C는 + − x / & | >> << 순서라 덧셈이 맨 앞이에요.

시험엔 이 한 문장

ADD R3 R1 R2는 R1과 R2를 더해 R3에 저장하는 명령으로, ALU에 A=2, B=3, 제어신호 C=덧셈(1000 0000)이 입력되고 Y=5(0000 0101)가 출력된다.

확인 — 제어신호 C로 곱셈을 쓰면?

0010 0000 (세 번째 자리).

9. 메모리 계층 구조 (단골)

메모리는 레지스터 → 캐시 → RAM → SSD/HDD 순으로 빠르고, 이 순서로 작고 비싸요. 레지스터와 캐시만 CPU 안에 있어요. 교수님의 시험공부 비유로, RAM에는 1~7주차 PDF 전체, 캐시에는 지금 보는 자료, 레지스터에는 지금 풀고 있는 숫자가 올라와요.

시험엔 이 한 문장

메모리는 속도가 빠를수록 용량이 작고 비싸서, 레지스터, 캐시, RAM, 보조기억장치의 계층 구조로 쓴다. 레지스터와 캐시는 CPU 안에 있다.

확인 — CPU 안에 있는 메모리 두 개는?

레지스터와 캐시.

10. 가상메모리와 스와핑, 그리고 보조기억장치

RAM(물리메모리)이 모자라면 일부 데이터가 저장장치의 스왑 영역으로 쫓겨나요. 이것이 스와핑이고, 저장장치가 느려서 컴퓨터가 렉에 걸려요. 해결은 RAM을 늘리는 것이에요. 저장장치는 원리로 구분해서 HDD는 자기, CD-ROM은 광학, SSD는 전자예요.

시험엔 이 한 문장

데이터가 RAM 용량을 초과하면 보조기억장치의 스왑 영역을 쓰는 스와핑이 일어나 느려지므로 RAM을 늘려야 한다. HDD는 자기적, CD-ROM은 광학적, SSD는 전자적 성질을 이용하고, RAID는 여러 디스크를 묶고 파티션은 하나를 나눈다.

확인 — RAM이 모자랄 때 데이터가 옮겨 가는 곳은?

스왑 영역(보조기억장치).

기출 빈칸 상위 10개 (정답 굵게)

2023년 기출에 실제로 나온 문장이에요. 손으로 가리고 빈칸을 말해 본 뒤 확인하세요.

  1. 계산장치와 기억장치로 구성되고 프로그램을 한 줄씩 실행하는 현대 컴퓨터 구조는 폰노이만 구조이다.
  2. 반도체 집적도가 2년마다 2배가 된다는 법칙은 무어의 법칙이다.
  3. CPU 클럭이 높아지면 전력·발열이 늘어 온도가 올라가서 클럭을 무한정 높일 수 없다.
  4. 보조기억장치에 있으면 프로그램, 메모리에서 실행 중이면 프로세스이다.
  5. 프로세스를 여러 개 병렬 실행하면 멀티 프로세싱, 프로세스 하나 안에서 흐름을 여러 개로 하면 멀티 쓰레딩이다.
  6. 켜지면 가장 먼저 시작되어 자원과 프로그램을 관리하는 프로그램은 운영체제이다.
  7. 실행 전 코드는 보조기억장치에, 실행하면 주기억장치에 올라오고, 기계어는 CPU가 실행한다.
  8. 속도가 빠른 순서(RAM=1, SSD/HDD=2, 레지스터=3, 캐쉬=4)는 3, 4, 1, 2이다.
  9. RAM을 넘어 스왑을 쓰는 과정은 스와핑이고, 40GB 파일의 렉은 RAM을 업그레이드해 해결한다.
  10. HDD는 자기, CD-ROM은 광학, SSD는 전자. 여러 개 묶는 것은 RAID, 하나를 나누는 것은 파티션이다.

서술형 4개 — 이것만 연습

가리고 종이에 한 번씩 써 보세요. 위 "시험엔 이 한 문장"을 이어 붙이면 답이 돼요.

1. 폰노이만 구조를 설명하시오.

폰노이만 구조는 프로그램과 데이터를 기억장치에 저장하고, 명령어를 한 개씩 CPU로 가져와 실행하는 프로그램 내장형 구조이다. CPU는 제어와 연산, RAM은 실행 중인 프로그램과 데이터 저장, 보조기억장치는 영구 저장, 입출력장치는 사용자와의 인터페이스, 시스템 버스는 부품 간 데이터 전달 경로이다.

2. 명령어 실행 5단계를 쓰시오.

인출(PC가 가리키는 명령을 메모리에서 읽어 IR로 가져오고 PC를 증가), 해독(제어장치가 IR의 명령을 해독해 제어신호 결정), 실행(ALU가 계산), 데이터(메모리를 읽거나 쓰는 명령일 때만 MAR, MBR 사용), 기록(결과를 레지스터에 기록)의 순서이다.

3. 메모리 계층 구조를 쓰는 이유를 설명하시오.

빠른 메모리는 용량이 작고 비싸며 용량이 커질수록 느려진다. 빠르면서 큰 메모리는 너무 비싸므로 가격 안에서 속도와 용량을 함께 얻기 위해 레지스터, 캐시, RAM, 보조기억장치의 계층으로 나누어 쓴다. 필요한 데이터만 위 계층으로 올려 CPU가 빠르게 쓴다.

4. 40GB 파일을 16GB RAM으로 읽으면 느려지는 이유와 해결 방법을 쓰시오.

데이터가 RAM(물리메모리) 용량을 초과하면 일부가 보조기억장치의 스왑 영역으로 옮겨지는 스와핑이 일어난다. 접근 속도가 매우 느린 보조기억장치를 계속 쓰게 되어 컴퓨터가 느려진다. 코드를 수정하지 않는다면 데이터보다 큰 RAM(40GB 이상)으로 업그레이드해야 한다.
