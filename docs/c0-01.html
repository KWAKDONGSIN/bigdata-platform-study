컴퓨터는 무슨 일을 하는 기계일까요

컴퓨터(computer)는 한마디로 계산(computation)하는 기계예요. 교수님은 더 정확하게 "프로그램을 실행해서 계산하는 기계"라고 정리했어요.

컴퓨터가 하는 일은 크게 네 가지예요. 시험공부하는 학생을 떠올리면 쉬워요.

하는 일뜻대표 부품학생 비유
입력컴퓨터에 정보를 넣어요키보드, 마우스문제지를 받아서 읽기
처리계산하고 판단해요CPU머리로 문제 풀기
저장자료와 결과를 보관해요RAM, SSD·HDD책상 위(잠깐), 도서관(오래)
출력결과를 사람에게 보여 줘요모니터답안지에 답 쓰기

"계산"이라고 하면 덧셈·뺄셈만 떠올리기 쉬워요. 하지만 강의자료는 컴퓨터가 하는 계산을 다섯 가지로 나눠요.

종류어떤 계산인가요
산술 계산덧셈·뺄셈·곱셈·나눗셈 같은 사칙연산
논리 계산AND, OR, NOT으로 참(1)인지 거짓(0)인지 판단. 조건문과 반복문을 제어해요
데이터 처리자료를 검색하고, 정렬하고, 걸러 내요
그래픽 처리이미지, 영상, 게임 화면을 만들어요
복합 계산위의 것들을 섞은 더 복잡한 계산
한 줄 정의

컴퓨터 = 프로그램을 실행해서 계산하는 기계. 하는 일은 입력, 처리, 저장, 출력이에요.

왜 이렇게 나눠서 알아 둘까요? 나중에 컴퓨터가 느려지거나 멈췄을 때 "입력, 처리, 저장, 출력 중 어디가 문제인가"를 따져 볼 수 있기 때문이에요. 교수님도 부품을 배우는 이유가 "문제가 생기면 어디서 생기는지 이해하기 위해서"라고 했어요.

시험엔 이렇게 써요

컴퓨터는 프로그램을 실행하여 계산하는 기계이다. 입력장치로 받은 데이터를 CPU가 처리하고, 기억장치에 저장하며, 출력장치로 결과를 보여 준다.

잠깐 확인 — 컴퓨터가 하는 네 가지 일은 무엇인가요?

입력, 처리, 저장, 출력이에요. "받아서 → 계산해서 → 보관하고 → 보여 준다"로 기억하세요.
