운영체제(OS) ★★

컴퓨터를 켜면 가장 먼저 실행되는 프로그램이 운영체제(OS, Operating System)예요. 운영체제는 SSD에 설치돼 있다가 전원을 켜면 RAM에 올라와서, 이후에 실행하는 모든 응용 프로그램과 부품을 관리해요. 종류는 윈도우, 리눅스, macOS가 대표적이에요.

한 줄 정의

운영체제 = 컴퓨터 전원이 켜지면 가장 먼저 시작되며, 컴퓨터 자원을 관리하고 여러 응용 프로그램의 실행을 관리하는 프로그램.

강의자료가 정리한 운영체제의 주요 관리 일은 아래와 같아요. 이 중 프로세스 관리, 주기억장치(메모리) 관리가 교수님이 강조한 두 가지예요.

관리 대상하는 일
프로세스 관리프로세스를 만들고, 없애고, 잠시 멈추고, 계속하게 해요
작업 관리작업의 순서와 우선순위를 정해요
주기억장치 관리프로세스마다 RAM 공간을 나눠 주고(할당), 끝나면 거둬들여요(회수)
보조기억장치 관리저장장치를 효율적으로 쓰게 해요
입출력장치·파일·보안 관리키보드, 모니터 같은 장치와 파일, 보안을 관리해요
비유 — 카페의 바리스타

강의자료의 비유예요. 손님이 커피 머신을 직접 만지면 사용법도 알아야 하고 기계가 망가질 수 있어요. 그래서 바리스타(운영체제)에게 부탁해요. 응용 프로그램도 부품(하드웨어)을 직접 만지지 않고 운영체제에 부탁해서 쓰고, 운영체제는 여러 손님의 주문이 뒤엉키지 않게 순서를 정해 줘요.

왜 운영체제가 메모리를 관리해야 할까요? 컴퓨터마다 RAM 용량이 4GB, 8GB, 16GB로 다 다르고, 한꺼번에 프로세스 여러 개가 RAM을 나눠 써야 하기 때문이에요. 서로의 공간을 침범하면 오류가 나니까 운영체제가 정리해 줘요.

그래서 프로그램을 만드는 사람은 "RAM이 거의 무한한 것처럼" 코드를 짜요. 이것이 가상 메모리의 아이디어이고, 실제 RAM에 맞춰 배치하는 일은 운영체제가 맡아요. RAM이 모자라면 저장장치(SSD)의 일부를 임시 공간으로 쓰는데, 이 영역이 스왑(swap) 영역이에요. 자세한 내용은 메모리 장에서 이어져요.

시험엔 이렇게 써요

컴퓨터 전원이 켜지면 가장 먼저 시작되며, 컴퓨터 자원을 관리하고 여러 응용 프로그램의 실행을 관리하는 프로그램을 운영체제라고 한다. (2023 기출 1번 빈칸 정답)

잠깐 확인 — 컴퓨터를 켜면 가장 먼저 실행되는 소프트웨어는 무엇인가요?

운영체제예요. 운영체제가 올라온 뒤에야 워드나 게임 같은 응용 프로그램을 실행할 수 있어요.
