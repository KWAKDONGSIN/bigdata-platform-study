Q3. sum.py가 실행되는 과정 (10점)

다음 파이썬 코드가 어디에 저장되고, 어디에 올라가고, 누가 계산하는지를 빈칸 10개(A~E, v~z)로 물어요. 한 칸에 1점이에요.

1. n = 1 2. sum = 0 3. while (n <= 100): 4. sum = sum + n 5. n = n + 1
코드 줄무슨 뜻
n = 1n이라는 이름의 칸에 1을 넣어요.
sum = 0sum이라는 이름의 칸에 0을 넣어요.
while (n <= 100):n이 100 이하인 동안 아래 두 줄을 계속 반복해요.
sum = sum + nsum 칸의 값에 n을 더해 다시 sum 칸에 넣어요.
n = n + 1n 칸의 값을 1 키워요.

실행 결과 이 코드에는 print가 없어서 화면에 나오는 것은 없어요. 대신 메모리 속 값이 바뀌어, 반복이 끝나면 sum은 5050, n은 101이 돼요.

왜 그런지

  • 실행 전에는 파이썬 실행기와 코드가 보조기억장치(A)에 있어요. 실행하면 주기억장치(B)로 올라와요. 폰노이만 구조의 "SSD → RAM → CPU" 흐름이에요.
  • 한 줄씩 해석한 기계어는 CPU(C)가 실행해요.
  • 1번째 줄은 n(D)에 1(v), 2번째 줄은 sum(E)에 0(w)을 기억시켜요.
  • 3번째 줄은 n이 100 이하인지 보는 줄이라 x는 100이에요. 1은 100 이하라서 다음으로 넘어가요.
  • 4번째 줄은 sum = 0 + 1 = 1이라 y는 1이고, 값은 sum(E) 칸에 들어가요.
  • 5번째 줄은 n = 1 + 1 = 2라 z는 2이고, 값은 n(D) 칸에 들어가요.

손으로 따라가는 요령은 표를 그려 값을 한 줄씩 적는 거예요.

반복줄 4 실행 뒤 sum줄 5 실행 뒤 n
시작 전01
1번째0 + 1 = 12
2번째1 + 2 = 33
3번째3 + 3 = 64
올해 시험에서도 이렇게 쓰세요

"저장은 보조기억장치, 실행 중에는 주기억장치(RAM), 계산은 CPU"를 먼저 쓰고, 변수는 칸마다 이름(n, sum)과 값을 적어 한 줄씩 따라가세요. 코드가 달라져도 같은 틀이에요.

잠깐 확인 — 프로그램이 실행되기 전에 코드가 보관되는 곳은 어디인가요?

보조기억장치(SSD 또는 HDD)예요. 실행하면 주기억장치(RAM)로 올라와요.
