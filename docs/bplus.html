① 큰 그림 한 줄 외우기 15분

이 과목은 결국 "프로그램 한 줄이 컴퓨터 안에서 어떻게 움직이나"예요. 시험지 받으면 여백에 먼저 써 두세요.

그대로 외우기

보조기억장치(SSD) → (실행) → 주기억장치(RAM) → 한 줄씩 → CPU(ALU)가 계산 → 결과는 다시 RAM

이것만 기억한 줄
실행 5단계인출 → 해독 → 실행 → 데이터 → 기록 (ADD는 데이터 단계가 비어 있음)
메모리 계층레지스터 → 캐시 → RAM → SSD/HDD (빠를수록 작고 비싸다)
RAM이 모자라면가상메모리 → 스왑 영역으로 밀려남(스와핑) → 느려짐
계산기 만들기반도체 → 논리게이트 → 논리회로(가산기) → ALU

교수님 말씀 — "CPU 구성 요소와 5단계는 꼭 복습", "레이턴시와 대역폭은 둘 다 속도지만 다른 개념", "주소 변환 과정(TLB → 페이지 테이블 → 스왑 → 캐시)은 빈칸을 만들어 둘 테니 암기".

④ 기출 빈칸 문장 모음 30분

2023년 기출에 실제로 나온 문장이에요. 굵은 글씨가 정답이니, 손으로 가리고 빈칸을 말해 본 뒤 확인하세요. 올해도 비슷한 문장이 나올 수 있어요.

  1. 계산장치(CPU)와 기억장치로 구성되어, 계산장치가 기억장치의 프로그램에서 한 줄씩 실행하는 현대 컴퓨터 구조를 폰노이만 구조라고 한다.
  2. 집적회로의 반도체 집적도가 2년마다 2배씩 증가한다는 것을 무어의 법칙이라고 한다.
  3. 싱글코어는 하나의 CPU 안에 연산 장치가 1개이고, 멀티코어는 여러 개이다.
  4. CPU 클럭이 높아질수록 전력 소모와 발열이 증가하여 CPU의 온도가 상승하며, 이것이 클럭을 무한정 높일 수 없게 한다.
  5. 응용 프로그램의 코드가 보조기억장치에 보관되어 있으면 프로그램, 실행되어 메모리에 적재되어 있으면 프로세스라고 한다.
  6. 하나의 프로그램을 여러 개의 프로세스로 병렬 실행하는 것을 멀티 프로세싱, 하나의 프로세스 안에서 여러 흐름으로 병렬 실행하는 것을 멀티 쓰레딩이라고 한다.
  7. 컴퓨터 전원이 켜지면 가장 먼저 시작되고, 컴퓨터 자원과 여러 응용 프로그램의 실행을 관리하는 프로그램을 운영체제라고 한다.
  8. 컴퓨터 부품 간에 데이터가 전송되는 통로 기능을 하는 것은 메인보드, 거의 대부분의 계산을 하는 것은 CPU, 비휘발성으로 데이터를 반영구 보관하는 것은 보조기억장치(SSD/HDD), 휘발성으로 수행 중인 프로그램 코드와 데이터를 보관하는 것은 RAM이다.
  9. 이미지 처리와 딥러닝 같은 행렬 기반 연산을 병렬로 빠르게 하는 것은 GPU(그래픽카드)이고, 교류를 직류로 바꿔 전원을 공급하는 것은 전원공급장치이다.
  10. 코드가 실행되기 전에 파이썬 실행기와 코드는 보조기억장치에 있고, 실행되면 주기억장치에 적재되며, 해석된 기계어는 CPU에 전달되어 실행된다.
  11. XOR 논리 게이트는 두 비트가 같으면 0, 다르면 1을 출력한다. 반가산기는 합 비트 S와 올림 비트 Cout을 출력한다.
  12. 전가산기는 두 입력 비트(A, B)와 한 개의 올림 비트(Cin)를 받아 합 S와 올림 Cout을 출력한다. 8비트 덧셈기에서 맨 아래 Cin은 0이다.
  13. CPU는 한 기계어 명령을 인출(fetch), 해독(decode), 실행(execute), 데이터(data), 기록(write back)의 5단계로 실행한다.
  14. 인출 단계에서 PC가 4이고 명령이 2칸이면 MAR ← 4, PC ← 6이 되고, IR에는 ADD R3 R1 R2가 들어간다.
  15. 실행 단계에서 ALU 제어신호는 +이고, X는 5, Y는 7, AC에는 12가 들어간다.
  16. CPU 안에 있는 메모리는 레지스터와 캐시이고, 접근 속도가 빠른 순서는 레지스터 → 캐시 → RAM → SSD/HDD이다.
  17. 엑셀 프로그램을 설치하면 보조기억장치에 저장되고, 실행하면 주기억장치(RAM)에 적재된다. 지금 계산하는 주변 데이터는 캐시에, ALU가 직접 더하는 값은 레지스터에 올라간다.
  18. 프로세스의 가상메모리 공간에 올린 데이터를 운영체제가 물리메모리에 할당하는데, 그 용량을 넘으면 보조기억장치의 스왑메모리 영역으로 옮겨지며 이를 스와핑이라 한다.
  19. 코드를 수정하지 않고 40GB 파일의 렉을 해결하려면 RAM을 40GB 이상으로 업그레이드해야 한다.
  20. HDD는 자기적, CD-ROM은 광학적, SSD는 전자적 성질을 이용한다.
  21. 보조기억장치 여러 개를 하나로 묶는 것은 RAID, 하나를 나눠 쓰는 것은 파티션이다.
  22. SSD는 HDD보다 읽기/쓰기가 빠르지만 같은 용량에 가격이 비싸다. 그래서 운영체제는 SSD에, 동영상과 사진은 HDD에 보관한다.

더 풀고 싶으면 기출 풀이 장에서 10문제를 한 번씩 직접 써 보세요.

⑤ 계산 유형 5개 직접 풀기 30분

기출 Q4, Q5, Q6, Q7, Q9가 이 유형이에요. 가린 채 한 번씩 직접 해 보세요.

1. 십진수 137을 1바이트 이진수로 (기출 Q4)

자릿값을 큰 것부터 써요. 128 64 32 16 8 4 2 1. 137은 128이 들어가고(남은 9), 64·32·16은 안 들어가고, 8이 들어가고(남은 1), 4·2는 안 들어가고, 1이 들어가요. 그래서 1000 1001이고, 검산은 128 + 8 + 1 = 137이에요. 같은 방법으로 77 = 64 + 8 + 4 + 1 = 0100 1101이에요.

2. 문자 Robot을 ASCII 이진수로 (기출 Q4)

표에서 R = 82, o = 111, b = 98, t = 116을 찾아요. 82 = 64 + 16 + 2 = 0101 0010, 111 = 64 + 32 + 8 + 4 + 2 + 1 = 0110 1111, 98 = 64 + 32 + 2 = 0110 0010, 116 = 64 + 32 + 16 + 4 = 0111 0100이에요. o가 두 번이라 같은 값을 두 번 써요.

3. ADD R3 R1 R2를 ALU에서 계산할 때 A, B, C, Y (기출 Q6.2)

R1은 1번째 줄에서 2, R2는 2번째 줄에서 3이에요. A = 2 = 0000 0010, B = 3 = 0000 0011이에요. 제어신호 C는 + − x / & | >> << 순서라 덧셈은 맨 앞이라 1000 0000이에요. Y = 2 + 3 = 5 = 0000 0101이에요.

4. 전가산기로 0000 0111 + 0000 0101 (기출 Q5.6~5.7)

1의 개수로 풀어요. 1이 1개면 S=1, 올림 0, 2개면 S=0, 올림 1, 3개면 S=1, 올림 1이에요. 0번째 자리 1+1(올림 0)은 S=0, 올림 1. 1번째 자리 1+0+올림1은 S=0, 올림 1. 2번째 자리 1+1+올림1은 S=1, 올림 1. 3번째 자리 0+0+올림1은 S=1이에요. 그래서 Y = 0000 1100(= 12)이에요.

5. 가상주소 10,000, 페이지 크기 4KB일 때 페이지 번호와 오프셋 (7주차 자료)

4KB = 4,096바이트예요. 10,000 = 2 × 4,096 + 1,808이라 페이지 번호는 2, 오프셋은 1,808이에요. 페이지 2가 프레임 9에 매핑되어 있으면 물리주소는 9 × 4,096 + 1,808 = 38,672이에요. 오프셋은 바뀌지 않아요.
