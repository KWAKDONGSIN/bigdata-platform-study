레이턴시 = 응답까지 걸리는 시간낮을수록 빠름대역폭 = 단위 시간당 전송량높을수록 많이 전송서로 다른 개념
9. 가상메모리, 스왑 영역, 스와핑을 설명하고, RAM 16GB 컴퓨터에서 40GB 파일을 읽을 때 느려지는 이유를 쓰시오.

시험지엔 이렇게 써요

가상메모리는 실제 RAM 크기와 상관없이 프로세스에 큰 메모리 공간을 제공하는 기술이다. 프로세스의 가상메모리에 올린 데이터를 운영체제가 물리메모리(RAM)에 할당하는데, 필요한 크기가 RAM 용량을 넘으면 일부가 보조기억장치의 스왑 영역으로 옮겨지며, 이 과정을 스와핑이라 한다. 40GB 데이터가 16GB RAM을 넘으면 접근 속도가 매우 느린 보조기억장치를 계속 사용하게 되어 컴퓨터가 매우 느려진다. 해결하려면 데이터보다 큰 RAM(40GB 이상)으로 업그레이드한다.

시험지엔 이렇게 써요

TLB는 자주 쓰는 주소 변환 정보(페이지→프레임)를 저장하는 캐시이고, 페이지 테이블은 가상 페이지가 RAM의 어느 프레임에 대응되는지 기록한 자료구조로 보통 RAM에 있으며, CPU 캐시는 실제 데이터(캐시라인)를 저장한다. CPU는 가상주소를 먼저 TLB에서 찾고(히트면 바로 물리주소), 미스이면 페이지 테이블을 탐색해 TLB를 갱신한다. 페이지가 RAM에 없으면 페이지 폴트로 OS가 스왑에서 RAM으로 적재하고 페이지 테이블을 갱신한다. 물리주소를 얻으면 캐시에서 데이터를 찾고, 미스이면 RAM에서 읽어 캐시를 채운다.

TLB = 주소 변환 정보 캐시페이지 테이블 = 페이지→프레임 표CPU 캐시 = 실제 데이터TLB 미스 ≠ 페이지 폴트페이지 폴트 → 스왑에서 적재주소 먼저, 데이터 나중

시험지엔 이렇게 써요

HDD는 회전하는 원판에 자기적 성질로 데이터를 저장하고, SSD는 NAND 플래시 메모리를 이용해 전자적으로 저장하는 보조기억장치이다. SSD는 읽기/쓰기 속도가 빠르지만 같은 용량에 가격이 비싸고, HDD는 느리지만 싸고 용량이 크다. 따라서 운영체제처럼 자주 쓰는 프로그램과 데이터는 SSD에, 동영상과 사진처럼 자주 쓰지 않는 데이터는 HDD에 보관하는 것이 효율적이다.

HDD 자기적SSD 전자적(플래시)SSD 빠르고 비쌈HDD 느리고 쌈자주 쓰는 것은 SSD덜 쓰는 것은 HDD

시험지엔 이렇게 써요

RAID는 여러 개의 보조기억장치를 연결해 하나의 논리적 저장장치로 구성해 용량과 성능을 개선하는 기술이고, 파티션은 보조기억장치 하나를 작은 용량의 여러 공간으로 나누어 쓰는 것이다. RAID 0은 데이터를 여러 디스크에 분산 저장(스트라이핑)해 접근·전송 속도를 높인다. RAID 1은 같은 데이터를 두 디스크에 복제(미러링)해 용량 이득은 없지만 결함 허용도가 높고 가격이 비싸다. RAID 5는 패리티를 분산 저장해 디스크 하나가 고장 나도 복구할 수 있으며 비용과 안정성이 조화로워 서버에서 널리 쓰인다.
