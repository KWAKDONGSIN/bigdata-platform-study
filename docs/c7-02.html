HW3W 데이터 표현 — 진법, ASCII, ALU 입력값

Q1 요지 : 正(5개를 뜻하는 표시) 7개로 적은 수량을 사람이 원고지에, 컴퓨터가 메모리에 어떻게 적는지 나타내고, 5진수, 2진수, 8진수, 16진수로 바꿔라.

풀이 : 正 한 글자가 5이고 7개니까 5 × 7 = 35예요. 사람은 "正"을 7칸에 쓰거나 "35"로 적고, 컴퓨터는 숫자 35를 8비트 이진수로 메모리 한 칸(1바이트)에 적어요.

진법답구하는 법 (나누기 나머지, 아래에서 위로 읽기)
5진수12035 ÷ 5 = 7 … 0, 7 ÷ 5 = 1 … 2, 1 ÷ 5 = 0 … 1 → 1 2 0
2진수10001135 = 32 + 2 + 1 → 1 0 0 0 1 1 (8비트로 쓰면 0010 0011)
8진수4335 ÷ 8 = 4 … 3 → 4 3
16진수2335 ÷ 16 = 2 … 3 → 2 3

Q2 요지 : 이름 "John"을 사람이 원고지에, 컴퓨터가 메모리에(ASCII 변환표 사용) 적어라. 사람은 J, o, h, n 네 칸에 적어요. 컴퓨터는 글자마다 ASCII 번호를 1바이트 이진수로 적어요.

글자ASCII 번호1바이트 이진수
J740100 1010
o1110110 1111
h1040110 1000
n1100110 1110

번호를 이진수로 바꿀 때는 128 64 32 16 8 4 2 1 자리에서 더해서 맞추는 방법이 쉬워요. 예를 들어 74 = 64 + 8 + 2라서 64, 8, 2 자리만 1이에요. (2023 기출 Q4의 "Robot"과 137, 7, 38, 77, 11도 같은 방식이에요.)

Q3 요지 : 어셈블리어 두 줄 ADD R1, 2, 3과 MUL R2, 5, 5를 ALU에서 계산할 때 A, B, C, Y의 8비트 값은?

풀이 : A와 B는 계산할 두 숫자, Y는 결과, C는 어떤 연산을 할지 고르는 제어신호예요. C는 왼쪽부터 +, -, ×, /, &, |, >>, << 순서(C7부터 C0)이고, 고른 연산 자리만 1이에요.

입력ADD R1, 2, 3MUL R2, 5, 5
A0000 0010 (2)0000 0101 (5)
B0000 0011 (3)0000 0101 (5)
C1000 0000 (+는 맨 앞)0010 0000 (×는 세 번째)
Y0000 0101 (5)0001 1001 (25 = 16 + 8 + 1)
시험엔 이렇게 써요

컴퓨터는 숫자를 이진수로, 글자를 ASCII 코드값의 이진수로 1바이트씩 메모리에 기록한다. ALU는 A, B 두 입력과 연산을 고르는 제어신호 C를 받아 결과 Y를 출력하며, 제어신호는 +, -, ×, /, &, |, >>, << 순서의 8비트 중 해당 연산 자리만 1이다.

잠깐 확인 — 5 × 5를 계산할 때 ALU의 제어신호 C는?

곱하기(×)는 세 번째 자리라서 0010 0000이에요.
