기계어와 명령어 — opcode와 operand ★★

CPU가 바로 알아듣는 말은 0과 1로 된 기계어뿐이에요. 사람은 파이썬 같은 고급언어로 코드를 쓰고, 번역기(인터프리터 등)가 이것을 기계어로 바꿔 줘요. 기계어는 사람이 읽기 어려워서, 거의 1대1로 직역한 어셈블리어로 읽어요.

고급언어 (파이썬)어셈블리어기계어 (16비트)
A = 2 + 3MOVE R1 21000 0001 0000 0010
MOVE R2 31000 0010 0000 0011
ADD R3 R1 R21100 0011 0001 0010
STORE CC R3(번지 CC에 R3 저장)
B = 5 * AMOVE R4 51000 0100 0000 0101
LOAD R5 CC(번지 CC에서 R5로 읽기)
MUL R6 R4 R51101 0110 0100 0101
STORE CD R6(번지 CD에 R6 저장)

파이썬 한 줄이 어셈블리 여러 줄이 돼요. A = 2 + 3 하나가 MOVE, MOVE, ADD, STORE 네 줄이에요. 번지(메모리 주소) 줄은 아래에서 따로 풀어요.

명령 한 줄(instruction)은 두 부분으로 이루어져요.

  • opcode(동작 코드) : 무슨 계산을 할지. MOVE, ADD, MUL, LOAD, STORE 등 (문장의 동사)
  • operand(피연산자) : 계산 대상. 숫자, 레지스터, 메모리 주소 (문장의 목적어)

이 수업의 가상 CPU에서는 16비트 명령 하나를 이렇게 4칸씩 끊어 읽어요. 아래 표가 기계어 빈칸 문제를 푸는 열쇠예요.

opcode2진수 (4비트)하는 일
MOVE1000값을 레지스터에 넣기 (대입)
LOAD1001메모리에서 레지스터로 읽기
STORE1010레지스터에서 메모리로 쓰기
ADD1100더하기
MUL1101곱하기

레지스터 번호는 그냥 2진수 4비트예요. R1=0001, R2=0010, R3=0011, R4=0100, R5=0101, R6=0110이에요. 아래 줄을 4칸씩 끊어서 읽어 보세요.

  • MOVE R1 2 = 1000 | 0001 | 0000 0010 → opcode(MOVE), 레지스터 R1, 숫자 2(8비트)
  • ADD R3 R1 R2 = 1100 | 0011 | 0001 | 0010 → opcode(ADD), 결과 R3, 더할 R1, 더할 R2
  • LOAD R5 CC = 1001 | 0101 | CC(8비트 주소)
  • STORE CC R3 = 1010 | CC(8비트 주소) | 0011

번지 CC와 CD는 16진수예요. 16진수 C는 10진수 12이고 2진수 1100이에요. D는 13이고 1101이에요. 그래서 CC = 1100 1100, CD = 1100 1101이에요. 이 값이 2023년 기출 정답과 교수님 설명이에요.

2023년 기출 Q6.1은 위 규칙으로 풀면 돼요.

빈칸답어떻게 풀었나
①0000 0011MOVE R2 3 → 숫자 3을 8비트로
②1000MOVE R1 2의 opcode (다른 MOVE 줄과 같아요)
③0000 0101MOVE R4 5 → 숫자 5를 8비트로
④1100 1100LOAD R5 CC → 주소 CC
⑤1010STORE CD R6의 opcode (STORE는 모두 1010)
⑥1100 1101주소 CD

강의자료 12쪽 예시의 STORE·LOAD 줄에는 주소 자리에 1010 1010 같은 값이 적혀 있어서, 위 규칙(예 LOAD R5의 R5=0101)과 서로 맞지 않아요. 자료 그대로 외우지 말고 규칙으로 푸세요. 참고로 2023 시험지 그림의 4번째 줄 끝 4비트도 0101로 찍혀 있지만 빈칸 ①~⑥과는 상관없어요.

명령의 종류도 알아 둬요. 메모리 접근 명령은 LOAD(메모리에서 레지스터로 읽기)와 STORE(레지스터에서 메모리로 쓰기)예요. 레지스터 계산 명령은 MOVE, ADD, MUL처럼 레지스터끼리 계산해요. 이 둘 외에 분기·반복에서 PC 값을 바꾸는 프로그램 이동 명령도 있어요.

명령어 집합 구조(ISA, Instruction Set Architecture)는 "CPU가 알아듣고 계산할 수 있는 명령어 전체"예요. 이 목록은 CPU 제조사 설계에 따라 달라서, ISA가 다른 CPU에서는 같은 프로그램이 안 돌아가요. 인텔 펜티엄의 기계어는 명령마다 길이가 달라요(가변 길이). AVR은 길이가 같아요(고정 길이).

명령에 주소(operand)를 몇 개 적느냐에 따라 형식이 4가지예요.

형식예특징
0-주소PUSH, POP피연산자가 묵시적(스택을 쓰는 구조)
1-주소ADD X
AC ← AC + M[X]		한쪽은 누산기(AC)가 정해져 있고, 결과도 AC에 저장
2-주소ADD R1, R2
R1 ← R1 + R2		R1의 원래 값은 지워져요
3-주소ADD R1, R2, R3
R1 ← R2 + R3		입력 값이 보존돼요. 프로그램은 짧아지지만 해독이 복잡해요

1-주소 형식으로 손계산 하나를 해 봐요. 명령이 16비트이고 opcode가 5비트, 주소가 11비트라면 opcode로 25 = 32가지 연산을, 주소로 211 = 2,048개 번지를 가리킬 수 있어요. 비트가 n개면 2를 n번 곱한 만큼 구분할 수 있기 때문이에요.

외우기 팁

opcode는 "동사", operand는 "목적어"예요. 같은 동사는 같은 코드로 써요. 그러니 빈칸이 나오면 같은 opcode를 쓴 다른 줄을 먼저 찾아보세요(②, ⑤가 그 경우예요).

시험엔 이렇게 써요

기계어 명령어는 연산의 종류를 나타내는 동작 코드(opcode)와 연산의 대상을 나타내는 오퍼랜드(operand)로 구성된다. 명령어 집합 구조(ISA)는 CPU가 인식하여 계산할 수 있는 명령어들의 집합이며 CPU 제조사의 설계에 따라 달라진다. 어셈블리어는 기계어를 사람이 이해하기 쉽게 거의 1대1로 직역한 언어이다.

잠깐 확인 — ADD R3 R1 R2에서 opcode와 operand를 구분해 보세요.

opcode는 ADD(더하라)이고, operand는 R3, R1, R2예요. R1과 R2를 더해서 R3에 저장하라는 뜻이에요.
