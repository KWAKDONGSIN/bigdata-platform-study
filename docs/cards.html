용어 · 이름 (38)

CPU
Central Processing Unit (중앙처리장치)

컴퓨터의 두뇌. 명령을 해석하고 계산한다

ALU
Arithmetic Logic Unit (산술논리연산장치)

CPU 안에서 덧셈·곱셈·AND·OR 같은 계산을 하는 장치

CU
Control Unit (제어장치)

명령을 해독해 각 장치에 제어 신호를 보내는 지휘자

RAM
Random Access Memory (주기억장치)

실행 중인 프로그램·데이터를 담는 휘발성 작업대

ROM
Read Only Memory

읽기 전용이고 전원이 꺼져도 남는 비휘발성 메모리

SRAM
Static RAM (정적 RAM)

빠르지만 비싸서 캐시에 쓰는 메모리

DRAM
Dynamic RAM (동적 RAM)

리프레시가 필요하고 싸서 주기억장치에 쓰는 메모리

SSD
Solid State Drive

플래시 메모리로 만든 빠른 저장장치(전자적 성질)

HDD
Hard Disk Drive

자기 원판에 기록하는 저장장치(자기적 성질)

GPU
Graphics Processing Unit (그래픽카드)

이미지·딥러닝의 행렬 연산을 병렬로 빠르게 하는 부품

PC (CPU 안)
Program Counter (프로그램 카운터)

다음에 읽을 명령어의 주소를 가진 레지스터 (Personal Computer가 아님)

IR
Instruction Register (명령 레지스터)

지금 실행할 명령어를 담는 레지스터

MAR
Memory Address Register

메모리의 읽고 쓸 주소를 담는 레지스터

MBR
Memory Buffer Register

메모리와 주고받는 값을 잠깐 담는 레지스터

AC
Accumulator (누산기)

ALU의 계산 결과를 임시로 담는 레지스터

OS
Operating System (운영체제)

전원을 켜면 가장 먼저 실행되어 컴퓨터 자원을 관리하는 프로그램

ISA
Instruction Set Architecture (명령어 집합 구조)

CPU가 알아듣는 명령어 전체. 제조사마다 다르다

RISC
Reduced Instruction Set Computer

단순한 명령을 빠르게 처리하는 설계 (ARM)

CISC
Complex Instruction Set Computer

복잡한 명령을 한 줄로 처리하는 설계 (x86)

BCD
Binary Coded Decimal (이진화 십진코드)

십진수 한 자리를 4비트로 바꿔 쓰는 코드

ASCII
American Standard Code for Information Interchange

영어 글자와 기호에 번호(1바이트)를 붙인 약속. A=65, a=97

MSB / LSB
Most / Least Significant Bit

이진수에서 가장 큰 자리(왼쪽) / 가장 작은 자리(오른쪽)

TLB
Translation Lookaside Buffer

주소 변환 정보(페이지→프레임)를 모아 둔 캐시

VA / PA
Virtual Address / Physical Address

프로그램이 쓰는 가상 주소 / RAM의 실제 주소

RAID
Redundant Array of Inexpensive(Independent) Disks

작은 디스크 여러 개를 묶어 큰 저장장치처럼 쓰는 기술

CD-ROM
Compact Disk Read Only Memory

레이저로 읽는 광학 저장장치(광학적 성질)

DVD
Digital Versatile Disc

CD와 같은 모양의 더 큰 용량 광디스크(일반 4.7GB)

VRAM
Video RAM

그래픽카드용 RAM. 읽는 핀과 쓰는 핀이 따로 있다

PCB
Process Control Block

운영체제가 프로세스 정보를 적어 두는 기록

HA / FA
Half Adder / Full Adder (반가산기 / 전가산기)

1비트 두 개 / 올림까지 세 개를 더하는 회로

XOR
Exclusive OR (배타적 논리합)

두 입력이 다르면 1, 같으면 0

NAND / NOR
NOT-AND / NOT-OR

AND의 반대 / OR의 반대 게이트

bit
binary digit

이진수 한 자리, 0 또는 1

Hz / GHz
Hertz (초당 횟수) / Giga Hertz

1GHz = 초당 10억 번, 3GHz = 초당 30억 번

KB / MB / GB / TB
2의 10제곱씩 커지는 바이트 단위

1KB = 2^10 바이트 = 1024 (K→M→G→T 순으로 1024배)

rpm
rotations per minute

디스크가 1분에 도는 바퀴 수 (7200rpm = 1회전 8.33ms)

SMT / 하이퍼스레딩
Simultaneous Multi-Threading

코어 하나가 두 흐름을 동시에 처리해 가상으로 코어를 2배로 보이게 하는 기술

FI·DI·EI·BD·WB
Fetch / Decode / Execute Instruction, Buffer/Data, Write Back

파이프라인 5단계 이름

공식 · 숫자 (15)

비트·바이트·자릿값
1바이트 = 8비트 (0~255, 256가지), 니블 = 4비트 = 16진수 한 자리. 1바이트 자릿값은 128 · 64 · 32 · 16 · 8 · 4 · 2 · 1 (큰 자릿값부터 들어가면 1, 아니면 0)
진법 변환
10진 → R진은 R로 계속 나눠 나머지를 거꾸로 읽는다 (35 → 5진 120, 8진 43, 16진 23). R진 → 10진은 자리 숫자 × 자릿값을 모두 더한다 (1000 1001 = 128 + 8 + 1 = 137)
2진 ↔ 8진 · 16진
2진수를 오른쪽부터 3비트씩 묶으면 8진수, 4비트씩 묶으면 16진수
2의 거듭제곱
2^10 = 1024 = 1K, 2^20 = 1M, 2^30 = 1G(약 10억), 2^40 = 1T
ASCII
A = 65, a = 97, 0 = 48 (한 글자 1바이트). 예) R = 82, o = 111, b = 98, t = 116
유니코드 한글
U+AC00 ~ U+D7A3, 총 11,172자
코드 기본
원소 N개의 고정길이 코드는 log2 N을 올림한 비트 (25개 → 5비트). 짝수 패리티는 1의 개수가 짝수가 되게 비트를 붙이고, 홀수 패리티는 홀수로
8421 BCD·3초과
BCD는 자리마다 4비트 (1225 → 0001 0010 0010 0101). 3초과는 각 자리에 3을 더한 코드
ALU 제어신호 C
C7~C0 = + − x / & | >> << 순서. 덧셈 1000 0000, 곱셈 0010 0000
명령 실행 5단계
인출 → 해독 → 실행 → 데이터 → 기록. 2칸 명령이면 PC는 2씩 증가 (4 → 6)
무어의 법칙·클럭
집적도 24개월(2년)마다 2배. 3GHz = 초당 30억 번
접근 속도 표
레지스터 <1ns · 캐시 0.5~2.5ns · RAM 50~70ns · SSD 20~200µs · HDD 5~20ms · CD-ROM 50~200ms
가상주소 계산
가상주소 = 페이지번호 × 페이지크기 + 오프셋 (4KB = 4096B, 10,000 = 2 × 4096 + 1808)
디스크 액세스 시간
탐색시간 + 회전지연시간 + 전송시간(+ 제어기 오버헤드). 평균 회전지연 = 반 바퀴 (7200rpm → 4.17ms, 10000rpm → 3ms)
2의 보수 (참고, 수업 자료 밖)
비트를 모두 뒤집고 1을 더한다 (5 = 0000 0101 → −5 = 1111 1011)
