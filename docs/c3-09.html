이 장 3줄 요약
  • 계산기(ALU)는 반도체(다이오드·트랜지스터) → 논리 게이트(AND·OR·NOT) → 논리 회로(덧셈기) → ALU 순으로 쌓아 만들고, ALU는 A, B(입력), C(제어), Y(출력) 신호로 동작해요.
  • 진리표 출력은 AND 0001, OR 0111, NAND 1110, NOR 1000, XOR 0110이고 NOT은 반대예요. 반가산기는 S = A XOR B, C = A AND B이고, 전가산기는 입력 1의 개수가 홀수면 S = 1, 2개 이상이면 Cout = 1이에요.
  • 8비트 덧셈기는 전가산기 8개를 이어서, i번의 Cout을 i+1번의 Cin에 연결하고 0번의 Cin은 0, 7번의 Cout은 연결하지 않아요.
