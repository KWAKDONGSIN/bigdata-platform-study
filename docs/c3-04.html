불 대수 — 논리를 식으로 쓰기

게이트의 규칙을 수학 식으로 쓴 것이 불 대수(부울 대수, Boolean algebra)예요. 값이 0과 1 둘뿐인 대수라서, 우리가 아는 곱셈과 덧셈과 비슷하지만 1 + 1이 2가 아니라 1이라는 점이 달라요.

게이트식으로 쓰기읽는 법
ANDF = A·B 또는 F = AB곱처럼 써요. "A 그리고 B"
ORF = A + B합처럼 써요. "A 또는 B"
NOTF = A (A 위에 막대)"A가 아니다". 0이면 1, 1이면 0
XORF = A ⊕ B"A와 B가 다르다". AB + AB와 같아요

식을 읽는 연습을 해 볼게요. 강의자료 22쪽의 반가산기 합(S)은 S = AB + AB = A ⊕ B예요. 풀어 읽으면 "A가 0이면서 B가 1이거나(AB), A가 1이면서 B가 0일 때(AB) S가 1이다"이고, 곧 "A와 B가 다를 때 1"이라서 XOR와 똑같아요.

그리고 자주 쓰는 기본 규칙이 있어요. 값이 0과 1뿐이라서 직접 대입해 보면 모두 확인돼요.

규칙식이유
0 또는 1과 합치기A + 0 = A
A + 1 = 1		OR는 1이 하나라도 있으면 1이에요
0 또는 1과 곱하기A·1 = A
A·0 = 0		AND는 0이 하나라도 있으면 0이에요
같은 것끼리A + A = A
A·A = A		A가 0이든 1이든 결과가 A예요
자기 자신의 반대와A + A = 1
A·A = 0		A와 A 중 하나는 반드시 1이고 하나는 0이에요

참고로 NAND와 NOR 식에는 드모르간 법칙이 있어요. AB(NAND)는 A + B와 같고, A+B(NOR)는 AB와 같아요. "막대를 쪼개면 AND와 OR가 서로 바뀐다"로 기억하세요. 수업에서 따로 다루지는 않았어요.

비유 — 규칙 문장을 수식으로

"비가 오고 우산이 있으면 외출한다"는 AND, "비가 오거나 눈이 오면 우산을 챙긴다"는 OR, "비가 오지 않는다"는 NOT이에요. 불 대수는 이런 일상 규칙을 짧은 식으로 쓰는 방법이에요.

시험엔 이렇게 써요

불 대수에서 AND는 곱(·), OR는 합(+), NOT은 위 막대(부정), XOR는 ⊕로 쓴다. 반가산기의 합은 S = A ⊕ B, 올림은 C = A·B이다.

잠깐 확인 — A + 1과 A · 0은 각각 얼마인가요?

A + 1 = 1, A · 0 = 0이에요. OR는 1이 있으면 항상 1, AND는 0이 있으면 항상 0이에요.
