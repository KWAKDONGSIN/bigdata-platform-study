하드웨어와 소프트웨어

컴퓨터는 두 덩어리로 이루어져요.

  • 하드웨어(hardware) : 손으로 만질 수 있는 물리적 부품이에요. CPU, RAM, SSD, 그래픽카드, 메인보드, 파워, 모니터, 키보드가 모두 하드웨어예요.
  • 소프트웨어(software) : 만질 수 없는 프로그램(코드)이에요. 하드웨어 위에서 일을 시키는 지시서예요.

소프트웨어도 두 종류로 나뉘어요. 하나는 운영체제(OS, Operating System)이고, 다른 하나는 응용 프로그램(application)이에요. 윈도우, 리눅스, macOS가 운영체제이고, 엑셀, 파워포인트, 게임, 크롬, 파이썬이 응용 프로그램이에요.

비유 — 극장

하드웨어는 극장 건물과 무대, 배우예요. 응용 프로그램은 그날 공연하는 연극(대본)이고, 운영체제는 배우와 무대를 배정하고 순서를 정해 주는 극장 관리자예요. 관리자 없이는 연극을 올릴 수 없어요.

교수님도 "컴퓨터를 조립하고 나서 바로 쓸 수 있는 게 아니라, 운영체제를 깔아 줘야 한다"고 말했어요. 전원을 켜면 가장 먼저 실행되는 소프트웨어가 운영체제이고, 그다음에 우리가 엑셀 같은 응용 프로그램을 실행해요. 하지만 우리가 컴퓨터를 쓰는 진짜 목적은 응용 프로그램이에요.

시험엔 이렇게 써요

하드웨어는 컴퓨터를 구성하는 물리적 장치이고 소프트웨어는 하드웨어를 동작시키는 프로그램이다. 운영체제는 컴퓨터 전원이 켜지면 가장 먼저 실행되어 컴퓨터 자원을 관리하고 응용 프로그램의 실행을 관리하는 프로그램이다.

잠깐 확인 — 엑셀과 윈도우 중 어느 쪽이 운영체제인가요?

윈도우예요. 엑셀은 윈도우 위에서 실행되는 응용 프로그램이에요.
