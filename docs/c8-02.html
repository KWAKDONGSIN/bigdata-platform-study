Q2. 컴퓨터 부품 6개 알아보기 (12점)

보기의 부품 6개는 보조기억장치(1), 그래픽카드(2), 전원공급장치(3), CPU(4), RAM(5), 메인보드(6)예요. 2.1은 사진 속 상자에 번호를 쓰고, 2.2는 설명에 맞는 부품 번호를 써요. 6칸 + 6칸이라 한 칸에 1점이에요.

정답 2.1 사진의 왼쪽 위에서 아래로 3, 6, 4, 2이고, 오른쪽 위는 1, 오른쪽 아래는 5예요.

사진에서 보이는 모습부품번호
맨 위의 네모난 상자전원공급장치(파워)3
부품이 모두 꽂힌 큰 바탕 판메인보드6
팬(선풍기)이 달린 네모 칩CPU(와 쿨러)4
아래쪽의 큰 팬이 달린 긴 카드(ZOTAC 글자)그래픽카드(GPU)2
오른쪽 납작한 상자(SAMSUNG 글자)보조기억장치(SSD)1
CPU 옆의 세로로 길쭉한 막대RAM5

정답 2.2

설명답이유
a. 부품 간 데이터가 다니는 통로6 메인보드모든 부품이 메인보드에 꽂히고, 그 위의 길(버스)로 데이터가 다녀요.
b. 거의 모든 계산을 담당4 CPU계산(ALU)과 제어를 하는 컴퓨터의 두뇌예요.
c. 비휘발성, 전원이 꺼져도 반영구 보관1 보조기억장치SSD·HDD는 전원을 꺼도 데이터가 남아요.
d. 휘발성, 실행 중인 프로그램과 데이터 보관5 RAM전원이 꺼지면 사라지는 대신 빠른 작업대예요.
e. 이미지 처리·딥러닝 같은 행렬 연산을 병렬로2 그래픽카드(GPU)간단한 계산 수천 개를 한꺼번에 하는 데 강해요.
f. 교류를 직류로 바꿔 전원 공급3 전원공급장치콘센트의 교류(AC)를 부품이 쓰는 직류(DC)로 바꿔 줘요.
비유

주방으로 생각해 보세요. CPU는 요리사, RAM은 지금 쓰는 조리대, SSD는 냉장고와 창고, 그래픽카드는 같은 일을 한꺼번에 해내는 조수 부대, 메인보드는 주방 바닥과 통로, 전원공급장치는 가스와 전기를 대 주는 설비예요.

올해 시험에서도 이렇게 쓰세요

설명에서 "비휘발성"이면 보조기억장치, "휘발성"이면 RAM, "행렬·병렬"이면 GPU, "교류→직류"이면 파워, "통로"이면 메인보드, "대부분의 계산"이면 CPU로 연결하세요. 사진 문제는 팬이 달린 것(CPU, 그래픽카드)과 길쭉한 막대(RAM)부터 찾으면 쉬워요.

잠깐 확인 — 전원이 꺼져도 데이터가 남는 부품은 RAM과 SSD 중 무엇인가요?

SSD예요. RAM은 휘발성이라 전원이 꺼지면 사라져요.
