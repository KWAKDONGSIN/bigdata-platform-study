앞으로 자주 만날 말 미리 보기

1장부터 나오는 말을 한 번에 훑어봐요. 지금은 "아, 이런 말이 있구나" 정도만 알면 돼요. 오른쪽 열의 장에서 자세히 배워요.

용어쉬운 뜻어디서
CPU컴퓨터의 두뇌. 계산과 제어를 해요1장
RAM실행 중인 프로그램과 데이터를 잠깐 올려 두는 책상. 전원이 꺼지면 지워져요1장
SSD · HDD프로그램과 데이터를 오래 보관하는 보조기억장치. 전원이 꺼져도 남아요1장
폰노이만 구조프로그램을 기억장치에 두고 한 줄씩 CPU로 가져와 실행하는 현대 컴퓨터의 설계1장
프로그램 / 프로세스저장돼 있는 코드 / 실행되어 메모리에 올라온 코드1장
비트 · 바이트0 또는 1 한 자리 / 8비트 묶음2장
진법 · 문자 코드숫자를 2·8·16진수로 쓰는 법 / 글자를 숫자로 바꾸는 약속(ASCII)2장
논리 게이트0과 1을 받아 0 또는 1을 내놓는 기본 회로(AND, OR, NOT 등)3장
가산기 · ALU게이트를 조립한 덧셈 회로 / 계산을 담당하는 CPU 속 계산기3장
시험엔 이렇게 써요

(용어 고르기 문제 요령) 보기가 비슷해 보여도 "어디에 있는가"로 구분하세요. 보조기억장치에 보관된 코드는 프로그램, 메모리에 올라와 실행 중인 코드는 프로세스예요. 전원이 꺼져도 남으면 비휘발성, 사라지면 휘발성이에요.

잠깐 확인 — 8비트는 몇 바이트이고, 2장에서는 그것으로 무엇을 표현하나요?

1바이트예요. 1바이트로 0부터 255까지 256가지를 표현하고, 숫자와 글자를 이진수로 바꿔서 저장하는 방법을 2장에서 배워요.
