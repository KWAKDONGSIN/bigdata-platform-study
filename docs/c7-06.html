HW7W 가상메모리와 보조기억장치 ★★★ 올해 새 유형

Q1 요지 : 각 상황에서 일어나는 동작과 사건을 보기에서 모두 골라 순서대로 번호를 쓰라. 각 문제는 서로 영향을 주지 않고 현재 상태에서 따로 수행하며, 스와핑은 빈 6번 프레임을 쓴다.

보기는 ① TLB 접근, ② TLB 히트, ③ TLB 미스, ④ 페이지 테이블 접근, ⑤ 페이지 존재, ⑥ 페이지 폴트, ⑦ 캐시 접근, ⑧ 캐시 히트, ⑨ 캐시 미스, ⑩ 메모리 데이터 접근, ⑪ 스와핑이에요. 풀이 순서는 늘 같아요. TLB를 보고 → (미스면) 페이지 테이블을 보고 → (필요하면 스와핑) → 물리 프레임 번호를 얻으면 캐시를 보고 → (미스면) 메모리를 봐요. 5장 5-8의 그림을 따라가면 돼요.

문제풀이답
1) 파워포인트가 2페이지 0번째 바이트 읽기TLB에 파워포인트는 0페이지뿐이라 미스(①③). 파워포인트 페이지 테이블에서 2페이지는 7프레임이라 존재(④⑤). 프레임 7은 캐시(3, 2, 8, 4)에 없어서 캐시 미스(⑦⑨). 메모리에서 읽어요(⑩).1, 3, 4, 5, 7, 9, 10
2) 브라우저가 2페이지 읽기TLB에 브라우저 2페이지가 없어 미스(①③). 페이지 테이블에서 2페이지가 스왑 영역이라 페이지 폴트(④⑥). 운영체제가 스왑 영역에서 빈 6프레임으로 적재하고 테이블과 TLB를 갱신해요(⑪). 프레임 6은 캐시에 없어 미스(⑦⑨), 메모리에서 읽어요(⑩).1, 3, 4, 6, 11, 7, 9, 10
3) 워드가 2페이지 읽기TLB에 (워드, 2페이지 → 2프레임)이 있어 히트(①②). 프레임 2는 캐시에 있어 캐시 히트(⑦⑧). 메모리까지 안 가요.1, 2, 7, 8

Q2 요지 : 워드의 0페이지 0번째 바이트, 브라우저의 0페이지 0번째 바이트 값은? 페이지 테이블로 프레임을 찾고 그 프레임의 데이터에서 맨 앞 두 자리를 읽어요(16진수 두 자리가 1바이트예요).

  • 1) 워드 0페이지 → 워드 페이지 테이블에서 5프레임 → 메모리 5프레임 데이터 BC02…D811 → 0번째 바이트는 BC예요.
  • 2) 브라우저 0페이지 → 브라우저 페이지 테이블에서 8프레임 → 메모리 8프레임 데이터 E101…A912 → 0번째 바이트는 E1이에요.

Q3 요지 : 맞으면 O, 틀리면 X.

설명답이유
1) 가상 페이지 크기와 물리 프레임 크기는 같다O같은 크기로 나누어 대응시켜요
2) TLB 미스가 발생하면 반드시 페이지 폴트가 발생한다X페이지가 RAM에 있으면 페이지 테이블로 정상 변환돼요 (문제 1번 파워포인트 경우)
3) 파워포인트의 1페이지는 현재 RAM에 적재되어 있다X파워포인트 1페이지는 스왑 영역에 있어요
4) 캐시에 저장된 4프레임 데이터는 브라우저 1페이지의 데이터이다O브라우저 1페이지는 4프레임에 있고, 캐시의 4프레임 데이터(F401…B319)가 메모리 4프레임과 같아요
5) 브라우저 2페이지의 데이터는 현재 RAM 6프레임에 들어 있다X브라우저 2페이지는 스왑 영역에 있고, 6프레임은 비어 있어요 (스와핑 때 들어올 자리일 뿐이에요)

Q4 요지 : 보조기억장치 설명의 빈칸을 보기에서 골라 채워라.

문장답
보조기억장치 여러 개를 연결하여 하나의 큰 용량을 가진 장치처럼 사용하는 것RAID
보조기억장치 하나를 작은 용량의 공간으로 나누어 사용하는 것파티션
자기적 성질을 이용HDD
광학적 성질을 이용CD-ROM
전자적 성질을 이용SSD
시험엔 이렇게 써요

TLB 미스 후에는 페이지 테이블을 탐색하여 페이지가 RAM에 있으면(페이지 존재) 정상적으로 주소를 변환하고, 없으면 페이지 폴트가 발생하여 운영체제가 스왑 영역의 페이지를 RAM에 적재(스와핑)하고 페이지 테이블과 TLB를 갱신한다. 물리주소를 얻은 뒤에는 캐시에 접근하여 히트이면 데이터를 사용하고 미스이면 메모리 데이터에 접근한다. TLB 미스가 곧 페이지 폴트는 아니다.

잠깐 확인 — 워드가 0페이지를 읽으면 TLB, 캐시에서 각각 히트인가요? (TLB에 (워드, 0 → 5)가 있고, 캐시에는 5프레임 데이터가 없어요)

TLB는 히트(①②)예요. 캐시에는 5프레임이 없으니 캐시 미스(⑦⑨)이고 메모리에서 읽어요(⑩). 정답은 1, 2, 7, 9, 10이에요.
