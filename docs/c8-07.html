Q7. 명령 실행의 마이크로 단계 (10점)

CPU는 메모리 00번지부터 시작해 지금 04번지의 ADD R3 R1 R2를 실행 중이에요. 이때 서로 다른 두 단계의 그림에서 빈칸 ①~⑩(각 1점)을 채워요.

한 명령은 인출(fetch) → 해독(decode) → 실행(execute) → 데이터(data) → 기록(write back) 5단계로 나뉘어 실행돼요.

단계무슨 일
인출PC가 가리키는 번지의 명령을 메모리에서 읽어 IR로 가져와요. 그다음 PC를 다음 명령 번지로 바꿔요.
해독제어장치(CU)가 IR의 명령을 풀어 제어신호를 정해요.
실행ALU가 계산해요.
데이터메모리를 읽거나 쓰는 명령일 때만 일해요. (MAR, MBR 사용)
기록결과를 레지스터에 적어요.

정답

빈칸정답이유
①인출(fetch)PC, MAR, MBR에서 IR로 명령을 가져오는 그림이에요.
②4PC가 지금 가리키는 번지는 04예요.
③6명령 하나가 두 칸(04, 05)을 차지해서 PC는 다음 명령 번지 06이 돼요.
④4MAR에는 읽을 번지 4가 먼저 들어가요.
⑤ADD R3 R1 R2MBR에 읽어 온 명령이 IR로 옮겨져요.
⑥실행(execute)ALU가 계산을 수행하는 그림이에요.
⑦+ADD이므로 제어신호는 덧셈이에요.
⑧5X에는 R1의 값이에요. 앞에서 MOVE R1 5로 5를 넣었어요.
⑨7Y에는 R2의 값이에요. MOVE R2 7로 7을 넣었어요.
⑩12AC에는 5 + 7의 결과가 들어가요.

이 명령은 메모리를 읽고 쓰지 않아서 4단계(데이터)에서는 아무 일도 안 해요. 마지막 5단계(기록)에서 AC의 12가 R3에 기록돼요.

비유

도서관에서 책 한 권을 읽는 일과 같아요. 책장 번호(PC)를 보고(인출), 제목과 내용을 이해하고(해독), 풀이대로 계산하고(실행), 필요하면 서랍을 열어 확인하고(데이터), 공책에 결과를 적어요(기록).

올해 시험에서도 이렇게 쓰세요

단계 이름은 "인출, 해독, 실행, 데이터, 기록"을 순서대로 쓰고, 인출에서는 "PC → MAR → 메모리 → MBR → IR, 그리고 PC 값 증가", 실행에서는 "ALU가 X, Y에 제어신호대로 계산해 AC에 저장"이라고 적으세요. 교수님이 CPU 구성 요소와 이 5단계를 복습하라고 따로 말했어요.

잠깐 확인 — 명령어 하나가 2칸을 차지할 때 04번지 명령을 읽은 뒤 PC는 몇이 되나요?

6이에요. 04, 05번지를 읽었으니 다음 명령은 06번지예요.
