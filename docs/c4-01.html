폰 노이만 구조 — 프로그램이 실행되는 길 ★★

컴퓨터 안에서 프로그램은 세 군데를 차례로 지나가요. 먼저 보조기억장치(SSD나 HDD)에 보관돼 있다가, 실행하면 주기억장치(RAM)에 올라오고, 한 줄씩 CPU로 가서 계산돼요. 이렇게 "CPU + 기억장치로 이루어지고 프로그램을 한 줄씩 실행하는" 방식을 폰 노이만 구조(Von Neumann architecture)라고 해요.

비유

요리 학원을 떠올려 보세요. 레시피 책은 책꽂이(보조기억장치)에 꽂혀 있고, 오늘 만들 레시피만 주방 작업대(RAM)에 펼쳐 놓아요. 요리사(CPU)는 레시피를 한 줄씩 읽으며 요리하고, 중간 결과는 작업대에 다시 놓아요.

왜 이렇게 나눌까요? 보조기억장치는 크고 값이 싸지만 느려서 CPU가 바로 쓰기엔 답답해요. 그래서 지금 필요한 것만 빠른 RAM에 올려 놓고 써요. 전원이 꺼져도 남아야 하는 프로그램은 보조기억장치에, 실행 중인 것은 RAM에 있는 거예요.

2023년 기출 Q3가 정확히 이 흐름을 물어봤어요. 아래 sum.py는 1부터 100까지 더하는 파이썬 코드예요.

1. n = 1; 2. sum = 0; 3. while (n <= 100): 4. sum = sum + n 5. n = n +1
코드 줄무슨 뜻
n = 1n이라는 이름의 상자를 만들고 1을 넣어요 (대입).
sum = 0sum이라는 상자를 만들고 0을 넣어요.
while (n <= 100):n이 100 이하인 동안 아래 두 줄을 계속 반복해요.
sum = sum + nsum에 n을 더해서 다시 sum에 넣어요 (누적).
n = n +1n을 1 늘려요.

실행 결과는 이래요. 시험지 코드에는 화면에 출력하는 줄이 없어요. 하지만 반복이 끝나면 sum 상자에는 1+2+...+100 = 5050이 들어 있어요. 첫 반복만 따라가 보면 n=1일 때 sum은 0+1=1이 되고, n은 2가 돼요.

기출 빈칸은 이렇게 채워요. 보관은 보조기억장치, 적재는 주기억장치, 계산은 CPU, 변수 상자(n, sum)는 RAM 안에 있어요.

칸답이유
A보조기억장치실행 전에는 파일로 보관돼 있어요.
B주기억장치실행하면 RAM에 적재돼요. 변수 값도 여기에 기억돼요.
CCPU기계어로 바뀐 명령을 계산하는 곳이에요.
D, En, sum1번 줄은 n, 2번 줄은 sum을 만들어요. 4번 줄이 E(sum), 5번 줄이 D(n)에 값을 넣어요.
v, w, x1, 0, 100n=1, sum=0, 조건은 n <= 100이에요.
y, z1, 2첫 반복에서 sum=0+1=1, n=1+1=2예요.
시험엔 이렇게 써요

폰 노이만 구조는 계산장치(CPU)와 기억장치로 구성되어, 계산장치가 기억장치의 프로그램에서 명령을 한 줄씩 실행하고 계산 결과를 기억장치에 기록하는 방식으로 동작하는 컴퓨터 구조이다. 프로그램은 보조기억장치에 보관되어 있다가 실행되면 주기억장치(RAM)에 적재되고, CPU가 명령을 한 줄씩 가져와 계산한다.

잠깐 확인 — 실행 중인 프로그램의 변수 값 n, sum은 어디에 기억되나요?

주기억장치(RAM)예요. 프로그램이 실행되면 RAM에 올라오고, 변수 값도 RAM의 변수 공간에 기억돼요.
