조립 순서와 내 컴퓨터 사양 읽기 (실습)

교수님은 부품이 어떻게 조립되는지도 사진으로 보여 줬어요. 순서는 아래와 같아요. 교수님 요약은 "선만 잘 연결하고 선 정리만 잘하면 된다"예요.

  • ① CPU 장착 : 메인보드의 CPU 자리에 CPU를 꽂아요.
  • ② 써멀 그리스 도포 : CPU 위에 열 전달을 돕는 그리스를 발라요. CPU와 쿨러 사이의 빈틈을 메워 열이 잘 빠지게 해요.
  • ③ CPU 쿨러 장착 : 열을 식히는 팬을 달아요.
  • ④ RAM 장착 : 메인보드의 RAM 슬롯에 꽂아요.
  • ⑤ SSD, 그래픽카드 연결 : SSD는 판(M.2)이거나 선으로 연결해요. 그래픽카드는 PCI 슬롯에 꽂아요.
  • ⑥ 파워 연결 : 파워의 선들을 메인보드와 부품에 연결하고 전원을 켜요.

조립을 끝냈다고 바로 쓸 수 있는 것은 아니에요. 윈도우나 리눅스 같은 운영체제를 설치해야 비로소 쓸 수 있어요.

내 컴퓨터가 어떤 부품으로 이루어졌는지 보는 프로그램도 배웠어요. 윈도우는 CPU-Z나 Speccy, 맥은 MacCPUID예요. 읽는 법은 이래요.

부품읽는 법
CPU예 Intel Core i7-1360P. i3 < i5 < i7 순으로 등급이 올라가고, 뒤 숫자의 앞 두 자리(13)가 세대예요
코어와 스레드예 12코어 16스레드. 코어는 실제 계산 장치 수, 스레드는 동시에 처리할 수 있는 가상의 개수예요 (1-8에서 자세히)
RAM예 DDR5 16GB. DDR 뒤의 숫자(3, 4, 5…)가 세대, 16GB가 용량이에요
GPU그래픽 부분의 이름을 적으면 돼요
SSDCPU-Z에는 안 나와요. Speccy를 쓰거나 생략해도 돼요 (교수님 말)

모든 컴퓨터는 폰노이만 구조를 따르기 때문에 구성은 똑같고 사양만 달라요. 이 실습의 요지가 이 문장이에요.

시험엔 이렇게 써요

(서술형 요령) "내 컴퓨터의 주요 부품"을 쓸 때는 CPU(모델과 코어·스레드), RAM(종류와 용량), 메인보드, VGA(그래픽카드) 순으로 이름을 적고, 각 부품의 기능을 한 줄씩 덧붙여요.

잠깐 확인 — DDR5 16GB에서 5와 16은 각각 무엇을 뜻하나요?

5는 RAM의 세대(규격 버전), 16GB는 용량이에요.
