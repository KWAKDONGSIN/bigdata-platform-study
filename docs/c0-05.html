프로그램이 돌아가는 아주 큰 그림

이 사이트 전체가 사실 이 한 그림을 자세히 풀어 쓴 거예요. 먼저 아주 작은 파이썬 프로그램을 볼게요. 1부터 100까지 더하는 프로그램이에요.

sum = 0 for i in range(1, 101): sum += i print("1부터 100까지의 합은", sum, "입니다.")
코드 줄무슨 뜻인가요
sum = 0sum이라는 이름의 칸을 만들고 0을 넣어요
for i in range(1, 101):i가 1, 2, 3 … 100이 될 때까지 아래 줄을 반복해요 (101은 포함하지 않아요)
sum += isum에 i를 더해서 다시 sum에 넣어요 (sum = sum + i와 같아요)
print(...)화면에 결과를 출력해요

실행 결과(출력)

1부터 100까지의 합은 5050 입니다.

이 프로그램이 컴퓨터 안에서 거치는 길은 이래요.

  • 먼저 저장 : 코드를 파일(sum.py)로 만들어 SSD·HDD에 저장해 둬요. 이때는 "보관만 된" 상태예요.
  • ① 적재 : 실행하면 코드가 RAM으로 올라와요. 이것을 적재(load)라고 해요.
  • ② 한 줄씩 : RAM에 올라온 코드가 한 줄씩 CPU로 전달돼요.
  • ③ 기록 : CPU가 계산하고, 결과(sum, i 값)를 RAM에 기록해요. ②와 ③을 100번 반복해요.
  • ④ 출력과 종료 : 결과를 화면에 보여 주고, 프로그램이 끝나면 RAM의 코드와 중간 결과는 모두 지워져요. 교수님 표현으로 "방 빼라"예요.

한 가지 더 알아 둘 점이 있어요. 파이썬 같은 사람이 읽는 코드는 CPU가 바로 이해하지 못해요. CPU는 0과 1(기계어)만 알아들어서, 중간에 파이썬 인터프리터가 한 줄씩 기계어로 번역해서 CPU에 넘겨요. 이 번역 과정은 1장에서 자세히 다뤄요.

비유 — 시험공부

도서관(SSD)에는 책이 많이 보관돼 있어요. 공부하려는 책만 책상(RAM)으로 가져오고, 머리(CPU)로 한 줄씩 읽고 풀어서, 푼 내용을 책상 위 노트에 적어요. 공부가 끝나면 책상을 비우고, 답안지(모니터)에 쓴 결과만 남아요. 교수님도 시험 공부에 도서관, 책상, 노트를 빗대어 설명했어요.

외우기 팁

저장은 SSD, 실행은 RAM, 계산은 CPU. "보관 → 올림 → 계산 → 기록 → 출력" 순서로 말할 수 있으면 돼요.

시험엔 이렇게 써요

프로그램은 보조기억장치(SSD)에 저장되어 있다가 실행되면 주기억장치(RAM)에 적재되고, 명령어가 한 줄씩 CPU로 전달되어 실행되며, 그 결과가 다시 RAM에 기록된다.

잠깐 확인 — 프로그램이 끝나면 RAM에 있던 코드와 중간 결과는 어떻게 되나요?

모두 지워져요. RAM은 실행 중인 것만 잠깐 올려 두는 책상이라서, 오래 보관할 것은 SSD·HDD에 저장해야 해요.
