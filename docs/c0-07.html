이 장 3줄 요약
  • 컴퓨터는 프로그램을 실행해서 계산하는 기계이고, 하는 일은 입력·처리·저장·출력이에요. 계산기와 달리 프로그램을 바꿔 끼울 수 있어요.
  • 계산 부품이 전기 회로라서 전기가 있으면 1, 없으면 0으로 모든 정보를 표현하고, 소프트웨어는 운영체제와 응용 프로그램으로 나뉘어요.
  • 프로그램은 SSD에 저장 → 실행하면 RAM에 적재 → 한 줄씩 CPU가 계산 → 결과를 RAM에 기록 → 출력 순서로 돌아가요.
