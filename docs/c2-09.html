기출 4번 — 메모리 칸에 숫자와 글자 쓰기 ★★★

2023 기출 4번은 이 장의 내용을 한 번에 묻는 문제예요. 한 칸이 8비트(1바이트)인 메모리에 다섯 개 숫자 137, 7, 38, 77, 11과 글자 R, o, b, o, t를 01~10번 주소에 순서대로 쓰는 거예요. 푸는 순서는 두 단계예요.

  • 숫자 : 자리값 표(128 64 32 16 8 4 2 1)로 8비트 이진수를 만들어요 (2-2).
  • 글자 : ASCII 표에서 코드를 찾아 맨 앞에 0을 붙인 8비트로 써요 (2-7).
주소넣을 것변환 과정메모리(8비트)
01137128 + 8 + 11 0 0 0 1 0 0 1
0274 + 2 + 10 0 0 0 0 1 1 1
033832 + 4 + 20 0 1 0 0 1 1 0
047764 + 8 + 4 + 10 1 0 0 1 1 0 1
05118 + 2 + 10 0 0 0 1 0 1 1
06R열 101, 행 0010 → 820 1 0 1 0 0 1 0
07o열 110, 행 1111 → 1110 1 1 0 1 1 1 1
08b열 110, 행 0010 → 980 1 1 0 0 0 1 0
09o08번의 o와 같아요0 1 1 0 1 1 1 1
10t열 111, 행 0100 → 1160 1 1 1 0 1 0 0

배점은 칸 하나에 1점이에요. 실수가 많은 곳은 소문자 o의 코드를 두 번 쓰는 것과 앞의 0을 빼먹는 것이에요. 같은 글자는 같은 코드이고, 항상 8자리로 맞추세요.

시험엔 이렇게 써요

(이렇게 푸세요) 숫자는 자리값(128, 64, 32, 16, 8, 4, 2, 1)을 이용해 8비트 이진수로 바꾸고, 문자는 ASCII 변환표에서 열과 행의 비트를 이어 붙이고 앞에 0을 붙여 8비트로 쓴다. 각 칸이 정확히 8자리인지 마지막에 세어 확인하세요.

잠깐 확인 — 77을 8비트 이진수로 쓰면 무엇인가요?

01001101이에요. 77 = 64 + 8 + 4 + 1이라서 64, 8, 4, 1 자리에 1을 써요.
