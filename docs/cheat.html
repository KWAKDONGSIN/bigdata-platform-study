공식 · 숫자

항목값
비트·바이트·자릿값1바이트 = 8비트 (0~255, 256가지), 니블 = 4비트 = 16진수 한 자리. 1바이트 자릿값은 128 · 64 · 32 · 16 · 8 · 4 · 2 · 1 (큰 자릿값부터 들어가면 1, 아니면 0)
진법 변환10진 → R진은 R로 계속 나눠 나머지를 거꾸로 읽는다 (35 → 5진 120, 8진 43, 16진 23). R진 → 10진은 자리 숫자 × 자릿값을 모두 더한다 (1000 1001 = 128 + 8 + 1 = 137)
2진 ↔ 8진 · 16진2진수를 오른쪽부터 3비트씩 묶으면 8진수, 4비트씩 묶으면 16진수
2의 거듭제곱2^10 = 1024 = 1K, 2^20 = 1M, 2^30 = 1G(약 10억), 2^40 = 1T
ASCIIA = 65, a = 97, 0 = 48 (한 글자 1바이트). 예) R = 82, o = 111, b = 98, t = 116
유니코드 한글U+AC00 ~ U+D7A3, 총 11,172자
코드 기본원소 N개의 고정길이 코드는 log2 N을 올림한 비트 (25개 → 5비트). 짝수 패리티는 1의 개수가 짝수가 되게 비트를 붙이고, 홀수 패리티는 홀수로
8421 BCD·3초과BCD는 자리마다 4비트 (1225 → 0001 0010 0010 0101). 3초과는 각 자리에 3을 더한 코드
ALU 제어신호 CC7~C0 = + − x / & | >> << 순서. 덧셈 1000 0000, 곱셈 0010 0000
명령 실행 5단계인출 → 해독 → 실행 → 데이터 → 기록. 2칸 명령이면 PC는 2씩 증가 (4 → 6)
무어의 법칙·클럭집적도 24개월(2년)마다 2배. 3GHz = 초당 30억 번
접근 속도 표레지스터 <1ns · 캐시 0.5~2.5ns · RAM 50~70ns · SSD 20~200µs · HDD 5~20ms · CD-ROM 50~200ms
가상주소 계산가상주소 = 페이지번호 × 페이지크기 + 오프셋 (4KB = 4096B, 10,000 = 2 × 4096 + 1808)
디스크 액세스 시간탐색시간 + 회전지연시간 + 전송시간(+ 제어기 오버헤드). 평균 회전지연 = 반 바퀴 (7200rpm → 4.17ms, 10000rpm → 3ms)
2의 보수 (참고, 수업 자료 밖)비트를 모두 뒤집고 1을 더한다 (5 = 0000 0101 → −5 = 1111 1011)
