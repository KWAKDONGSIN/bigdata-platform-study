이 장 3줄 요약
  • HW2~HW4는 부품 6개의 기능, sum.py가 SSD → RAM → CPU로 실행되는 흐름, 진법·ASCII·ALU 제어신호, 게이트와 가산기(S는 1의 개수가 홀수, Cout은 2개 이상)를 복습해요.
  • HW5는 ADD R3 R1 R2의 5단계(PC 4 → 6, X 2 · Y 3, AC 5, 데이터 No action, R3 5)와 기계어 빈칸(CC = 1100 1100, CD = 1100 1101)이 핵심이에요.
  • HW6은 레지스터·캐시·RAM·보조기억장치 4층의 속도·용량 순서와 엑셀 예시, HW7은 TLB → 페이지 테이블(폴트면 스와핑) → 캐시 → 메모리 순서로 사건 번호를 쓰는 문제와 RAID·파티션·HDD·CD-ROM·SSD 빈칸이에요.
