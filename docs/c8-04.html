Q4. 십진수와 문자를 1바이트 이진수로 (10점)

8비트(=1바이트)가 1워드인 메모리가 있어요. 십진수 137, 7, 38, 77, 11과 문자 Robot의 다섯 글자를 1바이트 이진수로 바꿔 메모리 01~10번에 순서대로 써요. 문자는 ASCII 표를 봐요. 한 줄에 1점이에요.

풀이 방법 8칸의 자릿값은 왼쪽부터 128, 64, 32, 16, 8, 4, 2, 1이에요. 큰 자릿값부터 "들어가면 1, 안 들어가면 0"으로 채우면 돼요.

수쪼개기이진수 (8비트)
137128 + 8 + 11000 1001
74 + 2 + 10000 0111
3832 + 4 + 20010 0110
7764 + 8 + 4 + 10100 1101
118 + 2 + 10000 1011

문자는 먼저 ASCII 표에서 숫자를 찾고, 같은 방법으로 이진수로 바꿔요.

문자ASCII 숫자쪼개기이진수 (8비트)
R8264 + 16 + 20101 0010
o11164 + 32 + 8 + 4 + 2 + 10110 1111
b9864 + 32 + 20110 0010
o111위와 같음0110 1111

외우기 팁

ASCII 표가 없어도 대문자는 A=65, 소문자는 a=97에서 알파벳 순서를 더하면 돼요. R은 18번째 글자라 64 + 18 = 82, t는 20번째라 96 + 20 = 116이에요. 숫자 0은 48이에요.

올해 시험에서도 이렇게 쓰세요

시험지 여백에 "128 64 32 16 8 4 2 1"을 먼저 적고, 큰 자릿값부터 빼 가며 1을 표시하세요. 다 끝나면 1인 자릿값을 더해 원래 수가 되는지 검산하면 실수가 줄어요. 수업 슬라이드의 138, 5, 32, 27과 Data 문제도 같은 방법이에요.

잠깐 확인 — 십진수 11을 8비트 이진수로 쓰면?

0000 1011이에요. 8 + 2 + 1 = 11이에요.
