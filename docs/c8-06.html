Q6. 기계어와 ALU (10점)

고급언어 코드가 어셈블리어를 거쳐 기계어로 번역되고, 3번째 줄이 ALU에서 실행되는 그림이에요. 기계어 빈칸 ①~⑥(각 1점)과 ALU 입력값 4개(각 1점)를 써요.

6.1 풀이 요령 명령 한 줄은 16비트로, 4비트씩 네 덩어리예요. 맨 앞이 동작 코드(opcode)이고 뒤는 대상(operand)이에요. 그림에 이미 나온 줄에서 "사전"을 만들어 쓰면 돼요.

의미이진수어디서 알 수 있나요
MOVE10002번째 줄 MOVE R2 3, 5번째 줄 MOVE R4 5
ADD11003번째 줄 ADD R3 R1 R2
STORE10104번째 줄 STORE CC R3
LOAD10016번째 줄 LOAD R5 CC
MUL11017번째 줄 MUL R6 R4 R5
R1~R60001, 0010, 0011, 0100, 0101, 0110레지스터 번호를 이진수로
숫자 2, 3, 50000 0010, 0000 0011, 0000 01018비트 이진수
CC, CD1100 1100, 1100 11014번째 줄에서 CC를 읽고, CD는 CC 다음 번지(+1)
빈칸줄풀이정답
①2번째MOVE R2 3이라 1000, 0010 다음에 숫자 30000 0011
②1번째MOVE이므로 동작 코드1000
③5번째MOVE R4 5이므로 숫자 50000 0101
④6번째LOAD R5 CC이므로 주소 CC1100 1100
⑤8번째STORE이므로 동작 코드1010
⑥8번째STORE CD R6이므로 주소 CD1100 1101

참고로 4번째 줄 끝이 0101로 인쇄돼 있지만 R3은 0011이라 인쇄 오류로 보여요. 문제 답에는 영향이 없어요.

6.2 ALU 입력값 3번째 줄 ADD R3 R1 R2는 "R1과 R2를 더해 R3에 저장"이에요.

  • R1에는 1번째 줄에서 2가, R2에는 2번째 줄에서 3이 들어 있어요.
  • A는 2, B는 3이에요.
  • 제어신호 C는 +, -, x, /, &, |, >>, << 순서이고, 덧셈은 맨 앞(C7)이라 1000 0000이에요.
  • Y는 2 + 3 = 5예요.
입력8비트 값
A0000 0010
B0000 0011
C1000 0000
Y0000 0101

곱셈(x)이면 세 번째 자리라 C가 0010 0000이 돼요. 수업 슬라이드의 5 x 5 = 25 예시는 A=0000 0101, B=0000 0101, C=0010 0000, Y=0001 1001이에요.

올해 시험에서도 이렇게 쓰세요

기계어 빈칸은 "그림에 이미 나온 줄에서 opcode, 레지스터, 주소를 사전처럼 베껴 오는 문제"라고 쓰고 풀면 돼요. ALU 문제는 A, B에 두 레지스터 값, C에 연산 위치(덧셈은 1000 0000), Y에 계산 결과를 8비트로 적으세요.

잠깐 확인 — 제어신호 C로 뺄셈(-)을 고르면 C는?

0100 0000이에요. 순서가 +, -, x, / 이라 두 번째 자리가 1이에요.
