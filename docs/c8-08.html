Q8. 메모리 계층 구조 (11점)

메모리 4종류는 주기억장치(RAM, 1), 보조기억장치(SSD/HDD, 2), 레지스터(3), 캐쉬(4)예요. 8.1~8.3은 각 2점, 8.4는 5칸 각 1점이에요.

문제정답이유
8.1 CPU 안에 있는 메모리 2개3, 4레지스터와 캐쉬는 CPU 칩 안에 있어요. RAM은 CPU 밖 별도 부품이에요.
8.2 접근 속도가 빠른 순서3, 4, 1, 2레지스터 → 캐쉬 → RAM → SSD/HDD 순이에요.
8.3 같은 가격 대비 용량이 큰 순서2, 1, 4, 3빠를수록 비싸서 용량이 작아요. 속도 순서를 거꾸로 하면 돼요.

8.4 엑셀로 분기별 매출 평균을 계산하는 과정

상황정답이유
1) 엑셀 프로그램을 설치했다2 보조기억장치설치는 저장이라서 영구 보관되는 SSD/HDD에 해요.
2) 엑셀 아이콘을 눌러 실행했다1 주기억장치(RAM)실행하면 프로그램이 RAM에 올라와요.
3) 거래내역 파일을 불러왔다1 주기억장치(RAM)열린 파일의 데이터도 RAM에 올라와요.
4) 2020년 4분기 주변 데이터로 평균 계산4 캐쉬지금 계산하는 부분과 그 주변은 자주 쓸 가능성이 높아 캐쉬에 올라와요.
5) 170만과 220만을 직접 더하고 있다3 레지스터CPU(ALU)가 바로 계산하는 값은 레지스터에 있어요.
비유

교수님의 시험공부 비유예요. 보조기억장치는 내 컴퓨터 안의 모든 자료, RAM에는 중간고사 범위 1~7주차 PDF 전체, 캐쉬에는 지금 보고 있는 1주차 자료, 레지스터에는 지금 풀고 있는 한 문제의 숫자가 올라와요. 책상(레지스터)이 작을수록 손이 빨리 닿아요.

장치CPU와의 관계접근 속도
레지스터CPU 안1ns보다 빠름
캐쉬CPU 안0.5~2.5ns
RAMCPU 밖50~70ns
SSDCPU가 직접 접근 못 함20~200µs
하드디스크자기 디스크를 물리적으로 회전5~20ms
올해 시험에서도 이렇게 쓰세요

"빠를수록 작고 비싸다. 그래서 레지스터 → 캐쉬 → RAM → SSD/HDD 계층으로 쓴다"를 먼저 쓰세요. 순서 문제는 속도 순서를 써 놓고 용량 순서는 그 반대로 뒤집으면 돼요. 상황 문제는 "설치=보조기억장치, 실행·열기=RAM, 지금 계산하는 주변=캐쉬, 지금 계산하는 값=레지스터"로 구분하세요.

잠깐 확인 — CPU 안에 있는 메모리 두 가지는?

레지스터와 캐쉬예요. RAM은 CPU 밖에 따로 꽂혀 있어요.
