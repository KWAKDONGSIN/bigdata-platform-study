꼭 외울 25줄

  1. 폰노이만 구조는 계산장치(CPU)와 기억장치로 구성되어 계산장치가 기억장치의 프로그램을 한 줄씩 실행하고 결과를 기억장치에 기록하는 구조이다.
  2. 무어의 법칙은 집적회로의 반도체 집적도가 24개월(2년)마다 2배씩 증가한다는 법칙이다. 황의 법칙은 함정이다.
  3. 싱글코어는 CPU 안에 연산 장치가 1개, 멀티코어는 여러 개이다. 클럭이 높을수록 전력·발열이 늘어 온도가 올라가서 클럭을 무한정 높일 수 없다.
  4. 코드가 보조기억장치에 있으면 프로그램, 실행되어 메모리에 올라와 있으면 프로세스이다.
  5. 하나의 프로그램을 여러 프로세스로 병렬 실행하면 멀티 프로세싱(크롬 창 여러 개), 한 프로세스 안에서 여러 흐름으로 실행하면 멀티 쓰레딩(탭 여러 개)이다.
  6. 운영체제는 전원이 켜지면 가장 먼저 시작되어 컴퓨터 자원과 여러 응용 프로그램의 실행을 관리한다.
  7. 6대 부품은 메인보드(데이터 통로), CPU(대부분의 계산), 보조기억장치(비휘발성 반영구 보관), RAM(휘발성, 실행 중인 코드·데이터), GPU(행렬 연산 병렬 처리), 전원공급장치(교류를 직류로)이다.
  8. 휘발성은 전원이 꺼지면 데이터가 사라지는 성질이다. sum.py는 SSD에 있다가 실행되면 RAM에 적재되고 CPU가 한 줄씩 계산하며, 결과(변수 값)는 다시 RAM에 기록된다.
  9. AND는 모두 1일 때만 1, OR는 하나라도 1이면 1, NOT은 반대로, XOR는 같으면 0 다르면 1을 출력한다. (A, B)가 00, 01, 10, 11일 때 AND 0001, OR 0111, XOR 0110이다.
  10. 반가산기는 비트 두 개를 더해 합 S(XOR)와 올림 Cout(AND)을 내고, 전가산기는 아랫자리 올림 Cin까지 세 개를 더한다. 8비트 덧셈기는 전가산기 8개를 이어 i번의 Cout을 i+1번의 Cin에 연결하고 맨 아래 Cin은 0이다.
  11. CPU의 필수 구성 요소는 ALU(계산), 제어장치 CU(명령 해독·제어신호), 레지스터 세트(CPU 안의 작고 빠른 메모리)이다.
  12. 레지스터는 PC(다음 명령 주소), IR(현재 명령), MAR(메모리 주소), MBR(메모리에서 읽은 값), AC(계산 결과)이다.
  13. 기계어는 연산 종류인 opcode와 대상인 operand로 되어 있다. ADD R3 R1 R2에서 ADD가 opcode, R3·R1·R2가 operand이다.
  14. 명령 한 줄은 인출(fetch) → 해독(decode) → 실행(execute) → 데이터(data) → 기록(write back) 5단계로 실행된다.
  15. ADD 같은 계산 명령은 데이터 단계가 No action(1-2-3-5)이고, LOAD·STORE 같은 메모리 접근 명령은 실행 단계가 No action(1-2-4-5)이다.
  16. 인출 단계에서는 PC의 주소를 MAR에 넣고 메모리에서 읽은 명령을 MBR을 거쳐 IR에 가져오며 PC는 다음 명령 주소로 바뀐다. PC가 4이고 명령이 2칸이면 MAR은 4, PC는 6이다.
  17. 메모리 계층은 레지스터 → 캐시 → RAM → SSD/HDD 순으로 빠르고, 위로 갈수록 용량이 작고 비싸다. CPU 안의 메모리는 레지스터와 캐시이다.
  18. SRAM은 빠르고 비싸서 캐시에, DRAM은 싸고 집적도가 높아 RAM에 쓴다. 필요한 데이터가 캐시에 있으면 히트, 없으면 미스이다.
  19. 레이턴시는 데이터에 접근하는 데 걸리는 시간(낮을수록 빠름)이고, 대역폭은 단위 시간당 전송되는 데이터 양이다. 둘은 다른 개념이다.
  20. 가상메모리는 실제 메모리 크기와 관계없이 프로세스에 큰 공간을 주는 기술이고, 가상메모리는 페이지, 물리메모리는 같은 크기의 프레임으로 나눈다. 주소 변환은 페이지 번호만 프레임 번호로 바꾸고 오프셋은 그대로이다.
  21. 프로세스가 쓰는 메모리가 물리메모리(RAM)를 넘으면 일부가 보조기억장치의 스왑 영역으로 이동하는데 이것이 스와핑이고 컴퓨터가 느려진다. 코드를 안 고치고 40GB 렉을 해결하려면 RAM을 늘린다.
  22. 주소 변환은 TLB → 페이지 테이블 → (필요하면 스왑) → 캐시 순이다. TLB 히트면 물리주소를 바로 얻고, 미스면 페이지 테이블을 찾는다.
  23. 페이지가 RAM에 없으면 페이지 폴트가 나서 운영체제가 스왑 영역의 페이지를 RAM에 올리고 페이지 테이블과 TLB를 갱신한다. TLB 미스가 곧 페이지 폴트는 아니다.
  24. HDD는 자기적, CD-ROM은 광학적, SSD는 전자적 성질을 이용한다.
  25. SSD는 HDD보다 빠르지만 같은 용량에 비싸서 운영체제는 SSD에, 동영상·사진은 HDD에 둔다. 여러 디스크를 하나로 묶는 것이 RAID, 하나를 나눠 쓰는 것이 파티션이다.

순서 3개는 통째로

1. CPU 명령 5단계 (Q7, 교수님 지시)

인출 → 해독 → 실행 → 데이터 → 기록

외우기 요령은 앞글자 인해실데기입니다. 계산 명령은 데이터를 건너뛰고(1-2-3-5), 메모리 명령은 실행을 건너뜁니다(1-2-4-5).

2. 주소 변환 과정 (빈칸으로 나온다고 교수님이 말함)

TLB → 페이지 테이블 → (페이지 폴트면 스왑에서 RAM으로) → 캐시 → (미스면) 메모리

외우기 요령은 티-페-스-캐입니다. TLB에 없으면 페이지 테이블, RAM에 없으면 스왑, 물리주소를 얻은 뒤에 캐시입니다.

3. 프로그램 실행 과정 (Q3)

보조기억장치(SSD) → 주기억장치(RAM) 적재 → CPU가 한 줄씩 계산 → 결과를 RAM에 기록

외우기 요령은 보 → 주 → C → 기입니다. 빈칸 A는 보조기억장치, B는 주기억장치, C는 CPU입니다.

계산은 이 요령만

1. 십진수 → 8비트 이진수 (Q4)

여백에 자릿값 128 64 32 16 8 4 2 1을 먼저 쓰고, 큰 것부터 들어가면 1 아니면 0을 쓴 뒤 남은 수로 다음 자리를 봅니다. 마지막에 더해서 검산합니다. 문자는 ASCII 표에서 번호(A=65, a=97)를 찾아 같은 방법으로 바꿉니다.

예

137 = 128 + 8 + 1이라 1000 1001입니다. 77 = 64 + 8 + 4 + 1이라 0100 1101입니다.

2. 전가산기로 덧셈 (Q5)

오른쪽 자리부터 한 자리씩 A, B, 올림 Cin 세 개에서 1의 개수를 셉니다. 1이 1개면 S=1에 올림 0, 2개면 S=0에 올림 1, 3개면 S=1에 올림 1입니다. 올림은 왼쪽 자리로 넘기고 맨 아래 Cin은 0입니다.

예

0000 0111 + 0000 0101은 0번 자리 S=0 올림 1, 1번 자리 S=0 올림 1, 2번 자리 S=1 올림 1, 3번 자리 S=1이라 0000 1100(= 12)입니다.

3. ALU 입력값 A, B, C, Y (Q6)

레지스터에 든 값을 그림에서 찾아 8비트 이진수로 A, B에 씁니다. 제어신호 C는 + − x / & | >> << 순서에서 해당 연산 자리만 1입니다(덧셈 1000 0000). Y는 계산 결과를 이진수로 씁니다.

예

ADD R3 R1 R2에서 R1=2, R2=3이면 A=0000 0010, B=0000 0011, C=1000 0000, Y=0000 0101(= 5)입니다.
