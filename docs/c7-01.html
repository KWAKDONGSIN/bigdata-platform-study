HW2W 컴퓨터 구조 — 부품 6개와 sum.py

Q1 요지 : 컴퓨터 내부 사진의 부품 ①~⑥의 이름과 기능을 설명하라.

풀이 : 사진에서 위쪽 칸의 네모(①)는 전원공급장치, 쿨러(방열팬) 밑의 부품(②)은 CPU, 아래쪽 판(③)은 그래픽카드, 초록색 큰 테두리(④)는 이 모든 부품이 꽂히는 판인 메인보드, 길쭉한 막대(⑤)는 RAM, 오른쪽 상자(⑥)는 SSD예요.

번호이름기능
①전원공급장치교류 전류를 직류 전류로 바꿔서 컴퓨터에 전원을 공급해요
②CPU컴퓨터의 거의 모든 계산을 담당해요
③그래픽카드(GPU)이미지 처리, 딥러닝 학습 같은 행렬 기반 연산을 병렬로 빠르게 해요
④메인보드부품끼리 데이터가 오가는 통로 역할을 해요
⑤RAM휘발성 기억장치로, 수행 중인 프로그램 코드와 데이터를 보관해요
⑥SSD (보조기억장치)비휘발성 기억장치로, 전원이 꺼져도 데이터를 반영구 보관해요

2023년 기출 Q2도 같은 그림이에요. 기능 문장 여섯 개에 부품을 연결하는 문제인데 위 표의 "기능" 열이 그대로 출제됐어요.

Q2 요지 : SSD의 c:\a에 sum.py가 저장돼 있다. 이 코드를 실행할 때 CPU, RAM, SSD 사이에서 일어나는 일을 설명하라.

sum = 0 for i in range(1, 101): sum += i print("1부터 100까지의 합은", sum, "입니다.")
코드 줄무슨 뜻
sum = 0sum 상자에 0을 넣어요.
for i in range(1, 101):i를 1부터 100까지 하나씩 바꿔 가며 아래 줄을 반복해요 (range(1, 101)은 1~100).
sum += isum에 i를 더해요 (sum = sum + i와 같아요).
print(...)문장과 sum 값을 화면에 출력해요.

실행 결과는 1부터 100까지의 합은 5050 입니다. 한 줄이에요. 1+2+...+100 = 5050이에요.

풀이 (폰 노이만 구조대로 4단계)

  • ① 적재 : 실행하면 운영체제가 SSD(c:\a)에 있던 python 실행기와 sum.py를 RAM에 올려요(프로세스가 돼요).
  • ② 번역 : python 실행기가 sum.py를 한 줄씩 읽어 기계어로 바꿔요.
  • ③ 실행 : 기계어 명령이 RAM에서 CPU로 한 줄씩 가요. CPU의 제어장치가 해독하고 ALU가 더하기를 계산해요.
  • ④ 기록 : sum, i 같은 변수의 값은 RAM의 변수 공간에 계속 갱신되고, 반복이 끝나면 결과를 화면에 출력해요.

Q3 요지 : 내 컴퓨터의 CPU, RAM, 메인보드, 그래픽카드 사양을 조사해 적어라. 이건 사람마다 답이 달라서 풀이는 없어요. 윈도우는 CPUID 프로그램으로 확인하고, CPU는 이름·코어·스레드·클럭, RAM은 용량, 그래픽카드는 이름과 메모리를 적어요. 시험에는 나오지 않아요.

시험엔 이렇게 써요

프로그램을 실행하면 보조기억장치(SSD)에 있던 실행기와 코드가 주기억장치(RAM)에 적재되고, CPU가 RAM의 명령을 한 줄씩 가져와 계산하며, 계산 결과와 변수 값은 RAM에 기록된다. 메인보드는 컴퓨터 부품 간 데이터가 전송되는 통로 기능을 한다.

잠깐 확인 — "비휘발성이며 전원이 꺼져도 반영구 보관"과 "휘발성이며 실행 중인 프로그램과 데이터 보관"은 각각 어느 부품인가요?

앞의 것은 보조기억장치(SSD/HDD), 뒤의 것은 RAM이에요.
