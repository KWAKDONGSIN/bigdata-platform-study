이 장 3줄 요약
  • CPU는 ALU(계산) + CU(제어) + 레지스터(PC, IR, AC, MAR, MBR 등)로 이루어지고, 프로그램은 보조기억장치 → RAM → CPU 순서로 한 줄씩 실행돼요.
  • 명령은 opcode + operand이고, 한 줄은 인출-해독-실행-데이터-기록 5단계로 실행돼요(계산은 1-2-3-5, 메모리는 1-2-4-5). 겹쳐 하면 파이프라인이에요.
  • 클럭을 높이면 발열(온도)이 늘어 한계가 있어서 멀티코어로 갔고, 병렬 처리는 멀티프로세싱(창)과 멀티쓰레딩(탭)으로 나뉘어요.
