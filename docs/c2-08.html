패리티 비트와 유니코드

패리티 비트(parity bit)는 데이터가 올바른지 검사하려고 덧붙이는 비트 1개예요.

  • 짝수 패리티(even) : 전체에서 1의 개수가 짝수가 되도록 붙이는 비트예요.
  • 홀수 패리티(odd) : 전체에서 1의 개수가 홀수가 되도록 붙이는 비트예요.

예제 2-13의 A와 T를 풀어 볼게요. 먼저 ASCII의 7비트에서 1이 몇 개인지 세요.

글자ASCII 7비트1의 개수짝수 패리티 비트홀수 패리티 비트
A10000012개 (짝수)0 (이미 짝수)1 (홀수로 만듦)
T10101003개 (홀수)1 (짝수로 만듦)0 (이미 홀수)

왜 붙일까요? 데이터를 주고받다가 비트 하나가 바뀌면 1의 개수의 짝홀이 규칙과 달라져서 오류를 알아챌 수 있기 때문이에요.

ASCII는 영어에 최적화돼 있어서 한글은 못 담아요. 그래서 전 세계 글자를 담는 유니코드(Unicode)가 만들어졌어요.

  • 국제적으로 통용되는 16비트 문자 체계예요. 1991년에 1.0 버전이 나왔어요.
  • U+0000 ~ U+007F 영역은 영문자(ASCII와 같은 칸)이고, 그 뒤로 여러 나라 글자가 이어져요.
  • 한글은 U+AC00부터 U+D7A3까지 11,172자예요. 자음·모음만이 아니라 조합된 글자 하나하나가 모두 자기 번호를 가져요.
print(hex(ord("홍"))) print(ord("홍")) print(chr(0xD64D))
코드 줄무슨 뜻인가요
print(hex(ord("홍")))"홍"의 유니코드 번호를 16진수로 보여 줘요
print(ord("홍"))같은 번호를 10진수로 보여 줘요
print(chr(0xD64D))16진수 D64D 번호의 글자를 찾아요

실행 결과(출력)

0xd64d 54861 홍

그래서 예제 2-14 "홍길동"의 유니코드는 홍 = U+D64D, 길 = U+AE38, 동 = U+B3D9예요.

교수님이 덧붙인 주의점이 있어요. 한글은 저장 방식(인코딩)이 여러 개예요. UTF-16은 한글 한 글자가 2바이트이고 UTF-8은 3바이트예요.

쓸 때와 읽을 때의 방식이 다르면 글자가 깨져요. 그래서 변수 이름과 코드는 영어로 쓰라고 권했어요.

시험엔 이렇게 써요

패리티 비트는 데이터가 올바른지 검사하기 위해 추가하는 비트로, 짝수 패리티는 1의 개수가 짝수가 되도록, 홀수 패리티는 홀수가 되도록 붙인다. 유니코드는 세계 각국의 언어를 표현하는 국제 문자 체계이며 한글은 U+AC00부터 U+D7A3까지 11,172자가 정의되어 있다.

잠깐 확인 — 7비트 1010100(T)에 짝수 패리티 비트를 붙이면 몇이 되나요?

1이에요. 1이 3개(홀수)라서 하나를 더 붙여야 총 4개(짝수)가 돼요.
