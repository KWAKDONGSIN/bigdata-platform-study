CPU를 나눠 쓰는 법 — 멀티태스킹, 멀티프로세싱, 멀티쓰레딩 ★★

요즘 컴퓨터는 크롬, 파워포인트, 게임을 한꺼번에 켜 놔요. 이것을 가능하게 하는 용어가 여러 개라 헷갈려요. 7주차에 교수님이 정리한 것을 표로 모았어요.

용어뜻비유
일괄 처리초창기 방식. 한 번에 작업을 1개만 처리해요한 줄짜리 계산대
시분할
time sharing		CPU 시간을 아주 잘게 쪼개 여러 프로세스가 번갈아 써요. 사람 눈에는 동시에 도는 것처럼 보여요 (번갈아 바꾸는 일을 컨텍스트 스위치라고 해요)선생님 한 명이 학생 여러 명을 1분씩 돌아가며 지도
멀티태스킹여러 프로그램이 동시에 실행되는 것처럼 보이게 하는 기술. 싱글코어 시절에는 시분할로 만들었어요한 사람이 설거지·빨래·요리를 번갈아
멀티프로세싱하나의 일을 여러 개의 프로세스로 나눠 병렬 실행해요. 크롬 창을 여러 개 띄우는 것과 같아요가게를 여러 개 차림
멀티쓰레딩
multi-threading		프로세스는 하나만 띄우고, 그 안에서 여러 흐름(스레드)으로 병렬 실행해요. 크롬 한 창 안의 탭들과 같아요한 가게 안에서 직원 여러 명
멀티프로그래밍여러 프로그램을 동시에 RAM에 올려, 한 프로그램이 입출력으로 쉴 때 CPU가 다른 프로그램을 처리하게 해요―

빅데이터 처리에서 중요한 이유가 있어요. 40시간 걸리는 큰 작업을 10조각으로 나눠 동시에 돌리면(병렬 처리) 이론상 4시간이면 끝나요. 교수님은 파이썬은 멀티쓰레딩 병렬을 잘 지원하지 않아서 병렬 처리에 보통 멀티프로세싱을 쓴다고 했어요. 멀티태스킹과 멀티프로그래밍은 "안 써도 될 것 같다"고 했어요.

2023년 기출 Q1은 이 장의 용어 총정리예요. 답을 이렇게 외우세요.

번호답설명 문장 (기출)
1.1폰노이만 구조계산장치가 기억장치의 프로그램을 한 줄씩 실행해 결과를 기억장치에 기록하는 구조
1.2무어의 법칙집적도가 2년마다 2배
1.3, 1.4싱글코어, 멀티코어연산 장치가 1개 / 여러 개
1.5온도클럭이 높을수록 전력·발열이 늘어 상승
1.6, 1.7프로그램, 프로세스보조기억장치에 있으면 프로그램, 실행되어 메모리에 적재되면 프로세스 (5장)
1.8멀티 프로세싱하나의 프로그램을 여러 개의 프로세스로 병렬 실행
1.9멀티 쓰레딩하나의 프로세스 안에 여러 흐름으로 병렬 실행
1.10운영체제전원이 켜지면 가장 먼저 시작되며 자원과 응용 프로그램 실행을 관리 (5장)

보기에 있던 오버클럭, 황의 법칙, 집적도, 코어, 멀티태스킹, 멀티프로그래밍은 위 설명에 맞지 않아서 답이 아니에요(함정 보기).

시험엔 이렇게 써요

멀티 프로세싱은 하나의 프로그램을 여러 개의 프로세스로 나누어 병렬 실행하는 것이고, 멀티 쓰레딩은 하나의 프로세스 안에서 여러 흐름(스레드)으로 병렬 실행하는 것이다. 멀티태스킹은 여러 프로그램이 동시에 실행되는 것처럼 보이게 하는 기술로, 싱글코어에서는 CPU 시간을 쪼개 번갈아 쓰는 시분할 방식으로 구현되었다.

잠깐 확인 — 크롬 창을 2개 띄운 것과 한 창에 탭을 2개 연 것 중 멀티프로세싱은 어느 쪽인가요?

창을 2개 띄운 쪽이에요(프로세스가 2개). 탭은 한 프로세스 안의 스레드라서 멀티쓰레딩이에요.
