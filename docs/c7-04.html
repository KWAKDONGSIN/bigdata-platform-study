HW5W 중앙처리장치 — 인출부터 기록까지 ★★★

Q1~Q5 요지 : 메모리 0번 주소부터 프로그램이 시작되고 현재 PC가 4이다. 인출, 해독, 실행, 데이터, 기록 각 단계에서 데이터의 흐름을 그리고 설명하라. 메모리에는 00번지 MOVE R1 2, 02번지 MOVE R2 3, 04번지 ADD R3 R1 R2, 06번지 STORE CC R3이 들어 있어요. 현재 실행하는 명령은 04번지의 ADD R3 R1 R2이고, R1=2, R2=3이에요.

Q단계그림에 그릴 흐름과 설명
Q1인출PC의 4가 MAR로 가요(MAR ← 4). CU가 제어신호 Read를 내고, 4번지의 ADD R3 R1 R2가 메모리에서 MBR을 거쳐 IR로 가요. PC는 다음 명령 번지인 6으로 바뀌어요(PC ← 6).
Q2해독제어장치(CU)가 IR의 명령을 해독해요. R1의 값 2는 X로, R2의 값 3은 Y로 들어가고 ALU 제어신호는 더하기(+)로 정해져요.
Q3실행ALU가 X와 Y를 받아 2 + 3 = 5를 계산하고 결과를 AC에 담아요(AC ← 5).
Q4데이터ADD는 메모리를 쓰지 않는 레지스터 계산 명령이라 No action이에요.
Q5기록AC의 5를 목적 레지스터 R3에 기록해요(R3 ← 5).

그림을 그릴 때는 4장의 CPU 내부 그림을 기준으로, 단계마다 "값이 지나가는 길"을 굵은 화살표로 칠하고 상자 옆에 값(4, 6, 5 같은)을 적으면 돼요. 설명은 위 표의 문장을 그대로 쓰면 돼요. 이 흐름은 기출 Q7에서 (R1, R2가 5, 7이라서 결과가 12인 것만 다르게) 그대로 나왔어요.

Q6 요지 : 어셈블리어와 기계어가 1대1 대응된다고 할 때 빈칸 ①~⑤의 값은? 빈칸 위치는 이래요.

어셈블리어기계어 (빈칸 포함)
MOVE R1 21000 0001 ① (8비트)
MOVE R2 3② (4비트) 0010 0000 0011
STORE CC R31010 ③ (8비트) 0011
STORE CD R6④ (4비트) ⑤ (8비트) 0110
빈칸답이유
①0000 0010숫자 2를 8비트로 (MOVE R1 2의 마지막 칸)
②1000MOVE의 opcode
③1100 1100번지 CC. 16진수 C = 1100 이라서 CC = 1100 1100
④1010STORE의 opcode (위의 STORE CC R3과 같아요)
⑤1100 1101번지 CD. 16진수 D = 1101 이라서 CD = 1100 1101

과제 그림의 LOAD R5 CC 줄은 기계어가 1001 1010 1010 1010으로 적혀 있어서, 규칙(R5=0101)과 맞지 않아요. 그 줄 값으로 CC를 읽으면 ③이 1010 1010이 될 수도 있지만, 교수님은 16진수 CC = 1100 1100으로 설명했고 2023 기출 정답도 같아요. 그래서 위 표를 답으로 쓰세요.

시험엔 이렇게 써요

ADD R3 R1 R2 실행 시 인출 단계에서 PC(4)를 MAR로 보내 메모리의 명령을 MBR을 거쳐 IR로 가져오고 PC를 6으로 바꾼다. 해독 단계에서 제어장치가 명령을 해독해 X, Y에 값을 넣고 제어신호를 +로 정한다. 실행 단계에서 ALU가 계산하여 결과를 AC에 저장하고, 데이터 단계는 메모리를 사용하지 않으므로 동작이 없으며, 기록 단계에서 AC의 값을 R3에 기록한다.

잠깐 확인 — STORE 명령에서는 5단계 중 어느 두 단계가 "No action"인가요?

실행(3단계)과 기록(5단계)이에요. 메모리에 쓰는 일은 데이터(4단계)에서 해요.
