CPU 안에는 무엇이 있을까 — ALU, 제어장치, 레지스터 ★★★

CPU는 반드시 있어야 하는 부품 3가지와, 성능을 높이려고 덧붙인 부품 1가지로 이루어져요. 필수 3가지는 산술논리연산장치(ALU), 제어장치(CU), 레지스터 세트예요.

부품하는 일비유
ALU
Arithmetic Logic Unit
산술논리연산장치		덧셈·뺄셈 같은 산술 연산과 AND·OR 같은 논리 연산 등 기본 연산을 해요.계산기
CU
Control Unit, 제어장치		메모리에서 가져온 명령을 해독(decode)하고, 각 장치가 움직이도록 제어신호를 보내요.오케스트라 지휘자
레지스터 세트
register set		CPU 안에 있는, 용량은 작지만 매우 빠른 메모리예요. 범용 레지스터와 특수 레지스터로 나뉘어요.손에 든 메모지
캐시 (확장 부품)자주 쓰는 데이터를 임시로 보관해서 메모리까지 가는 시간을 줄여요. L1, L2, L3 단계가 있어요. (5장에서 자세히)책상 위 참고서

CPU 내부 구조 단순화. 실선 화살표는 값이 이동하는 길, 점선은 CU가 보내는 제어신호예요. 강의자료 8쪽 그림을 단순화했어요.

레지스터는 쓰임새에 따라 두 종류로 나눠요. 범용 레지스터는 R1, R2처럼 ALU 계산에 쓰는 데이터를 담는 보통 1~32개의 레지스터예요. 특수 레지스터는 정해진 한 가지 일만 하는 레지스터예요. 슬라이드에 나온 특수 레지스터는 PC, IR, AC, MAR, MBR 다섯 개예요.

이름뜻비유
PC
Program Counter		다음에 가져올 명령이 메모리 몇 번지에 있는지 적어 둬요.책갈피 (다음에 읽을 쪽)
IR
Instruction Register		지금 실행하려고 가져온 명령 한 줄을 담아요.지금 읽는 문장
AC
ACcumulator, 누산기		ALU 계산 결과를 잠깐 담아요.계산기 화면
MAR
Memory Address Register		메모리의 몇 번지를 읽거나 쓸지 번호를 적어 둬요.도서관 청구기호 쪽지
MBR
Memory Buffer Register
(MDR이라고도 해요)		메모리에서 읽어 온 값, 또는 메모리에 쓸 값을 잠깐 담아요.카운터에서 받은 책을 놓는 쟁반

그림의 X, Y는 ALU 입구에 있는 작은 레지스터예요. 계산할 두 값이 X와 Y로 들어가고, 결과는 AC로 나와요.

비유 — 교수님의 시험공부

SSD는 도서관, RAM은 책장, 캐시는 책상, 레지스터는 책상 위에서 필기하는 노트, ALU는 두뇌예요. 도서관에서 필요한 책만 빌려 책장에 꽂고, 지금 볼 책은 책상에 펴고, 계산하는 숫자는 노트에 적는 식이에요.

왜 레지스터와 캐시를 따로 둘까요? ALU는 1초에 수십억 번 계산하는데 RAM이나 SSD는 그 속도로 데이터를 못 대 줘요. 그래서 CPU 가까이에 작고 빠른 메모리를 층층이 둬서 ALU가 기다리지 않게 해요. 속도는 레지스터 > L1 > L2 > L3 > RAM > 디스크 순이고, 용량은 반대 순서예요.

시험엔 이렇게 써요

CPU의 필수 구성 요소는 산술논리연산장치(ALU), 제어장치(CU), 레지스터 세트이다. ALU는 산술·논리 연산을 수행하고, 제어장치는 명령어를 해독하여 제어신호를 발생시키며, 레지스터는 CPU 내부에 있는 용량은 작지만 매우 빠른 메모리이다. 특수 레지스터에는 PC(다음 명령의 주소), IR(현재 명령), AC(누산기), MAR(메모리 주소), MBR(메모리 버퍼)이 있다.

잠깐 확인 — 다음에 실행할 명령이 메모리 몇 번지에 있는지 기억하는 레지스터는?

PC(프로그램 카운터)예요. 책갈피처럼 "다음에 읽을 번지"를 가리켜요.
