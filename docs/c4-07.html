CPU 성능 — 집적도, 클럭, 온도, 전력, 멀티코어 ★★

CPU의 성능 특성은 네 가지로 말해요. 자료 49쪽에 나오는 그대로예요.

요소무엇을 보나
집적도얼마나 많은 반도체(트랜지스터)가 들어 있나. 무어의 법칙 : 24개월(2년)마다 2배
클럭수얼마나 빨리 단일 연산이 수행되나. 3GHz는 초당 30억 번이에요
온도열이 적게 나는가
전력전력을 얼마나 적게 쓰는가

무어의 법칙은 인텔 공동 창업자 고든 무어가 말한 "집적회로의 반도체 집적도가 2년마다 2배가 된다"는 경험 법칙이에요. 1970년대부터 2000년대 초반까지 잘 맞았어요. 메모리에 대한 비슷한 법칙을 황의 법칙이라고 해요.

손계산 요령: 2년에 2배라서 4년이면 2×2=4배, 6년이면 8배, 10년이면 25 = 32배예요. (년수 ÷ 2번 2를 곱해요.)

클럭은 CPU가 "딱, 딱" 하고 박자를 맞추는 횟수예요. 클럭이 높을수록 빠르지만, 전력 소모와 발열이 늘어서 CPU 온도가 올라가요. 온도가 너무 높으면(보통 100도 이하에서 동작) 회로가 상해요. 그래서 클럭을 무한정 높일 수 없어요. 3GHz CPU의 박자 한 번은 1 ÷ 30억 초 = 약 0.33나노초예요.

그래서 2000년대 초에 "클럭 전쟁"이 끝나고 멀티코어 시대로 넘어갔어요. 클럭을 올리는 대신 일꾼 수를 늘린 거예요.

용어뜻
싱글코어하나의 CPU 안에 연산 장치(코어)가 1개
멀티코어하나의 CPU 안에 연산 장치(코어)가 여러 개 (듀얼, 쿼드, 옥타...). 요즘은 싱글코어가 없어요
하이퍼스레딩파이프라인을 이용해 물리 코어 하나가 2배의 일을 병렬로 처리해서 코어를 가상으로 늘리는 기법

CPU 사양 읽기 예시예요. "1.8GHz, 4코어 8스레드"는 클럭 1.8GHz로 동작하고, 물리적인 연산 장치(코어)는 4개이며, 하이퍼스레딩으로 8개 코어가 하는 계산을 처리할 수 있다는 뜻이에요.

비유 — 주방 확장

요리사 한 명의 손을 더 빠르게 하는 데는 한계가 있어요(클럭). 그래서 요리사를 4명으로 늘렸어요(멀티코어). 하이퍼스레딩은 요리사 한 명이 가스레인지 두 곳을 번갈아 돌보며 2인분 일을 하는 거예요.

시험엔 이렇게 써요

무어의 법칙은 집적회로의 반도체 집적도가 24개월(2년)마다 2배씩 증가한다는 법칙이다. CPU 클럭이 높아질수록 전력 소모와 발열이 증가하여 CPU의 온도가 상승하며, 이는 클럭을 무한정 높일 수 없게 하는 주요 요인이다. 싱글코어는 하나의 CPU 안에 연산 장치가 1개인 것이고 멀티코어는 여러 개인 것이다.

잠깐 확인 — CPU 클럭을 계속 높이지 못하는 가장 큰 이유는?

클럭이 높을수록 전력 소모와 발열이 늘어 온도가 올라가기 때문이에요. 그래서 코어 수를 늘리는 멀티코어로 방향을 바꿨어요.
