가상메모리와 스왑 (기출 Q9)

기출 9번이 40GB 파일을 16GB RAM으로 읽다가 컴퓨터가 멈추는 문제였어요. 빈칸 A~E와 해결책이 한 흐름이니 그 흐름을 통째로 외우세요.

① 빈칸 채우기 문장을 읽고 ____에 들어갈 말을 먼저 말하거나 써 본 뒤 눌러서 맞춰 보세요.

1) 프로세스에게 실제 메모리 크기를 신경 쓰지 않아도 되는 큰 메모리 공간을 제공하는 기술을 ____메모리라고 하며, 실제 관리는 ____가 한다.

가상, 운영체제예요. 호텔 투숙객은 방 번호만 알고 실제 방 배정은 직원이 하는 것과 같아요. (기출 Q9.1 A)

2) 운영체제는 가상메모리에 올린 데이터를 실제 RAM인 ____메모리에 할당하려고 한다.

물리예요. 프로세스가 보는 것은 가상, 실제 RAM은 물리메모리예요. (기출 Q9.1 B)

3) 물리메모리가 모자라면 일부 데이터가 ____(SSD/HDD)의 ____메모리(스왑 영역)로 옮겨진다.

보조기억장치, 스왑이에요. 쫓겨난 메모리를 모아 두는 저장장치의 특별한 공간이에요. (기출 Q9.1 C, D)

4) 메모리와 스왑 영역 사이에서 내용을 옮기는 과정을 ____이라고 한다.

스와핑이에요. (기출 Q9.1 E)

5) 스와핑이 자주 일어나면 RAM보다 훨씬 느린 ____를 계속 쓰게 되어 컴퓨터가 느려진다.

보조기억장치예요. RAM은 50~70ns, HDD는 5~20ms라서 차이가 아주 커요.

6) 코드를 고치지 않고 40GB 파일 때문에 생긴 렉을 해결하려면 CPU, RAM, HDD 중 ____를 40GB보다 크게 업그레이드해야 한다.

RAM이에요. CPU는 8코어로 충분하고 HDD는 1TB라 용량이 충분해요. 병목은 RAM이 데이터보다 작다는 것이에요. (기출 Q9.2)

7) 가상메모리를 같은 크기로 나눈 블록을 ____, 물리메모리(RAM)를 나눈 블록을 ____이라고 한다.

페이지, 프레임이에요. 두 블록의 크기는 같고, 그 크기가 페이지 크기예요(예 4KB = 4,096바이트).

8) 가상주소 = 페이지 번호 × ____ + ____ 이다.

페이지 크기, 오프셋(페이지 안의 위치)이에요.

9) 주소를 변환할 때 바뀌는 것은 페이지 번호에서 ____ 번호로의 대응뿐이고, ____은 그대로 유지된다.

프레임, 오프셋이에요. 페이지와 프레임의 크기가 같아서 블록 안의 위치는 변하지 않아요.

10) 최대 절전 모드는 전원을 끊기 전에 RAM 내용을 통째로 ____에 옮겨 두는 것인데, RAM이 ____성이기 때문이다.

스왑 영역, 휘발이에요. 다시 켜면 불러와서 이어서 해요.

② 순서대로 써 보기 기출 Q9에서 컴퓨터가 렉이 걸리는 흐름을 순서대로 써 보세요.

  • 가) 넘치는 부분이 보조기억장치의 스왑 영역으로 옮겨진다 (스와핑)
  • 나) 40GB 데이터가 프로세스의 가상메모리에 올라온다
  • 다) 느린 보조기억장치를 계속 쓰게 되어 컴퓨터가 거의 멈춘다
  • 라) 운영체제가 물리메모리(16GB)에 할당하려는데 용량이 모자라다
순서대로 써 보기 — 답 열기

나 → 라 → 가 → 다

가상메모리에 올림 → 물리메모리 할당 시도(모자람) → 스왑으로 쫓겨남(스와핑) → 느려짐이에요. 해결은 RAM 늘리기예요.

③ 계산 페이지 크기가 4,096바이트일 때 가상주소 8,300의 페이지 번호와 오프셋을 구해 보세요.

단계 풀이 보기 (종이에 먼저 풀어 본 뒤 열기)

8,300 ÷ 4,096을 해요. 몫이 2이고 2 × 4,096 = 8,192예요.

나머지는 8,300 − 8,192 = 108이에요.

페이지 번호 2, 오프셋 108이에요.

시험엔 이렇게 써요

가상메모리는 실제 메모리 크기와 관계없이 프로세스에 큰 메모리 공간을 제공하는 기술이다. 프로그램이 사용하는 메모리가 물리메모리(RAM) 용량을 초과하면 일부 데이터가 보조기억장치의 스왑 영역으로 이동하는데 이를 스와핑이라 하며, 접근 속도가 느린 보조기억장치를 계속 사용하므로 컴퓨터가 느려진다. 따라서 데이터 크기보다 큰 RAM(40GB 이상)으로 업그레이드해야 한다.

잠깐 확인 — 40GB 파일 렉을 코드 수정 없이 해결하려고 CPU 코어를 16개로 늘리면 도움이 될까요?

아니에요. 문제는 계산 능력이 아니라 RAM이 데이터보다 작은 것이에요. RAM 용량을 늘려야 스왑이 필요 없어져요.
