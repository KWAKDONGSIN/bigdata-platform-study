코드, 인코드·디코드, 고정길이 코드

숫자가 아닌 것(기호, 글자 등)도 2진수로 나타내야 해요. 이때 쓰는 약속이 코드예요.

한 줄 정의

코드 = 유한한 개수의 원소(기호)들을 서로 구별할 수 있게, 각 원소에 붙여 주는 숫자. 기호를 코드로 바꾸는 일이 인코드(encode), 코드를 보고 원래 기호를 찾는 일이 디코드(decode)예요.

비유 — 학번

학생 이름은 같은 사람이 있어도 학번은 모두 달라서 구별돼요. 학번을 붙이는 것이 인코드, 학번으로 학생을 찾는 것이 디코드예요.

코드는 길이에 따라 두 가지로 나뉘어요.

  • 고정길이 코드 : 모든 원소의 이진수 길이가 같아요.
  • 가변길이 코드 : 원소마다 이진수 길이가 달라요.

슬라이드 19쪽은 4개 기호 ♠ ◇ ♡ ♣에 코드 4가지를 붙여 놓고, ♣♡♠◇♡ 다섯 기호를 이어 쓴 뒤 다시 읽어 보게 해요.

기호코드 1코드 2코드 3코드 4
♠0100101
◇101101111
♡11011110110
♣1110111111000
종류가변길이가변길이고정길이(2비트)고정길이(3비트)
  • 코드 1 : 1110_110_0_10_110은 0을 만날 때마다 한 글자가 끝나서 ♣♡♠◇♡로 정확히 읽혀요.
  • 코드 2 : 1111_111_1_11_111은 1이 줄줄이 이어져서 어디서 끊을지 몰라 읽을 수 없어요(슬라이드의 "???"). 1이 11의 앞부분, 11이 111의 앞부분이라서 그래요.
  • 코드 3, 4 : 길이가 고정이라 2비트(또는 3비트)씩 끊으면 돼요.

배울 점은 가변길이 코드는 한 코드가 다른 코드의 앞부분이 되면 디코드가 안 된다는 거예요.

그러면 원소가 N개일 때 고정길이 코드에는 몇 비트가 필요할까요? 비트 k개로는 2의 k제곱 가지를 표현하니까 (2의 k제곱) ≥ N인 가장 작은 k(= log₂N을 올림)예요.

원소 수 N필요한 최소 비트 수 (예제 2-9)
8개2³ = 8이므로 3비트
10개2³ = 8로는 부족하고 2⁴ = 16이면 충분해서 4비트
16개2⁴ = 16이므로 4비트
25개2⁴ = 16은 부족하고 2⁵ = 32면 충분해서 5비트
시험엔 이렇게 써요

코드는 유한개의 원소로 이루어진 집합의 각 원소를 구별할 수 있도록 부여한 숫자이며, 원소를 코드로 바꾸는 것을 인코드, 코드에서 원소를 찾는 것을 디코드라고 한다. 원소의 수가 N개일 때 고정길이 코드의 비트 수는 log₂N을 올림한 값이다.

잠깐 확인 — 원소 25개를 구별하는 고정길이 코드는 최소 몇 비트가 필요한가요?

5비트예요. 4비트로는 16가지, 5비트로는 32가지를 만들 수 있어서 25개를 구별하려면 5비트가 필요해요.
