HW6W 메모리 계층 구조 ★★

보기는 1 레지스터, 2 캐시, 3 주기억장치(RAM), 4 보조기억장치(SSD/HDD)예요. (기출은 번호가 달랐으니 이름으로 외우세요.)

문제 요지답
Q1 CPU 안에 있는 메모리 2개1, 2 (레지스터, 캐시)
Q2 접근 속도가 빠른 순서1, 2, 3, 4 (레지스터 → 캐시 → RAM → 보조기억장치)
Q3 같은 가격 대비 용량이 큰 순서4, 3, 2, 1 (보조기억장치 → RAM → 캐시 → 레지스터)

Q4 요지 : 엑셀로 분기별 매출 자료를 만드는 과정의 빈칸에 메모리 종류를 쓰라.

칸상황답이유
1)엑셀 설치4 보조기억장치설치는 저장
2)엑셀 실행3 RAM실행하면 RAM에 적재
3)xlsx 파일을 불러옴3 RAM파일 데이터가 RAM에 올라와요
4)2020년 4/4분기 부분 데이터2 캐시지금 계산에 쓸 부분과 주변
5)170만 + 220만 계산 중인 값1 레지스터ALU가 직접 계산하는 값

Q5 요지 : 메모리 계층 구조를 사용하는 이유는? 한 문장으로 "빠르고 큰 메모리는 너무 비싸서, 빠르고 작은 메모리와 느리고 큰 메모리를 단계적으로 두어 정해진 가격 안에서 속도와 용량을 함께 얻으려고 한다"고 써요. CPU와 RAM·보조기억장치의 속도 차이가 커서 중간에 캐시를 두는 이유도 덧붙이면 좋아요.

시험엔 이렇게 써요

CPU 내부 메모리는 레지스터와 캐시이고, 속도는 레지스터, 캐시, 주기억장치, 보조기억장치 순으로 빠르며 용량은 반대 순서이다. 프로그램은 보조기억장치에 설치되고 실행되면 주기억장치에 적재되며, 계산에 쓰이는 주변 데이터는 캐시에, CPU가 직접 계산하는 값은 레지스터에 있다.

잠깐 확인 — "파일을 불러왔다"에서 파일 전체 데이터가 올라가는 곳은?

주기억장치(RAM)예요. 그중 지금 계산에 필요한 일부만 캐시와 레지스터로 올라가요.
