2의 거듭제곱과 데이터 크기 (KB, MB, GB, TB) ★★

메모리 용량은 항상 2의 거듭제곱으로 계산돼요. 숫자가 커서 겁나지만, 2¹⁰ = 1024 ≈ 1천만 알면 거의 다 풀려요.

거듭제곱값이름
2⁰ ~ 2⁹1, 2, 4, 8, 16, 32, 64, 128, 256, 512
2¹⁰1,0241K (킬로) ≈ 1천
2²⁰1,048,5761M (메가) ≈ 100만
2³⁰1,073,741,8241G (기가) ≈ 10억
2⁴⁰약 1.1조1T (테라) ≈ 1조
큰 거듭제곱 쉽게 계산하는 요령

지수를 10 + 나머지로 쪼개요. 2²⁷ = 2²⁰ × 2⁷ = 1M × 128 = 128M이에요. 2³⁴ = 2³⁰ × 2⁴ = 1G × 16 = 16G이고요. 즉 10단위는 K, M, G, T로 바꾸고 나머지 자리는 2의 작은 거듭제곱(1, 2, 4, 8, 16, 32, 64, 128, 256, 512)으로 써요.

슬라이드 14~15쪽의 빈칸을 이 요령으로 채워 볼게요.

식쪼개기값
2¹⁴2¹⁰×2⁴ = 16K16,384
2¹⁶2¹⁰×2⁶ = 64K65,536

이 거듭제곱이 메모리 용량 표기와 바로 이어져요. 메모리를 16GB로 샀다는 것은 1바이트짜리 칸이 16 × 2³⁰ = 2³⁴개, 약 171억 개(17,179,869,184개)라는 뜻이에요.

(3주차 수업에서 교수님이 말로 "1기가는 10조 개, 16GB는 160조 개"라고 했지만 틀린 계산이었어요. 위의 값과 강의자료 14쪽이 맞아요. 시험에는 이 값으로 쓰세요.)

비유 — 우체통 칸 수

메모리는 한 칸에 1바이트씩 들어가는 우체통이 줄지어 있다고 생각해 보세요. 16GB는 우체통이 약 171억 칸이에요. 칸마다 주소(번호)가 있어서 CPU가 번호로 찾아가요.

시험엔 이렇게 써요

2¹⁰ = 1,024 = 1K(킬로), 2²⁰ = 1M(메가), 2³⁰ = 1G(기가), 2⁴⁰ = 1T(테라)이다. 예를 들어 2²⁸ = 2²⁰ × 2⁸ = 256M이다.

잠깐 확인 — 2³²은 얼마인가요?

4G예요. 2³² = 2³⁰ × 2² = 1G × 4이고, 자릿수로 쓰면 4,294,967,296이에요.
