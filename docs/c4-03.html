부품을 잇는 길, 버스

CPU와 메모리 사이에는 신호가 다니는 길이 필요해요. 이 길을 버스(bus)라고 부르고, 하는 일에 따라 세 가지로 나눠요. 슬라이드 50쪽 요약에는 이름만 나오고 수업에서 자세히 다루지 않았어요. 위 그림의 CPU 왼쪽 선 세 개가 바로 버스예요.

버스무엇이 다니나그림에서
주소 버스"메모리 몇 번지를 볼 것인가"라는 번호MAR에서 메모리로
데이터 버스읽거나 쓸 실제 값 (양방향)MBR과 메모리 사이
제어 버스"읽어라(Read)", "써라(Write)" 같은 제어신호CU에서 메모리로
비유

택배로 물건을 주고받는다고 해 봐요. 주소 버스는 받는 사람 주소, 데이터 버스는 상자 안의 물건, 제어 버스는 "보내기"인지 "받기"인지 적은 전표예요.

시험엔 이렇게 써요

시스템 버스는 CPU와 메모리 등을 연결하는 통로로 주소 버스, 데이터 버스, 제어 버스로 구성된다. 주소 버스는 읽거나 쓸 메모리 번지를, 데이터 버스는 실제 데이터를, 제어 버스는 읽기/쓰기 같은 제어신호를 전달한다.
