진법과 10진수 ↔ 2진수 변환 ★★★

교수님은 n진법의 규칙은 딱 두 개라고 했어요. 이 두 개만 알면 어떤 진법이든 쓸 수 있어요.

  • ① 쓰는 기호가 n개 : 10진법은 0~9의 10개, 2진법은 0과 1의 2개예요.
  • ② 자리값이 1, n, n², n³ … : 오른쪽부터 1의 자리, n의 자리, n²의 자리…예요.

숫자 53을 여러 진법으로 써 볼게요. 정말 같은 수인지 자리값으로 확인해요. 절대적인 수의 크기는 변하지 않고 표현만 달라져요.

진법쓴 모양풀어 보면
10진수535×10 + 3×1 = 53
2진수11010132 + 16 + 4 + 1 = 53
5진수2032×25 + 0×5 + 3×1 = 53
8진수656×8 + 5×1 = 53
16진수353×16 + 5×1 = 53

2진수 → 10진수는 쉬워요. 1이 있는 자리의 자리값을 더하면 돼요. 오른쪽부터 자리값은 1, 2, 4, 8, 16, 32, 64, 128이에요(2를 계속 곱한 수).

자리값1286432168421
0100110001001100

1이 있는 자리만 더해요. 64 + 8 + 4 = 76이에요. 같은 방법으로 10000011은 128 + 2 + 1 = 131이에요(슬라이드 예제 2-7).

10진수 → 2진수는 두 가지 방법이 있어요. 둘 다 같은 답이 나오니 편한 쪽을 고르세요.

방법 A — 큰 자리값부터 빼기 (손계산에 추천)

자리값 표(128 64 32 16 8 4 2 1)를 그려 놓고 왼쪽부터 "들어가면 1, 안 들어가면 0"을 쓰면서 남은 수를 줄여요. 137이면 128이 들어가니 1(남은 수 9), 64와 32와 16은 안 들어가니 0, 8이 들어가니 1(남은 수 1), 4와 2는 0, 1이 들어가니 1이에요. 답은 10001001이에요.

방법 B — 2로 계속 나누기

2로 나눈 나머지를 기록하고, 몫이 0이 될 때까지 반복해요. 마지막에 나머지를 아래에서 위로 읽어요. 몫이 묶음의 수이고, 나머지가 그 자리(1의 자리)의 숫자라는 뜻이에요(자료의 진법 변환 원리).

나누기몫나머지
137 ÷ 2681 (맨 아래 → 맨 오른쪽 자리)
68 ÷ 2340
34 ÷ 2170
17 ÷ 281
8 ÷ 240
4 ÷ 220
2 ÷ 210
1 ÷ 201 (맨 위가 가장 큰 자리)

나머지를 맨 아래에서 위로 읽으면 1, 0, 0, 0, 1, 0, 0, 1이라서 10001001이에요. 5진수나 8진수도 같은 방식이에요. 53을 5로 나누면 몫 10에 나머지 3, 10을 5로 나누면 몫 2에 나머지 0, 2를 5로 나누면 몫 0에 나머지 2라서 아래에서 위로 읽으면 203이에요.

파이썬은 이 변환을 대신 해 줘요. 직접 확인해 볼 수 있어요.

print(bin(137)) print(oct(137)) print(hex(137)) print(int("10001001", 2))
코드 줄무슨 뜻인가요
print(bin(137))137을 2진수로 바꿔요 (앞의 0b는 2진수 표시)
print(oct(137))8진수로 바꿔요 (0o는 8진수 표시)
print(hex(137))16진수로 바꿔요 (0x는 16진수 표시)
print(int("10001001", 2))2진수 글자 "10001001"을 10진수로 되돌려요

실행 결과(출력)

0b10001001 0o211 0x89 137

연습으로 슬라이드 16쪽의 138, 5, 32, 27과 기출 4번의 137, 7, 38, 77, 11을 변환해 볼게요.

8비트로 쓸 때는 앞에 0을 채워서 항상 8자리로 맞춰요. 메모리 한 칸이 8비트라서 그래요.

왜 컴퓨터가 2진법을 쓸까요? 사람끼리는 10진법으로 충분하지만, 반도체 회로는 5볼트(1)와 0볼트(0) 두 신호만 구별하기 때문이에요. 그래서 컴퓨터에 계산을 시키려면 모든 수가 2진수로 바뀌어야 해요.

시험엔 이렇게 써요

컴퓨터는 숫자를 2진수로 바꾸어 메모리에 저장한다. 10진수 137은 128 + 8 + 1이므로 8비트 이진수로 10001001이다. (변환 문제는 자리값 128 64 32 16 8 4 2 1 표를 먼저 그리고 한 칸씩 채우세요)

잠깐 확인 — 10진수 38을 8비트 이진수로 쓰면 무엇인가요?

00100110이에요. 38 = 32 + 4 + 2이니까 32, 4, 2 자리에 1을 써요.
