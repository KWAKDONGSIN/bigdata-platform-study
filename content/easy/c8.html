Q1. 용어 빈칸 채우기 (10점)

보기 16개 중에서 골라 빈칸 10개를 채워요. 한 칸에 1점이에요. 보기에는 정답이 아닌 말 6개(멀티 태스킹, 멀티 프로그래밍, 집적도, 코어, 오버클럭, 황의 법칙)가 섞여 있어요.

문제 요지

  • 계산장치(CPU)와 기억장치로 되어 있고, 계산장치가 기억장치의 프로그램을 한 줄씩 실행해 결과를 기억장치에 쓰는 현대 컴퓨터 구조를 (1.1 폰노이만 구조)라고 한다.
  • 반도체 집적도가 2년마다 2배씩 증가한다는 것을 (1.2 무어의 법칙)이라고 한다.
  • (1.3 싱글코어)는 하나의 CPU 안에 연산 장치가 1개이고, (1.4 멀티코어)는 여러 개이다.
  • CPU 클럭이 높아질수록 전력 소모와 발열이 늘어 CPU의 (1.5 온도)가 올라가고, 그래서 클럭을 무한정 높일 수 없다.
  • 응용 프로그램의 코드가 보조기억장치에 있으면 (1.6 프로그램), 실행되어 메모리에 올라와 있으면 (1.7 프로세스)라고 한다.
  • 하나의 프로그램을 여러 개의 프로세스로 병렬 실행하는 것을 (1.8 멀티 프로세싱), 하나의 프로세스 안에서 여러 흐름으로 병렬 실행하는 것을 (1.9 멀티 쓰레딩)이라고 한다.
  • 전원이 켜지면 가장 먼저 시작되고, 컴퓨터 자원과 여러 응용 프로그램의 실행을 관리하는 프로그램을 (1.10 운영체제)라고 한다.

정답 위 굵은 글씨 10개예요.

왜 그런지

1.2무어의 법칙"24개월(2년)마다 2배"가 무어의 법칙이에요. 황의 법칙은 메모리판이라 함정이에요.
1.3, 1.4싱글코어, 멀티코어코어는 연산 장치 한 개를 부르는 이름이에요. 코어가 1개면 싱글, 여러 개면 멀티예요.

비유

프로그램은 서랍 속 레시피 책이고, 프로세스는 주방에서 지금 만들고 있는 요리예요. 요리사가 한 명이면 싱글코어, 여러 명이면 멀티코어예요. 같은 요리를 주방 여러 곳에서 따로 만들면 멀티 프로세싱이고, 한 요리를 여러 요리사가 나눠 만들면 멀티 쓰레딩에 가까워요.

교수님은 멀티 태스킹과 멀티 프로그래밍은 크게 안 써도 된다고 했어요. 그래서 시험 준비는 "프로세스 vs 프로그램", "멀티 프로세싱 vs 멀티 쓰레딩" 두 쌍만 확실히 구분하면 돼요.

올해 시험에서도 이렇게 쓰세요

빈칸 채우기는 보기에서 그대로 골라 써요. 헷갈리는 두 쌍은 "저장장치에 있으면 프로그램, 메모리에서 실행 중이면 프로세스", "프로세스 여러 개면 멀티 프로세싱, 프로세스 하나 안의 여러 흐름이면 멀티 쓰레딩"으로 기억하세요.

잠깐 확인 — 메모리에 올라가 실행 중인 프로그램을 뭐라고 부르나요?

프로세스예요. 저장장치에 있을 때는 그냥 프로그램이에요.

Q3. sum.py가 실행되는 과정 (10점)

다음 파이썬 코드가 어디에 저장되고, 어디에 올라가고, 누가 계산하는지를 빈칸 10개(A~E, v~z)로 물어요. 한 칸에 1점이에요.

코드 줄무슨 뜻
n = 1n이라는 이름의 칸에 1을 넣어요.
sum = 0sum이라는 이름의 칸에 0을 넣어요.
while (n <= 100):n이 100 이하인 동안 아래 두 줄을 계속 반복해요.
sum = sum + nsum 칸의 값에 n을 더해 다시 sum 칸에 넣어요.
n = n + 1n 칸의 값을 1 키워요.

실행 결과 이 코드에는 print가 없어서 화면에 나오는 것은 없어요. 대신 메모리 속 값이 바뀌어, 반복이 끝나면 sum은 5050, n은 101이 돼요.

왜 그런지

  • 실행 전에는 파이썬 실행기와 코드가 보조기억장치(A)에 있어요. 실행하면 주기억장치(B)로 올라와요. 폰노이만 구조의 "SSD → RAM → CPU" 흐름이에요.

5.7 8비트 덧셈 계산기 연결하기 (4점) 전가산기 8개를 줄 세워요.

  • 같은 번호끼리 연결해요. A0, B0는 맨 아래 전가산기(가장 낮은 자리)의 A, B로, A7, B7은 맨 위 전가산기로 들어가요.
  • 아랫자리의 Cout을 바로 윗자리의 Cin에 이어요. 올림이 아래에서 위로 전달돼요.
  • 맨 아래 전가산기의 Cin은 0이에요. (들어올 올림이 없으니까요)
  • 각 전가산기의 합 S0~S7을 Y0~Y7로 내보내요. 맨 위 전가산기의 Cout7은 연결하지 않아요.
비유

초등학교 세로셈이에요. 일의 자리부터 더하고, 10이 넘으면 윗자리로 올림 1을 올려 보내요. 전가산기 한 개가 한 자리의 세로셈을 담당하고, 올림 선이 그 다음 자리로 이어져요.

예를 들어 7 + 5를 8비트로 더해 볼게요. A는 0000 0111, B는 0000 0101이에요. 0번째 자리 1+1은 0에 올림 1, 1번째 자리 1+0+올림1은 0에 올림 1, 2번째 자리 1+1+올림1은 1에 올림 1, 3번째 자리 0+0+올림1은 1이라 Y는 0000 1100, 즉 12예요.

올해 시험에서도 이렇게 쓰세요

진리표는 "AND는 둘 다 1, OR는 하나라도 1, XOR는 서로 다르면 1"만 기억하면 채워져요. 전가산기는 1의 개수가 홀수면 S=1, 2개 이상이면 Cout=1로 확인하세요. 연결 문제는 "Cout은 위 자리 Cin으로, 맨 아래 Cin은 0"이라고 쓰면 돼요.

잠깐 확인 — 전가산기에서 A=1, B=1, Cin=1이면 S와 Cout은?

S=1, Cout=1이에요. 1이 세 개라 합은 이진수 11(십진수 3)이에요.

Q7. 명령 실행의 마이크로 단계 (10점)

CPU는 메모리 00번지부터 시작해 지금 04번지의 ADD R3 R1 R2를 실행 중이에요. 이때 서로 다른 두 단계의 그림에서 빈칸 ①~⑩(각 1점)을 채워요.

한 명령은 인출(fetch) → 해독(decode) → 실행(execute) → 데이터(data) → 기록(write back) 5단계로 나뉘어 실행돼요.

단계무슨 일
인출PC가 가리키는 번지의 명령을 메모리에서 읽어 IR로 가져와요. 그다음 PC를 다음 명령 번지로 바꿔요.
해독제어장치(CU)가 IR의 명령을 풀어 제어신호를 정해요.
실행ALU가 계산해요.
데이터메모리를 읽거나 쓰는 명령일 때만 일해요. (MAR, MBR 사용)
기록결과를 레지스터에 적어요.

정답

빈칸정답이유
①인출(fetch)PC, MAR, MBR에서 IR로 명령을 가져오는 그림이에요.
②4PC가 지금 가리키는 번지는 04예요.
③6명령 하나가 두 칸(04, 05)을 차지해서 PC는 다음 명령 번지 06이 돼요.
④4MAR에는 읽을 번지 4가 먼저 들어가요.
⑤ADD R3 R1 R2MBR에 읽어 온 명령이 IR로 옮겨져요.
⑥실행(execute)ALU가 계산을 수행하는 그림이에요.
⑦+ADD이므로 제어신호는 덧셈이에요.
⑧5X에는 R1의 값이에요. 앞에서 MOVE R1 5로 5를 넣었어요.
⑨7Y에는 R2의 값이에요. MOVE R2 7로 7을 넣었어요.
⑩12AC에는 5 + 7의 결과가 들어가요.

이 명령은 메모리를 읽고 쓰지 않아서 4단계(데이터)에서는 아무 일도 안 해요. 마지막 5단계(기록)에서 AC의 12가 R3에 기록돼요.

비유

도서관에서 책 한 권을 읽는 일과 같아요. 책장 번호(PC)를 보고(인출), 제목과 내용을 이해하고(해독), 풀이대로 계산하고(실행), 필요하면 서랍을 열어 확인하고(데이터), 공책에 결과를 적어요(기록).

올해 시험에서도 이렇게 쓰세요

단계 이름은 "인출, 해독, 실행, 데이터, 기록"을 순서대로 쓰고, 인출에서는 "PC → MAR → 메모리 → MBR → IR, 그리고 PC 값 증가", 실행에서는 "ALU가 X, Y에 제어신호대로 계산해 AC에 저장"이라고 적으세요. 교수님이 CPU 구성 요소와 이 5단계를 복습하라고 따로 말했어요.

잠깐 확인 — 명령어 하나가 2칸을 차지할 때 04번지 명령을 읽은 뒤 PC는 몇이 되나요?

6이에요. 04, 05번지를 읽었으니 다음 명령은 06번지예요.

메모리 4종류는 주기억장치(RAM, 1), 보조기억장치(SSD/HDD, 2), 레지스터(3), 캐쉬(4)예요. 8.1~8.3은 각 2점, 8.4는 5칸 각 1점이에요.

SSD전자플래시 메모리(NAND)에 전자를 가두는 방식이라 움직이는 부품이 없어요.
비유

파티션은 큰 집 하나를 방 여러 개로 나누는 것이고, RAID는 작은 방 여러 개를 이어 붙여 큰 방처럼 쓰는 것이에요. 서로 반대 방향이에요. 파티션을 나눠 두면 윈도우를 다시 설치할 때 그 파티션만 포맷하고 나머지 자료를 지키는 장점이 있어요.

RAID에는 여러 종류가 있지만 교수님은 RAID 0(여러 디스크에 나눠 쓰기, 빠름), RAID 1(똑같이 복사해 두기, 안전), RAID 5(패리티로 복구)를 주로 쓴다고 했어요. 나머지는 안 쓰니 넘어가도 돼요.

함정 보기는 섹터, 트랙, 실린더(HDD 디스크의 구조 이름), 포맷(데이터를 지우고 초기화), RAM과 레지스터(보조기억장치가 아님)예요.

올해 시험에서도 이렇게 쓰세요

"HDD는 자기, CD-ROM은 광학, SSD는 전자 방식이다. SSD는 빠르지만 비싸서 OS처럼 자주 쓰는 것을, HDD는 느리지만 싸서 동영상·사진처럼 덜 쓰는 것을 저장한다"로 외우세요. RAID는 여러 디스크를 묶는 것, 파티션은 하나를 나누는 것으로 구분해요.

잠깐 확인 — 디스크 하나를 여러 공간으로 나누는 것은 RAID와 파티션 중 무엇인가요?

파티션이에요. RAID는 반대로 여러 개를 묶는 것이에요.
