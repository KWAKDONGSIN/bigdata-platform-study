빈칸 암기 훈련

2023 기출은 빈칸 채우기, 부품 고르기, 과정 순서 쓰기가 중심이에요. 읽기만 하면 아는 느낌만 들어서, 이 장은 문장을 가리고 직접 떠올려 말하는 연습으로만 채웠어요. 소단원마다 빈칸 10문장, 순서 쓰기, 손계산 1문제가 있어요.

9-1. 컴퓨터 구조 기본 문장 (기출 Q1·Q2·Q3)

기출 1~3번이 이 부분이에요. 읽기만 하면 알겠다는 느낌만 생기고, 직접 떠올려 말해 본 것이 시험장에서 나와요. 눌러 보기 전에 꼭 입으로 먼저 말해 보세요.

이 장 쓰는 법

① 문장을 읽고 ____를 입으로 말하거나 공책에 써요. ② 눌러서 맞춰 봐요. ③ 틀린 번호는 종이에 적어 두고, 장 끝에서 그 번호만 다시 해요. 한 소단원은 10분 안에 끝내는 게 목표예요.

① 빈칸 채우기 문장을 읽고 ____에 들어갈 말을 먼저 말하거나 써 본 뒤 눌러서 맞춰 보세요.

1) 계산장치(CPU)와 기억장치로 이루어지고, 계산장치가 기억장치의 프로그램을 한 줄씩 실행해 결과를 기억장치에 쓰는 현대 컴퓨터 구조를 ____ 구조라고 한다.

폰노이만이에요. 프로그램을 기억장치에 넣어 두고 한 줄씩 꺼내 계산하는 방식이에요. (기출 Q1.1)

2) 반도체 집적도가 2년(24개월)마다 2배가 된다는 것을 ____의 법칙이라고 한다.

무어예요. 황의 법칙은 메모리에 대한 비슷한 법칙이라 기출에서 함정 보기였어요. (기출 Q1.2)

3) 하나의 CPU 안에 연산 장치(코어)가 1개이면 ____, 여러 개이면 ____라고 한다.

싱글코어, 멀티코어예요. 코어는 연산 장치 한 개를 부르는 이름이에요. (기출 Q1.3, 1.4)

4) CPU 클럭이 높아질수록 전력 소모와 발열이 늘어 CPU의 ____이 올라가고, 그래서 클럭을 무한정 높일 수 없다.

온도예요. 클럭 상승 → 발열 증가 → 온도 상승 → 회로가 상할 수 있어서 한계가 생겨요. (기출 Q1.5)

5) 응용 프로그램의 코드가 보조기억장치에 있으면 ____, 실행되어 메모리에 올라와 있으면 ____라고 한다.

프로그램, 프로세스예요. 레시피가 프로그램이고, 조리 중인 요리가 프로세스예요. (기출 Q1.6, 1.7)

6) 하나의 프로그램을 여러 개의 프로세스로 병렬 실행하는 것을 ____, 하나의 프로세스 안에서 여러 흐름으로 병렬 실행하는 것을 ____이라고 한다.

멀티 프로세싱, 멀티 쓰레딩이에요. 크롬 창을 여러 개 띄우면 멀티 프로세싱, 창 하나에 탭을 여러 개 띄우면 멀티 쓰레딩이에요. (기출 Q1.8, 1.9)

7) 컴퓨터 전원이 켜지면 가장 먼저 시작되고, 컴퓨터 자원과 여러 응용 프로그램의 실행을 관리하는 프로그램을 ____라고 한다.

운영체제예요. OS는 켜면 제일 먼저 실행되어 자원과 프로그램을 관리해요. (기출 Q1.10)

8) 컴퓨터 부품 간에 데이터가 다니는 통로 역할은 ____이 하고, 거의 모든 계산은 ____이 한다.

메인보드, CPU예요. 모든 부품이 메인보드에 꽂히고, CPU는 계산(ALU)과 제어를 하는 두뇌예요. (기출 Q2.2 a, b)

9) 전원이 꺼져도 데이터가 남는 비휘발성 부품은 ____이고, 실행 중인 프로그램 코드와 데이터를 담는 휘발성 부품은 ____이다.

보조기억장치(SSD/HDD), RAM이에요. 휘발성은 전원이 꺼지면 사라진다는 뜻이에요. (기출 Q2.2 c, d)

10) 교류를 직류로 바꿔 전원을 공급하는 부품은 ____이고, 이미지 처리·딥러닝 같은 행렬 연산을 병렬로 빠르게 하는 부품은 ____이다.

전원공급장치(파워), 그래픽카드(GPU)예요. 콘센트의 교류(AC)를 부품이 쓰는 직류(DC)로 바꿔 주는 설비와, 간단한 계산 수천 개를 한꺼번에 하는 조수 부대예요. (기출 Q2.2 e, f)

② 순서대로 써 보기 기출 Q3처럼 프로그램이 실행되는 길을 순서대로 써 보세요. 보기를 순서대로 가나다 기호로 쓰면 돼요.

  • 가) CPU가 한 줄씩 기계어를 가져와 계산한다
  • 나) 코드가 보조기억장치에 보관되어 있다
  • 다) 실행하면 주기억장치(RAM)에 적재된다
  • 라) 계산 결과(변수 값)가 기억장치에 기록된다
순서대로 써 보기 — 답 열기

나 → 다 → 가 → 라

보관 → 적재 → 계산 → 기록이에요. 폰노이만 구조의 SSD → RAM → CPU 흐름이고, 기출 Q3 빈칸 A는 보조기억장치, B는 주기억장치, C는 CPU였어요.

③ 계산 sum.py(n = 1, sum = 0에서 시작해 while (n <= 100): 안에서 sum = sum + n, n = n + 1을 반복)를 3번 반복하면 sum과 n은 각각 얼마일까요? 그리고 반복이 모두 끝나면 sum과 n은 얼마일까요?

단계 풀이 보기 (종이에 먼저 풀어 본 뒤 열기)

1번째 반복 sum = 0 + 1 = 1이고 n은 2가 돼요.

2번째 반복 sum = 1 + 2 = 3이고 n은 3이 돼요.

3번째 반복 sum = 3 + 3 = 6이고 n은 4가 돼요.

3번 반복하면 sum = 6, n = 4예요. n이 101이 되어야 조건 n <= 100이 거짓이 되어 멈추니, 끝났을 때 sum = 1 + 2 + … + 100 = 5050, n = 101이에요. print가 없어서 화면에는 아무것도 안 나와요.

시험엔 이렇게 써요

폰노이만 구조는 계산장치(CPU)와 기억장치로 구성되어 계산장치가 기억장치의 프로그램에서 명령을 한 줄씩 실행하고 결과를 기억장치에 기록하는 구조이다. 프로그램은 보조기억장치에 보관되어 있다가 실행되면 주기억장치(RAM)에 적재되고, CPU가 한 줄씩 가져와 계산한다.

잠깐 확인 — 크롬 창을 2개 띄운 것과 한 창에 탭을 2개 연 것 중 멀티 프로세싱은 어느 쪽인가요?

창을 2개 띄운 쪽이에요. 프로세스가 2개가 되기 때문이에요. 탭은 프로세스 하나 안의 흐름이라 멀티 쓰레딩이에요.

9-2. 데이터 표현 — 진법과 코드 (기출 Q4)

기출 4번은 십진수와 글자를 1바이트 이진수로 쓰는 손계산이에요. 먼저 용어와 규칙을 빈칸으로 떠올리고, 마지막에 직접 변환해 보세요.

① 빈칸 채우기 문장을 읽고 ____에 들어갈 말을 먼저 말하거나 써 본 뒤 눌러서 맞춰 보세요.

1) 컴퓨터에서 0 또는 1 한 자리를 나타내는 가장 작은 정보 단위는 ____이고, 이것 8개를 묶은 단위는 ____이다.

비트, 바이트예요. 비트(bit)는 binary digit(이진 숫자)을 줄인 말이에요.

2) 4비트를 묶은 단위를 ____이라고 하며, 16진수 한 자리와 같다.

니블(nibble)이에요. 비트 4개는 0000~1111로 16가지라 16진수 한 자리와 딱 맞아요.

3) 1바이트(8비트)로는 서로 다른 ____가지 값(0~255)을 나타낼 수 있다.

256이에요. 0 또는 1이 8자리이니 2를 8번 곱한 수예요.

4) 8비트 이진수의 자릿값은 왼쪽부터 ____이다.

128 64 32 16 8 4 2 1이에요. 오른쪽부터 1에 2를 계속 곱한 수예요. 시험지 여백에 먼저 적어 두세요.

5) 2진수를 오른쪽부터 ____비트씩 묶으면 8진수 한 자리, ____비트씩 묶으면 16진수 한 자리가 된다.

3, 4예요. 2의 3제곱이 8이고 2의 4제곱이 16이라서 그래요. 자리가 모자라면 왼쪽에 0을 채워요.

6) 16진수에서 10부터 15까지는 ____로 쓴다.

A, B, C, D, E, F예요. A는 10, B는 11, C는 12, D는 13, E는 14, F는 15예요. 그래서 1100은 8 + 4 = 12이고 C예요.

7) 2의 10제곱은 1K(킬로), 2의 20제곱은 1M(메가), 2의 30제곱은 1____, 2의 40제곱은 1____이다.

G(기가), T(테라)예요. 큰 거듭제곱은 10단위와 나머지로 쪼개요. 예를 들어 2의 28제곱은 1M × 256 = 256M이에요.

8) ASCII에서 대문자 A는 십진수 ____, 소문자 a는 ____, 숫자 글자 0은 ____이다.

65, 97, 48이에요. 알파벳은 차례대로 1씩 커져서 R은 65 + 17 = 82, t는 97 + 19 = 116이에요.

9) 문자 하나는 ASCII 7비트 코드 앞에 0을 붙여 ____비트(1바이트)로 메모리에 저장한다.

8비트예요. 메모리 한 칸이 8비트라서 항상 8자리로 맞춰요. 그래서 "Hello"는 5바이트예요.

10) 데이터 오류를 검사하려고 덧붙이는 비트를 ____ 비트라고 하며, 짝수 방식은 전체에서 1의 개수가 ____가 되도록 붙인다.

패리티, 짝수예요. 전송 중 비트 하나가 바뀌면 1의 개수의 짝홀이 규칙과 달라져서 오류를 알아챌 수 있어요.

② 순서대로 써 보기 문자 R을 메모리 한 칸(1바이트)에 넣는 순서를 써 보세요. 보기를 순서대로 가나다 기호로 쓰면 돼요.

  • 가) 열의 3비트와 행의 4비트를 이어 붙여 7비트 코드를 만든다
  • 나) ASCII 표에서 글자를 찾는다
  • 다) 맨 앞에 0을 붙여 8비트로 쓴다
순서대로 써 보기 — 답 열기

나 → 가 → 다

표에서 R은 열 101, 행 0010이라 1010010이고, 앞에 0을 붙이면 0101 0010이에요. 10진수로는 82예요.

③ 계산 십진수 77을 8비트 이진수로 바꿔 보세요. (기출 Q4의 77)

단계 풀이 보기 (종이에 먼저 풀어 본 뒤 열기)

자릿값 표를 먼저 적어요. 128 64 32 16 8 4 2 1.

128은 77보다 커서 0이에요. 64는 들어가서 1이고 남은 수는 13이에요.

32와 16은 13보다 커서 0이에요. 8은 들어가서 1이고 남은 수는 5예요.

4는 들어가서 1이고 남은 수는 1이에요. 2는 안 들어가서 0, 1은 들어가서 1이에요.

답은 0100 1101이에요. 검산은 64 + 8 + 4 + 1 = 77이에요.

시험엔 이렇게 써요

숫자는 자릿값(128 64 32 16 8 4 2 1)을 이용해 8비트 이진수로 바꾸고, 문자는 ASCII 표에서 열과 행의 비트를 이어 붙인 뒤 앞에 0을 붙여 8비트로 쓴다. 2진수를 오른쪽부터 3비트씩 묶으면 8진수, 4비트씩 묶으면 16진수이다.

잠깐 확인 — (10110110)₂를 16진수로 바꾸면 무엇인가요?

B6이에요. 1011 = 8 + 2 + 1 = 11 = B이고, 0110 = 4 + 2 = 6이에요.

9-3. 논리 게이트와 가산기 (기출 Q5)

기출 5번은 진리표 채우기와 8비트 덧셈기 연결이에요. 진리표는 출력 열만 외우면 쉽고, 전가산기는 1의 개수만 세면 풀려요.

① 빈칸 채우기 문장을 읽고 ____에 들어갈 말을 먼저 말하거나 써 본 뒤 눌러서 맞춰 보세요.

1) AND 게이트는 입력이 ____ 1일 때만 1을 출력한다.

모두예요. 하나라도 0이면 0이에요. 스위치 두 개를 한 줄로 이은 것처럼 둘 다 켜야 전구가 켜져요. (기출 Q5.1)

2) OR 게이트는 입력 중 ____ 1이면 1을 출력한다.

하나라도예요. 모두 0일 때만 0이에요. 스위치를 나란히 이은 것처럼 하나만 켜도 켜져요. (기출 Q5.2)

3) NOT 게이트는 입력 비트를 ____ 출력한다.

반대로(뒤집어)예요. 0이면 1, 1이면 0이에요. (기출 Q5.3)

4) XOR 게이트는 두 입력이 같으면 ____, 다르면 ____을 출력한다.

0, 1이에요. "둘이 다른가요?"를 묻는 회로예요. (기출 Q5.4)

5) 입력 (A, B)가 00, 01, 10, 11일 때의 출력은 AND가 ____, OR가 ____, XOR가 ____ 순이다.

AND 0001, OR 0111, XOR 0110이에요. NAND는 AND를 뒤집은 1110, NOR는 OR를 뒤집은 1000이에요.

6) 반가산기는 한 자리 비트 두 개를 더해 합 S와 ____를 출력하며, S는 ____ 게이트, 올림은 ____ 게이트로 만든다.

올림(Cout), XOR, AND예요. 1 + 1 = 10(이진수)이라 그 자리는 0이고 올림이 1이에요. (기출 Q5.5)

7) 전가산기는 A, B와 아랫자리에서 올라온 ____(Cin)까지 세 개를 더해 합 S와 올림 Cout을 출력한다.

올림이에요. 반가산기는 아랫자리의 올림을 받을 입구가 없어서 반쪽이라고 불러요. (기출 Q5.6)

8) 전가산기는 입력 세 개 중 1이 ____ 개이면 S가 1이 되고, ____ 개 이상이면 Cout이 1이 된다.

홀수(1개 또는 3개), 2개 이상이에요. 1이 0개면 0과 0, 1개면 S만 1, 2개면 Cout만 1, 3개면 둘 다 1이에요.

9) 8비트 덧셈 계산기는 전가산기 ____개를 이어서 만들고, i번 전가산기의 Cout을 i+1번 전가산기의 ____에 연결하며, 맨 아래 Cin에는 ____을 넣는다.

8개, Cin, 0이에요. 맨 아래에는 들어올 올림이 없고, 맨 위의 Cout은 연결하지 않아요. (기출 Q5.7)

10) ALU의 제어신호 C는 왼쪽부터 + - x / & | >> << 순서라서, 덧셈이면 C = ____, 곱셈이면 C = ____이다.

덧셈 1000 0000, 곱셈 0010 0000이에요. 덧셈은 첫 번째 자리, 곱셈은 세 번째 자리 하나만 1이에요. (기출 Q6.2)

② 순서대로 써 보기 계산기(ALU)를 레고처럼 아래부터 쌓는 순서를 써 보세요.

  • 가) ALU(계산기)
  • 나) 논리 게이트(AND, OR, NOT)
  • 다) 반도체(다이오드, 트랜지스터)
  • 라) 논리 회로(반가산기, 전가산기 등)
순서대로 써 보기 — 답 열기

다 → 나 → 라 → 가

반도체 → 논리 게이트 → 논리 회로 → ALU 순이에요. 1칸 블록 → 작은 블록 → 벽과 지붕 → 완성된 건물과 같아요.

③ 계산 전가산기로 0000 0111(7) + 0000 0101(5)를 계산해 보세요. 오른쪽(0번 자리)부터 올림을 넘겨요.

단계 풀이 보기 (종이에 먼저 풀어 본 뒤 열기)

0번 자리 1 + 1 + Cin 0은 1이 2개라서 S = 0, Cout = 1이에요.

1번 자리 1 + 0 + Cin 1은 1이 2개라서 S = 0, Cout = 1이에요.

2번 자리 1 + 1 + Cin 1은 1이 3개라서 S = 1, Cout = 1이에요.

3번 자리 0 + 0 + Cin 1은 1이 1개라서 S = 1, Cout = 0이에요. 4번부터 7번 자리는 모두 0이에요.

S를 위에서부터 쓰면 0000 1100, 즉 12예요. 7 + 5 = 12가 맞아요.

시험엔 이렇게 써요

AND는 두 비트가 모두 1이면 1, OR는 하나 이상이 1이면 1, NOT은 반대 비트, XOR는 두 비트가 같으면 0 다르면 1을 출력한다. 8비트 덧셈기는 전가산기 8개를 일렬로 놓고 i번의 Cout을 i+1번의 Cin에 연결하며, 가장 낮은 자리의 Cin은 0으로 하고 최종 올림은 연결하지 않는다.

잠깐 확인 — 전가산기에서 A = 1, B = 0, Cin = 1이면 S와 Cout은 각각 얼마인가요?

S = 0, Cout = 1이에요. 1이 2개라서 합은 이진수 10이에요. (기출 Q5.6의 한 줄)

9-4. CPU 5단계와 레지스터 (기출 Q6·Q7, 교수님이 꼭 복습하라고 한 곳)

교수님이 CPU 구성 요소와 명령 실행 5단계를 복습하라고 따로 말했고, 기출 7번이 이 그림에서 나왔어요. 가장 오래 투자할 소단원이에요.

① 빈칸 채우기 문장을 읽고 ____에 들어갈 말을 먼저 말하거나 써 본 뒤 눌러서 맞춰 보세요.

1) CPU의 필수 구성 요소 3가지는 계산을 하는 ____, 명령을 해독하고 제어신호를 내는 ____, CPU 안의 작고 빠른 메모리인 ____이다.

ALU(산술논리연산장치), 제어장치(CU), 레지스터 세트예요. 계산기, 지휘자, 손에 든 메모지에 비유해요.

2) 다음에 가져올 명령이 메모리 몇 번지에 있는지 적어 두는 레지스터는 ____이고, 지금 실행하려고 가져온 명령 한 줄을 담는 레지스터는 ____이다.

PC(프로그램 카운터), IR(명령 레지스터)이에요. PC는 책갈피, IR은 지금 읽는 문장이에요.

3) 메모리의 몇 번지를 읽고 쓸지 적어 두는 레지스터는 ____이고, 메모리에서 읽어 온 값이나 쓸 값을 잠깐 담는 레지스터는 ____이다.

MAR(메모리 주소 레지스터), MBR(메모리 버퍼 레지스터)이에요. MBR은 MDR이라고도 불러요.

4) ALU 입구의 X, Y에 계산할 두 값이 들어가고, 계산 결과는 ____(누산기)에 잠깐 담긴다.

AC예요. Accumulator의 약자이고 계산기 화면에 비유해요. 기출 Q7에서 AC에 12가 들어갔어요.

5) 명령 실행 5단계 중 PC가 가리키는 번지의 명령을 메모리에서 IR로 가져오는 첫 단계는 ____, ALU가 계산하는 단계는 ____, 결과를 레지스터에 적는 마지막 단계는 ____이다.

인출(fetch), 실행(execute), 기록(write back)이에요. 도서관에서 쪽지를 가져오고, 계산기를 두드리고, 공책에 적는 순서예요.

6) 제어장치(CU)가 IR의 명령을 풀어 제어신호를 정하는 단계는 ____이고, 메모리를 읽거나 쓰는 명령에서만 일하는 단계는 ____이다.

해독(decode), 데이터(data)예요. 데이터 단계에서는 MAR 번지와 MBR 사이에서 값을 읽거나 써요.

7) ADD 같은 레지스터 계산 명령은 ____ 단계가 No action이고, LOAD·STORE 같은 메모리 접근 명령은 ____ 단계가 No action이다.

데이터, 실행이에요. 계산 명령은 1-2-3-5단계, 메모리 접근 명령은 1-2-4-5단계로 움직여요.

8) 기계어 명령은 무슨 계산을 할지 나타내는 ____(동작 코드)와 계산의 대상을 나타내는 ____(피연산자)로 이루어진다.

opcode, operand예요. opcode는 문장의 동사, operand는 목적어예요. ADD R3 R1 R2에서 ADD가 opcode, R3·R1·R2가 operand예요.

9) 이 수업의 가상 CPU에서 opcode는 MOVE = ____, LOAD = ____, STORE = ____, ADD = ____, MUL = ____이다.

MOVE 1000, LOAD 1001, STORE 1010, ADD 1100, MUL 1101이에요. 기출 Q6.1은 그림에 이미 나온 줄에서 이 값을 사전처럼 베껴 오는 문제였어요.

10) 레지스터 번호는 4비트 이진수라서 R1은 0001, R3은 ____, R5는 ____이고, 16진수 주소 CC는 이진수로 ____이다.

R3 0011, R5 0101, CC 1100 1100이에요. 16진수 C가 12이고 이진수 1100이라서 CC는 1100 1100이고, 다음 번지 CD는 1100 1101이에요.

② 순서대로 써 보기 명령 한 줄이 실행되는 5단계를 순서대로 써 보세요.

  • 가) 기록
  • 나) 인출
  • 다) 실행
  • 라) 해독
  • 마) 데이터
순서대로 써 보기 — 답 열기

나 → 라 → 다 → 마 → 가 (인출 → 해독 → 실행 → 데이터 → 기록)

그림 문제는 어느 부품에 화살표가 있는지로 알아봐요. PC·MAR·IR이 보이면 인출, ALU·X·Y·AC가 보이면 실행이에요.

② 순서대로 써 보기 (하나 더) 인출 단계 안에서 일어나는 일을 순서대로 써 보세요.

  • 가) 메모리에서 읽은 명령이 MBR을 거쳐 IR에 들어간다
  • 나) PC 값이 MAR로 간다 (제어신호 Read)
  • 다) PC가 다음 명령의 번지로 바뀐다
순서대로 써 보기 — 답 열기

나 → 가 → 다

PC 값을 MAR로 보내 메모리의 그 번지를 읽고, 명령이 MBR을 거쳐 IR로 오면, PC를 다음 번지로 바꿔요.

③ 계산 메모리 04번지에 ADD R3 R1 R2가 있고, R1 = 5, R2 = 7이며, 명령 하나가 메모리 2칸을 차지해요. 5단계마다 무슨 일이 일어나는지 써 보세요. (기출 Q7)

단계 풀이 보기 (종이에 먼저 풀어 본 뒤 열기)

인출 단계 MAR ← 4, IR ← ADD R3 R1 R2, PC ← 6이에요. 04, 05번지를 읽었으니 다음 명령은 06번지예요.

해독 단계 X ← 5, Y ← 7이고 ALU 제어신호는 +예요.

실행 단계 ALU가 5 + 7을 계산해서 AC ← 12가 돼요.

데이터 단계는 메모리를 안 쓰는 명령이라 No action이에요.

기록 단계 AC의 12를 R3에 적어요. R3 ← 12예요.

정리하면 PC는 4에서 6으로, AC는 12, 마지막에 R3는 12가 돼요.

시험엔 이렇게 써요

CPU는 하나의 기계어 명령을 인출(fetch), 해독(decode), 실행(execute), 데이터(data), 기록(write back)의 5단계로 나누어 실행한다. 인출에서는 PC의 주소를 MAR에 넣고 메모리에서 읽은 명령을 MBR을 거쳐 IR에 가져오며 PC는 다음 명령의 주소로 바뀐다. 해독에서는 제어장치가 제어신호를 정하고, 실행에서는 ALU가 계산해 AC에 두며, 데이터는 메모리 접근 명령에서만 일하고, 기록에서는 결과를 레지스터에 적는다.

잠깐 확인 — LOAD R5 CC 명령에서 No action인 단계는 어느 단계인가요?

실행 단계예요. 계산이 없어서 3단계가 비고, 데이터 단계에서 Read로 MBR ← MEM[CC]를 하고, 기록 단계에서 R5 ← MBR이 돼요.

9-5. 메모리 계층·캐시·레이턴시 vs 대역폭 (기출 Q8)

기출 8번이 메모리 계층이에요. 교수님이 레이턴시(응답 시간)와 대역폭(초당 전송량)은 둘 다 속도지만 다른 개념이라고 따로 강조했으니, 이 둘을 말로 구분할 수 있게 해 두세요.

외우기 팁 — 접근 속도 숫자

레지스터 1ns보다 빠름, 캐시 0.5~2.5ns, RAM 50~70ns, SSD 20~200µs, HDD 5~20ms예요. 단위는 1ms = 1,000µs = 1,000,000ns이고, 순서는 "레-캐-램-보"로 외우면 돼요.

① 빈칸 채우기 문장을 읽고 ____에 들어갈 말을 먼저 말하거나 써 본 뒤 눌러서 맞춰 보세요.

1) 메모리를 접근 속도가 빠른 순서로 쓰면 레지스터 → ____ → ____ → ____이다.

캐시 → RAM(주기억장치) → 보조기억장치(SSD/HDD)예요. "레-캐-램-보"로 외워요. (기출 Q8.2)

2) CPU 안에 있는 메모리는 ____와 ____이고, RAM은 CPU ____에 따로 꽂혀 있다.

레지스터, 캐시, 밖이에요. 레지스터와 캐시는 CPU 칩 안에 있어요. (기출 Q8.1)

3) 메모리 계층에서 위로 갈수록 속도는 ____, 용량은 ____, 비트당 가격은 ____.

빨라지고, 작아지고, 비싸져요. 빠르고 큰 메모리는 너무 비싸서, 제한된 비용으로 속도와 용량을 함께 얻으려고 계층 구조를 써요.

4) 레이턴시는 데이터에 접근하는 데 걸리는 ____이며, 값이 ____을수록 빠르다.

시간, 낮이에요. 낮은 레이턴시가 접근이 빠르다는 뜻이에요. 교수님이 녹취에서 한 번 반대로 말했지만 자료 기준은 이 문장이에요.

5) 대역폭(스루풋)은 ____ 시간당 전송되는 데이터 ____이다.

단위, 양이에요. 높을수록 같은 시간에 더 많이 보내요. 바가지냐 물탱크냐의 차이예요.

6) 영상을 눌렀는데 재생이 시작되기까지 오래 걸린다면 ____이 나쁜 것이고, 4K 영상이 자꾸 끊긴다면 ____이 부족한 것이다.

레이턴시, 대역폭이에요. 둘 다 속도지만 앞은 시작까지 걸리는 시간, 뒤는 흘러오는 양이에요. (교수님 비유)

7) 필요한 데이터가 캐시에 있으면 캐시 ____, 없어서 다음 단계(L2, L3, RAM)에서 가져오면 캐시 ____이다.

히트(적중), 미스(실패)예요. 책상 위에 책이 있으면 히트, 책장까지 가야 하면 미스예요.

8) 프로그램이 한 곳을 읽으면 그 주변을 이어서 읽는 경향을 ____이라고 하며, 그래서 캐시는 주변 데이터까지 함께 올려 둔다.

지역성이에요. 시험공부를 1장, 2장, 3장 순서로 하는 것이 지역성이에요.

9) SRAM은 빠르지만 비싸서 ____에 쓰고, DRAM은 리프레시가 필요하지만 싸고 집적도가 높아서 ____에 쓴다.

캐시, 주기억장치(RAM)예요. 빠를수록 작고 비싸다는 계층 구조가 소자 차이에서 나와요.

10) 엑셀 프로그램을 설치하면 ____에 저장되고, 실행하거나 파일을 열면 ____에 올라가며, 지금 계산하는 주변 데이터는 ____에, ALU가 직접 더하는 두 숫자는 ____에 있다.

보조기억장치, RAM, 캐시, 레지스터예요. 설치는 저장, 실행·열기는 RAM, 지금 계산하는 주변은 캐시, 지금 계산하는 값은 레지스터예요. (기출 Q8.4)

② 순서대로 써 보기 같은 가격 대비 용량이 큰 순서(기출 8.3)를 써 보세요.

  • 가) 레지스터
  • 나) 캐시
  • 다) RAM
  • 라) 보조기억장치
순서대로 써 보기 — 답 열기

라 → 다 → 나 → 가

속도 순서의 반대예요. "보-램-캐-레"로 외워요. 빠를수록 비싸서 용량이 작아요.

② 순서대로 써 보기 (하나 더) CPU가 데이터를 찾으러 가는 순서를 써 보세요.

  • 가) RAM
  • 나) L2 캐시
  • 다) L1 캐시
  • 라) L3 캐시
순서대로 써 보기 — 답 열기

다 → 나 → 라 → 가

CPU에 가장 가까운 L1부터 보고, 없으면 L2, L3를 거쳐 마지막으로 RAM으로 내려가요.

③ 계산 SSD의 접근 속도 20µs를 ns로 바꾸고, RAM의 70ns와 비교해 약 몇 배 느린지 써 보세요.

단계 풀이 보기 (종이에 먼저 풀어 본 뒤 열기)

1ms = 1,000µs = 1,000,000ns이니 1µs = 1,000ns예요.

그래서 20µs = 20 × 1,000 = 20,000ns예요.

20,000 ÷ 70 ≈ 286이에요.

SSD는 RAM보다 약 290배(수백 배) 느려요. 그래서 컴퓨터가 느려지는 병목은 주로 RAM과 SSD 사이에서 생겨요.

시험엔 이렇게 써요

메모리 계층 구조는 레지스터, 캐시, 주기억장치(RAM), 보조기억장치로 이루어지며 위로 갈수록 접근 속도가 빠르고 용량이 작으며 비트당 가격이 비싸다. 레이턴시는 데이터에 접근하는 데 걸리는 시간으로 낮을수록 빠르고, 대역폭(스루풋)은 단위 시간당 전송되는 데이터 양이다.

잠깐 확인 — 영상이 끊김 없이 부드럽게 나오는 것은 레이턴시와 대역폭 중 무엇이 충분한 덕분인가요?

대역폭이에요. 같은 시간에 흘려보낼 수 있는 데이터 양이 충분하다는 뜻이에요. 재생 시작이 빠른 것은 레이턴시가 낮은 거예요.

9-6. 가상메모리와 스왑 (기출 Q9)

기출 9번이 40GB 파일을 16GB RAM으로 읽다가 컴퓨터가 멈추는 문제였어요. 빈칸 A~E와 해결책이 한 흐름이니 그 흐름을 통째로 외우세요.

① 빈칸 채우기 문장을 읽고 ____에 들어갈 말을 먼저 말하거나 써 본 뒤 눌러서 맞춰 보세요.

1) 프로세스에게 실제 메모리 크기를 신경 쓰지 않아도 되는 큰 메모리 공간을 제공하는 기술을 ____메모리라고 하며, 실제 관리는 ____가 한다.

가상, 운영체제예요. 호텔 투숙객은 방 번호만 알고 실제 방 배정은 직원이 하는 것과 같아요. (기출 Q9.1 A)

2) 운영체제는 가상메모리에 올린 데이터를 실제 RAM인 ____메모리에 할당하려고 한다.

물리예요. 프로세스가 보는 것은 가상, 실제 RAM은 물리메모리예요. (기출 Q9.1 B)

3) 물리메모리가 모자라면 일부 데이터가 ____(SSD/HDD)의 ____메모리(스왑 영역)로 옮겨진다.

보조기억장치, 스왑이에요. 쫓겨난 메모리를 모아 두는 저장장치의 특별한 공간이에요. (기출 Q9.1 C, D)

4) 메모리와 스왑 영역 사이에서 내용을 옮기는 과정을 ____이라고 한다.

스와핑이에요. (기출 Q9.1 E)

5) 스와핑이 자주 일어나면 RAM보다 훨씬 느린 ____를 계속 쓰게 되어 컴퓨터가 느려진다.

보조기억장치예요. RAM은 50~70ns, HDD는 5~20ms라서 차이가 아주 커요.

6) 코드를 고치지 않고 40GB 파일 때문에 생긴 렉을 해결하려면 CPU, RAM, HDD 중 ____를 40GB보다 크게 업그레이드해야 한다.

RAM이에요. CPU는 8코어로 충분하고 HDD는 1TB라 용량이 충분해요. 병목은 RAM이 데이터보다 작다는 것이에요. (기출 Q9.2)

7) 가상메모리를 같은 크기로 나눈 블록을 ____, 물리메모리(RAM)를 나눈 블록을 ____이라고 한다.

페이지, 프레임이에요. 두 블록의 크기는 같고, 그 크기가 페이지 크기예요(예 4KB = 4,096바이트).

8) 가상주소 = 페이지 번호 × ____ + ____ 이다.

페이지 크기, 오프셋(페이지 안의 위치)이에요.

9) 주소를 변환할 때 바뀌는 것은 페이지 번호에서 ____ 번호로의 대응뿐이고, ____은 그대로 유지된다.

프레임, 오프셋이에요. 페이지와 프레임의 크기가 같아서 블록 안의 위치는 변하지 않아요.

10) 최대 절전 모드는 전원을 끊기 전에 RAM 내용을 통째로 ____에 옮겨 두는 것인데, RAM이 ____성이기 때문이다.

스왑 영역, 휘발이에요. 다시 켜면 불러와서 이어서 해요.

② 순서대로 써 보기 기출 Q9에서 컴퓨터가 렉이 걸리는 흐름을 순서대로 써 보세요.

  • 가) 넘치는 부분이 보조기억장치의 스왑 영역으로 옮겨진다 (스와핑)
  • 나) 40GB 데이터가 프로세스의 가상메모리에 올라온다
  • 다) 느린 보조기억장치를 계속 쓰게 되어 컴퓨터가 거의 멈춘다
  • 라) 운영체제가 물리메모리(16GB)에 할당하려는데 용량이 모자라다
순서대로 써 보기 — 답 열기

나 → 라 → 가 → 다

가상메모리에 올림 → 물리메모리 할당 시도(모자람) → 스왑으로 쫓겨남(스와핑) → 느려짐이에요. 해결은 RAM 늘리기예요.

③ 계산 페이지 크기가 4,096바이트일 때 가상주소 8,300의 페이지 번호와 오프셋을 구해 보세요.

단계 풀이 보기 (종이에 먼저 풀어 본 뒤 열기)

8,300 ÷ 4,096을 해요. 몫이 2이고 2 × 4,096 = 8,192예요.

나머지는 8,300 − 8,192 = 108이에요.

페이지 번호 2, 오프셋 108이에요.

시험엔 이렇게 써요

가상메모리는 실제 메모리 크기와 관계없이 프로세스에 큰 메모리 공간을 제공하는 기술이다. 프로그램이 사용하는 메모리가 물리메모리(RAM) 용량을 초과하면 일부 데이터가 보조기억장치의 스왑 영역으로 이동하는데 이를 스와핑이라 하며, 접근 속도가 느린 보조기억장치를 계속 사용하므로 컴퓨터가 느려진다. 따라서 데이터 크기보다 큰 RAM(40GB 이상)으로 업그레이드해야 한다.

잠깐 확인 — 40GB 파일 렉을 코드 수정 없이 해결하려고 CPU 코어를 16개로 늘리면 도움이 될까요?

아니에요. 문제는 계산 능력이 아니라 RAM이 데이터보다 작은 것이에요. RAM 용량을 늘려야 스왑이 필요 없어져요.

9-7. 주소 변환 순서 — TLB, 페이지 테이블, 페이지 폴트, 캐시

교수님(7주차)이 가상주소가 TLB, 페이지 테이블, 스왑, 캐시를 거쳐 데이터가 되는 과정은 빈칸을 만들어 둘 테니 암기하라고 했어요. 올해 새로 나온 내용이라 기출에는 없지만 가장 확실한 빈칸 후보예요.

한 줄 흐름

TLB → 페이지 테이블 → (필요하면 스왑) → 물리주소 → 캐시 → 메모리

1단계는 주소 알아내기, 2단계는 데이터 가져오기예요.

① 빈칸 채우기 문장을 읽고 ____에 들어갈 말을 먼저 말하거나 써 본 뒤 눌러서 맞춰 보세요.

1) CPU가 데이터 하나를 읽는 일은 두 단계로 나뉜다. 1단계는 ____를 알아내는 것(가상주소 → 물리주소)이고, 2단계는 ____를 가져오는 것이다.

주소, 데이터예요. 교수님이 "주소를 알아야 데이터를 가져올 수 있다"고 설명했어요.

2) CPU가 가상주소로 메모리에 접근하면 주소 변환 정보를 가장 먼저 ____에서 찾는다.

TLB예요. 페이지 테이블보다 먼저 보는 빠른 메모장이에요.

3) TLB는 페이지 테이블에서 자주 쓰는 ____ 정보(페이지 → 프레임)를 캐시처럼 모아 둔 곳이며, 실제 데이터는 담지 않는다.

주소 변환이에요. 실제 데이터는 CPU 캐시에 있어요.

4) 주소 변환 정보가 TLB에 있으면 TLB ____, 없으면 TLB ____이다.

히트, 미스예요. 히트면 물리주소를 바로 얻어요.

5) TLB 미스가 나면 ____를 탐색한다.

페이지 테이블이에요. 페이지가 RAM의 어느 프레임에 대응되는지 적은 표이고 프로세스마다 하나씩 있어요.

6) 페이지 테이블에서 찾은 페이지가 RAM에 있으면 변환 정보를 ____에 등록(갱신)하고 물리주소를 얻는다.

TLB예요. 다음에 같은 페이지를 찾을 때 빠르게 하려는 거예요.

7) 필요한 페이지가 RAM에 없고 스왑 영역에 있으면 ____가 발생하고, 운영체제가 스왑에서 RAM으로 적재한 뒤 ____와 TLB를 갱신하고 다시 실행한다.

페이지 폴트, 페이지 테이블이에요. 이때 스왑과 RAM 사이의 이동이 스와핑이에요.

8) 물리주소를 얻은 뒤에는 ____에 먼저 접근해 히트이면 데이터를 바로 쓰고, 미스이면 ____에서 캐시 라인을 가져온다.

(CPU) 캐시, 메모리(RAM)예요. 필요한 한 칸만이 아니라 주변까지 한 묶음(캐시 라인)으로 가져와요.

9) 주소 변환에 쓰는 장치 중 실제 데이터가 들어 있는 것은 ____뿐이고, TLB와 페이지 테이블은 변환 정보를 담는다.

CPU 캐시예요. TLB는 "주소 변환 정보를 찾았나", 페이지 테이블은 "이 페이지가 RAM에 있나", 캐시는 "데이터가 캐시에 있나"를 묻는 장치예요.

10) 페이지는 RAM에 있지만 TLB에 변환 정보가 없을 때는 페이지 테이블을 탐색한 뒤 ____를 갱신한다.

TLB예요. 자료 20쪽 확인문제의 첫 줄이에요. 둘째 줄은 캐시 미스로 RAM에서 캐시 라인을 읽고 CPU 캐시를 갱신, 셋째 줄은 페이지 폴트로 OS가 RAM에 적재하고 페이지 테이블을 갱신해요.

② 순서대로 써 보기 TLB 미스가 나고, 페이지는 RAM에 있고, 캐시도 미스가 나는 경우의 순서를 써 보세요.

  • 가) 캐시 접근, 캐시 미스
  • 나) TLB 접근, TLB 미스
  • 다) 변환 정보를 TLB에 등록하고 물리주소를 얻는다
  • 라) 메모리(RAM)에서 데이터를 가져온다
  • 마) 페이지 테이블 접근, 페이지가 RAM에 있음
순서대로 써 보기 — 답 열기

나 → 마 → 다 → 가 → 라

TLB에서 못 찾으면 페이지 테이블로 가고, 변환을 마치면 TLB에 등록하며, 물리주소를 얻은 뒤 캐시를 보고, 캐시에도 없으면 메모리에서 가져와요.

② 순서대로 써 보기 (하나 더) 페이지 폴트가 나는 경우의 순서를 써 보세요.

  • 가) 스왑 영역의 페이지를 RAM에 적재한다 (스와핑)
  • 나) TLB 미스
  • 다) 페이지 테이블 접근, 페이지가 RAM에 없음 (페이지 폴트)
  • 라) 페이지 테이블과 TLB를 갱신하고 다시 실행한다
  • 마) TLB 접근
순서대로 써 보기 — 답 열기

마 → 나 → 다 → 가 → 라

TLB를 보고 → 미스 → 페이지 테이블에도 RAM에 없음 → OS가 스왑에서 RAM으로 적재 → 표와 TLB를 고치고 다시 해요. 그다음에 물리주소로 캐시를 봐요.

③ 계산 페이지 크기 4,096이고 페이지 테이블이 (페이지 0 → 프레임 7, 1 → 2, 2 → 9, 3 → 4)일 때 가상주소 10,000의 물리주소를 구해 보세요.

단계 풀이 보기 (종이에 먼저 풀어 본 뒤 열기)

10,000 ÷ 4,096 = 몫 2, 나머지 1,808이에요. (2 × 4,096 = 8,192이고 10,000 − 8,192 = 1,808)

페이지 테이블에서 페이지 2는 프레임 9예요.

물리주소 = 9 × 4,096 + 1,808 = 36,864 + 1,808이에요.

답은 38,672예요. 오프셋 1,808은 그대로이고 페이지 번호만 프레임 번호로 바뀌었어요.

시험엔 이렇게 써요

CPU가 가상주소로 메모리에 접근하면 먼저 TLB에서 주소 변환 정보를 찾는다. TLB 히트이면 물리주소를 바로 얻고, TLB 미스이면 페이지 테이블을 탐색한다. 페이지가 RAM에 있으면 TLB를 갱신하고, RAM에 없으면 페이지 폴트가 발생하여 운영체제가 스왑 영역의 페이지를 RAM에 적재하고 페이지 테이블과 TLB를 갱신한다. 물리주소를 얻은 뒤에는 캐시에 접근하여 히트이면 데이터를 사용하고, 미스이면 메모리에서 데이터를 가져온다.

잠깐 확인 — TLB 미스가 나면 반드시 페이지 폴트가 발생하나요?

아니에요. 페이지가 RAM에 있으면 페이지 테이블로 정상 변환해요. 페이지가 RAM에 없을 때만 페이지 폴트가 나요.

9-8. 보조기억장치 (기출 Q10)

기출 10번이 빈칸 9개로 이 부분 전체를 물었어요. 원리 3가지, 파티션과 RAID의 차이, SSD와 HDD의 쓰임새를 문장째 떠올려 보세요.

함정 보기

섹터·트랙·실린더는 HDD 디스크의 구조 이름이에요. 포맷은 데이터를 지우고 초기화하는 일이에요. RAM과 레지스터는 보조기억장치가 아니에요. 기출 Q10 보기에 이 말들이 섞여 있었어요.

① 빈칸 채우기 문장을 읽고 ____에 들어갈 말을 먼저 말하거나 써 본 뒤 눌러서 맞춰 보세요.

1) 보조기억장치는 저장 원리로 구분한다. HDD는 ____ 성질, CD-ROM은 ____ 성질, SSD는 ____ 성질을 이용한다.

자기적, 광학적, 전자적이에요. 자석의 N극·S극, 레이저 반사, 플래시 메모리의 전기 상태로 0과 1을 구분해요. (기출 Q10.1~10.3)

2) 보조기억장치는 전원이 꺼져도 데이터가 남는 ____성이고, 용량은 크지만 접근 속도는 ____.

비휘발, 느리다예요. CPU가 직접 접근하지 못하고 RAM에 올라온 다음에야 일해요.

3) HDD는 판(디스크)을 돌리고 ____를 물리적으로 움직여 읽고 쓰기 때문에 SSD보다 느리다.

헤드예요. 레코드판과 바늘에 비유해요. 기계 동작이 필요해서 전기 신호만 쓰는 반도체보다 느려요.

4) HDD 판 위의 동심원 한 줄을 ____이라고 하고, 그것을 잘게 나눈 조각으로 한 번에 읽고 쓰는 최소 단위를 ____라고 한다.

트랙, 섹터예요. 여러 판에서 위치가 같은 트랙의 묶음은 실린더예요.

5) SSD는 ____ 플래시 메모리로 만든 반도체 저장장치이며, 읽기·쓰기의 최소 단위는 ____, 지우기의 최소 단위는 ____이다.

NAND, 페이지, 블록이에요. 페이지 여러 개가 모여 블록 하나가 돼요.

6) SSD는 HDD보다 읽기/쓰기가 ____ 같은 용량의 가격은 ____.

빠르지만, 비싸다예요. 움직이는 부품이 없어서 빠르고 조용해요. (기출 Q10.6)

7) 그래서 운영체제처럼 자주 쓰는 것은 ____에, 동영상·사진처럼 자주 안 쓰는 것은 ____에 보관하면 효율적이다.

SSD, HDD예요. 빠르고 비싼 쪽에 자주 쓰는 것을, 느리고 싼 쪽에 덜 쓰는 것을 두는 계층 구조 생각이에요. (기출 Q10.8, 10.9)

8) 보조기억장치 여러 개를 하나의 논리적 저장장치로 묶어 용량과 성능을 개선하는 것을 ____, 하나를 작은 공간 여러 개로 나누어 쓰는 것을 ____라고 한다.

RAID, 파티션이에요. 서로 반대 방향이에요. (기출 Q10.4, 10.5)

9) RAID-0은 데이터를 나눠 저장하는 ____으로 빠르지만 고장에 약하고, RAID-1은 똑같이 복사하는 ____으로 안전하며, RAID-5는 ____를 디스크에 분산 저장해 속도와 안정성을 절충한다.

스트라이핑, 미러링, 패리티예요. 교수님이 RAID 0, 1, 5를 주로 쓴다고 했어요. RAID 2·3·4는 넘어가도 돼요.

10) 디스크를 파티션으로 나눠 두면 ____ 파티션만 포맷하고 다시 설치해도 다른 파티션의 자료는 그대로 남는다.

운영체제예요. 방을 통째로 청소하는 것과 칸막이 방 하나만 청소하는 차이예요.

② 순서대로 써 보기 HDD, CD-ROM, SSD를 접근 속도가 빠른 순서로 써 보세요.

  • 가) HDD (5~20ms)
  • 나) CD-ROM (50~200ms)
  • 다) SSD (20~200µs)
순서대로 써 보기 — 답 열기

SSD는 µs 단위, HDD는 ms 단위, CD-ROM은 HDD보다 더 느린 수십~수백 ms예요. 기계로 움직이는 부분이 많을수록 느려요.

③ 계산 4TB 디스크 5개를 RAID-5로 묶으면 쓸 수 있는 용량은 얼마일까요? (교수님이 든 예)

단계 풀이 보기 (종이에 먼저 풀어 본 뒤 열기)

RAID-5는 패리티 한 개 몫을 빼요.

(디스크 수 − 1) × 디스크 용량 = (5 − 1) × 4TB예요.

답은 16TB예요. 같은 디스크 4TB 4개를 RAID-0으로 묶으면 16TB, 2개를 RAID-1로 묶으면 4TB, 5개를 RAID-6으로 묶으면 12TB예요.

시험엔 이렇게 써요

HDD는 자기적, CD-ROM은 광학적, SSD는 전자적 성질을 이용한다. SSD는 HDD보다 읽기/쓰기가 빠르지만 같은 용량에 가격이 비싸다. 그래서 운영체제처럼 자주 쓰는 것은 SSD에, 동영상·사진처럼 자주 쓰지 않는 것은 HDD에 보관한다. RAID는 여러 보조기억장치를 하나의 논리적 저장장치로 묶는 것이고, 파티션은 하나를 작은 공간으로 나누는 것이다.

잠깐 확인 — RAID-1은 어떤 기술을 쓰고 장점과 단점은 무엇인가요?

이 장 3줄 요약
  • 기출은 읽는 문제가 아니라 빈칸을 쓰는 문제예요. 읽기보다 직접 떠올리기가 오래 남으니, 문장을 가리고 말한 뒤에 눌러 보세요.
  • 교수님이 찍어 준 3곳은 CPU 5단계(인출·해독·실행·데이터·기록), 레이턴시와 대역폭 구분, 주소 변환 순서(TLB → 페이지 테이블 → 스왑 → 물리주소 → 캐시 → 메모리)예요.
  • 손계산은 세 가지예요. 자릿값 128 64 32 16 8 4 2 1로 이진수 변환, 전가산기는 1의 개수 세기, 가상주소는 페이지 번호 × 페이지 크기 + 오프셋이에요.
