컴퓨터 구조 소개 — 부품이 서로 어떻게 일하는가

이 장은 중간고사 1번(빈칸 채우기), 2번(6대 부품), 3번(sum.py 실행 과정)이 모두 나오는 곳이에요. 컴퓨터가 어떤 설계로 동작하는지(폰노이만 구조), 어떤 부품이 있는지, CPU가 왜 멀티코어가 되었는지, 프로그램과 프로세스가 어떻게 다른지를 차례로 배워요.

1-1. 폰노이만 구조 ★★★

컴퓨터를 만들려면 두 가지가 필요해요. 하나는 어떻게 계산할지에 대한 설계(논리적 구조)이고, 다른 하나는 그 설계를 실제 기계로 만드는 일(물리적 구현)이에요. 이 중 설계에 해당하는 것이 폰노이만(Von Neumann) 구조예요.

컴퓨터 구현의 2요소내용
논리적 구조 설계폰노이만 구조
물리적 기기 구현전자 컴퓨터(전기·전자 신호를 이용), 양자 컴퓨터(양자역학 원리를 이용)
한 줄 정의

폰노이만 구조 = 프로그램과 데이터를 주기억장치(RAM)에 저장하고, 명령어를 한 개씩 CPU로 가져와 실행(계산)하는 구조. 이렇게 프로그램을 기억장치 안에 넣어 두기 때문에 "프로그램 내장형 컴퓨터"라고도 불러요.

폰노이만 구조를 이루는 부분은 다섯 가지예요. 원래 핵심은 CPU와 메모리 둘뿐이었는데, 쓰기 편하도록 저장장치와 입출력장치가 붙었어요.

구성 요소기능
중앙처리장치(CPU)제어 및 연산. 계산하고 전체를 지휘해요
주기억장치(RAM)실행 중인 프로그램과 데이터를 저장해요
보조기억장치(SSD, HDD)실행이 끝난 프로그램과 데이터를 영구 저장해요
입출력장치컴퓨터와 사용자의 인터페이스. 입력은 마우스·키보드, 출력은 모니터
시스템 버스(system bus)구성 요소들 사이에서 데이터가 오가는 전달 경로(data path)
비유 — 주방

요리사(CPU)가 조리대(RAM) 위에 레시피(프로그램)와 재료(데이터)를 펼쳐 놓고, 레시피를 한 줄씩 읽으며 요리해요. 쓰지 않는 재료와 레시피 책은 창고(SSD·HDD)에 두고요. 요리사가 아무리 유능해도, 레시피가 조리대에 올라와 있어야 요리를 시작할 수 있어요.

왜 이런 구조가 중요할까요? 이 구조 덕분에 프로그램이 아무리 길어도(천 줄, 만 줄, 십만 줄) 한 줄씩 CPU로 가져와 실행하면 되기 때문이에요. 하드웨어는 그대로 두고 프로그램만 바꿔 끼우면 전혀 다른 일을 시킬 수 있어요.

시험엔 이렇게 써요

계산장치(CPU)와 기억장치로 구성되어서, 계산장치가 기억장치의 프로그램에서 한 줄씩 실행하여 계산 결과를 기억장치에 기록하는 방식으로 동작하는 현대의 컴퓨터 구조를 폰노이만 구조라고 한다. (2023 기출 1번 빈칸 정답은 "폰노이만 구조"예요)

잠깐 확인 — 폰노이만 구조의 핵심 두 가지는 무엇인가요?

① 프로그램과 데이터를 RAM에 저장한다. ② 명령어를 한 개씩 CPU로 가져와 실행한다. 이 두 줄이 전부예요.

1-2. 프로그램이 실행되는 과정 — sum.py 따라가기 ★★★

3번 문제는 코드 한 줄이 컴퓨터 안에서 어떻게 움직이는지 묻는 문제예요. 먼저 큰 흐름을 외우고, 그다음 시험에 나온 코드를 손으로 따라가 볼게요.

  • ① 실행 전 : 프로그램(sum.py)과 파이썬 실행기는 보조기억장치(SSD)에 저장돼 있어요. 이때는 "보관만 된(비활성)" 상태예요.
  • ② 실행 : 실행하면 코드가 주기억장치(RAM)에 적재(load)돼요. 이제 "활성" 상태예요.
  • ③ 번역 : RAM의 코드 한 줄을 파이썬 인터프리터(실행기)가 기계어(0과 1)로 바꿔요. 파이썬 코드는 CPU로 바로 갈 수 없어요.
  • ④ 계산 : 기계어가 CPU(ALU)로 전달돼 계산해요.
  • ⑤ 기록 : 계산 결과(변수 값)를 RAM의 데이터 영역에 기록하고, 다음 줄로 넘어가 ③~⑤를 반복해요.

번역 단계는 2주차에 교수님이 생략했다가 3주차에 정정해서 넣은 부분이에요. 기계어와 거의 1대 1로 대응되는 사람이 읽을 수 있는 언어가 어셈블리어예요. RAM 안은 두 영역으로 나뉜다고 생각하세요. 코드가 올라가는 코드 영역과, 변수 값이 적히는 데이터 영역이에요.

비유 — 시나리오와 배우

교수님은 프로그램을 "계산 시나리오"라고 했어요. 시나리오(프로그램)가 나오면 배우(CPU)가 그 대본을 한 줄씩 연기해요. 파이썬 인터프리터는 외국어 대본을 배우가 알아듣는 말로 한 줄씩 통역해 주는 통역사예요.

이제 2023 기출 3번에 나온 코드를 볼게요.

1. n = 1; 2. sum = 0; 3. while (n <= 100): 4. sum = sum + n 5. n = n + 1
코드 줄무슨 뜻인가요
n = 1;n이라는 이름의 칸을 만들고 1을 넣어요 (끝의 ;은 줄 끝 표시일 뿐이에요)
sum = 0;sum이라는 칸을 만들고 0을 넣어요
while (n <= 100):"n이 100 이하인 동안" 아래 두 줄을 반복해요. 조건 판단 명령이에요
sum = sum + n오른쪽을 먼저 계산(sum 값 + n 값)해서 그 결과를 sum 칸에 넣어요
n = n + 1n 값에 1을 더해 n 칸에 다시 넣어요

이 코드에는 print가 없어서 화면에 출력되는 것은 아무것도 없어요. 대신 RAM의 변수 칸에 값이 남아요. 손으로 따라간 결과는 아래와 같아요.

줄하는 일RAM의 변수 칸 (실행 후)
1n 칸 만들고 1 기억n = 1
2sum 칸 만들고 0 기억n = 1, sum = 0
31 <= 100 이 참이니 아래로변화 없음
40 + 1 = 1 을 sum에n = 1, sum = 1
51 + 1 = 2 를 n에n = 2, sum = 1
32 <= 100 참, 다시 반복변화 없음
4~5sum = 1 + 2 = 3, n = 3n = 3, sum = 3
…계속 반복…
끝n이 101이 되면 조건이 거짓이라 반복 종료n = 101, sum = 5050

시험 문제는 이 흐름에서 빈칸을 뽑은 거예요. 변수가 어느 줄에서 처음 만들어지는지만 따라가면 풀려요.

빈칸정답이유
A보조기억장치실행 전에는 저장장치에 있어요
B주기억장치실행하면 RAM에 적재돼요. 변수 값도 RAM에 기억돼요
CCPU기계어를 받아 실행하는 곳이에요
D, vn, 11번째 줄 n = 1
E, wsum, 02번째 줄 sum = 0
x1003번째 줄 n <= 100 조건의 오른쪽 값
y14번째 줄 sum = 0 + 1
z25번째 줄 n = 1 + 1 (변수는 D=n)
손으로 따라가는 요령

① 변수 칸 표(n, sum)를 먼저 그려요. ② 줄 번호 순서대로 한 줄씩 칸의 값을 고쳐 써요. ③ =는 "같다"가 아니라 "오른쪽을 계산해서 왼쪽 칸에 넣는다"예요. ④ 반복문은 첫 바퀴만 정확히 하면 나머지는 규칙이 보여요.

시험엔 이렇게 써요

sum.py는 보조기억장치(SSD)에 저장되어 있다가 실행되면 파이썬 실행기와 함께 주기억장치(RAM)에 적재된다. 실행기가 코드를 한 줄씩 해석하여 기계어로 CPU에 전달하면 CPU가 계산을 실행하고, 그 결과(변수 값)가 다시 RAM에 기록된다. 이 과정이 반복되며, 프로그램이 종료되면 RAM의 코드와 데이터는 사라지고 출력 결과만 남는다.

잠깐 확인 — 위 코드에서 3번째 줄(while)은 어떤 명령이고, CPU가 하는 일은 무엇인가요?

조건 판단 명령이에요. CPU가 n 값이 100 이하인지 비교해서 참이면 4, 5번째 줄로 넘어가고 거짓이면 반복을 끝내요.

1-3. 컴퓨터의 6대 부품과 역할 ★★★

컴퓨터 본체를 열면 부품이 여러 개 보이지만, 시험에 나오는 핵심은 6가지예요. 교수님은 실제 본체를 들고 와서 보여 줬고, 조립 사진 자료도 나눠 줬어요. 아래 사진에서 위치를 먼저 눈에 익혀 두세요.

비유 — CPU와 GPU

CPU는 어려운 문제를 하나씩 척척 푸는 수학 천재 한 명이에요. GPU는 쉬운 계산을 수천 명이 한꺼번에 푸는 부대예요. 사진이나 딥러닝처럼 같은 계산을 엄청나게 많이 반복하는 일은 부대가 훨씬 빨라요.

부품 말고도 쿨러(CPU의 열을 식히는 팬)와 케이스(껍데기)가 있어요. 키보드·마우스·모니터는 본체 밖의 입출력장치예요. 6대 부품에는 들어가지 않아요.

사진 문제 푸는 법이에요. 2023 기출 2.1번은 본체 사진에 빈칸 6개를 두고 부품 번호를 쓰게 했어요. 위치로 찾으면 돼요. 위쪽 상자는 파워, 둥근 팬이 달린 곳은 CPU, 그 옆 얇은 막대는 RAM, 아래의 큰 카드는 그래픽카드, 오른쪽 상자는 SSD, 판 전체는 메인보드예요.

전원공급장치(파워)예요. 콘센트의 교류 전기를 컴퓨터 부품이 쓰는 직류로 바꿔 줘요.

1-4. 조립 순서와 내 컴퓨터 사양 읽기 (실습)

교수님은 부품이 어떻게 조립되는지도 사진으로 보여 줬어요. 순서는 아래와 같아요. 교수님 요약은 "선만 잘 연결하고 선 정리만 잘하면 된다"예요.

  • ① CPU 장착 : 메인보드의 CPU 자리에 CPU를 꽂아요.
  • ② 써멀 그리스 도포 : CPU 위에 열 전달을 돕는 그리스를 발라요. CPU와 쿨러 사이의 빈틈을 메워 열이 잘 빠지게 해요.
  • ③ CPU 쿨러 장착 : 열을 식히는 팬을 달아요.
  • ④ RAM 장착 : 메인보드의 RAM 슬롯에 꽂아요.
  • ⑤ SSD, 그래픽카드 연결 : SSD는 판(M.2)이거나 선으로 연결해요. 그래픽카드는 PCI 슬롯에 꽂아요.
  • ⑥ 파워 연결 : 파워의 선들을 메인보드와 부품에 연결하고 전원을 켜요.

조립을 끝냈다고 바로 쓸 수 있는 것은 아니에요. 윈도우나 리눅스 같은 운영체제를 설치해야 비로소 쓸 수 있어요.

내 컴퓨터가 어떤 부품으로 이루어졌는지 보는 프로그램도 배웠어요. 윈도우는 CPU-Z나 Speccy, 맥은 MacCPUID예요. 읽는 법은 이래요.

모든 컴퓨터는 폰노이만 구조를 따르기 때문에 구성은 똑같고 사양만 달라요. 이 실습의 요지가 이 문장이에요.

시험엔 이렇게 써요

(서술형 요령) "내 컴퓨터의 주요 부품"을 쓸 때는 CPU(모델과 코어·스레드), RAM(종류와 용량), 메인보드, VGA(그래픽카드) 순으로 이름을 적고, 각 부품의 기능을 한 줄씩 덧붙여요.

잠깐 확인 — DDR5 16GB에서 5와 16은 각각 무엇을 뜻하나요?

5는 RAM의 세대(규격 버전), 16GB는 용량이에요.

1-5. 휘발성과 비휘발성 — RAM과 보조기억장치 ★★

휘발성은 전원이 꺼지면 데이터가 사라지는 성질이고, 비휘발성은 전원이 꺼져도 데이터가 남는 성질이에요. 휘발유가 날아가듯 사라진다는 뜻이에요.

RAM (주기억장치)SSD · HDD (보조기억장치)
성질휘발성 — 전원을 끄면 사라져요비휘발성 — 전원을 꺼도 남아요
역할실행 중인 프로그램 코드와 데이터실행이 끝난 프로그램과 데이터를 영구 저장
속도빠르지만 비싸서 용량이 작아요 (예 16GB)느리지만 싸서 용량이 커요 (예 512GB~수 TB)
비유책상 위도서관
비유 — 책상과 도서관

시험공부를 하러 도서관(SSD)에 가서 필요한 책만 골라 책상(RAM)에 올려놓고 공부해요. 공부를 마치면 책상을 싹 치우죠. 책상은 작고 빠르게 쓰고, 도서관은 크고 오래 보관하는 곳이에요. 컴퓨터를 끄는 것은 책상 위를 싹 치우는 일이고, 도서관 책은 그대로 있어요.

왜 기억장치를 둘로 나눴을까요? 빠르면서 용량도 크고 싼 메모리는 만들 수 없기 때문이에요. 그래서 "빠른 일은 RAM이, 오래 보관하는 일은 저장장치가 맡자"고 역할을 나눴어요.

교수님은 컴퓨터가 렉에 걸리는 이유도 여기에서 설명했어요. 프로그램이 쓰는 데이터가 RAM보다 커지면 저장장치의 일부를 RAM 대신 쓰는데, 저장장치는 훨씬 느려서 계산이 그 앞에서 발목이 잡혀요. 그래서 데이터가 RAM에 다 들어가는지가 중요해요. 이 내용은 메모리 장에서 더 자세히 다뤄요.

시험엔 이렇게 써요

RAM은 휘발성 기억장치로 전원이 꺼지면 데이터가 사라지며 수행 중인 프로그램 코드와 데이터를 보관한다. SSD·HDD 같은 보조기억장치는 비휘발성 기억장치로 전원이 꺼져도 데이터를 반영구 보관한다.

잠깐 확인 — 컴퓨터를 껐다 켜면 RAM과 SSD 중 어느 쪽 내용이 남아 있나요?

SSD예요. RAM은 휘발성이라 전원이 꺼지면 모두 사라지고, SSD는 비휘발성이라 그대로 남아요.

1-6. 무어의 법칙과 황의 법칙 ★★

먼저 집적도라는 말부터 알아야 해요. 집적도는 칩(CPU) 안에 트랜지스터(반도체 스위치)가 얼마나 많이 들어 있는가예요. 뇌 세포가 많을수록 똑똑하듯, 트랜지스터가 많을수록 CPU 성능의 한계치가 높아져요.

한 줄 정의

무어의 법칙 = 반도체(CPU)의 집적도가 약 24개월(2년)마다 2배씩 증가한다는 경험 법칙. 인텔의 공동 창업자 고든 무어가 말했어요. (녹취에는 이름이 다르게 적혀 있지만 음성 인식 오류예요)

2년마다 2배이면 10년이면 32배(2의 5제곱), 20년이면 약 1000배(2의 10제곱)가 돼요. 이런 증가를 기하급수적이라고 해요. 이 속도가 1970년대부터 2000년대 초반까지 이어졌어요.

비유 — 접어서 넣는 옷장

같은 크기의 옷장에 옷을 2년마다 두 배로 접어 넣는다고 생각해 보세요. 옷장 크기(칩 크기)는 그대로인데 들어가는 옷(트랜지스터)이 해마다 늘어나서 옷장이 점점 똑똑해지는 거예요.

시험에서는 비슷한 이름의 황의 법칙이 함께 보기로 나와서 헷갈리기 쉬워요. 교수님 설명으로 둘을 비교하면 이래요.

무어의 법칙황의 법칙
어느 부품CPU (반도체 집적도)메모리 (RAM)
내용집적도가 2년마다 2배메모리가 얼마나 빨리 발전해 왔는가를 말하는 법칙
이름의 주인인텔 창업자 무어삼성전자 CEO를 지낸 황 씨

참고로 황의 법칙은 일반적으로 "메모리 용량이 1년에 2배씩 늘어난다"고 알려져 있어요. 교수님은 숫자까지는 말하지 않았고 "메모리는 황의 법칙, CPU는 무어의 법칙"이라는 구분을 강조했어요.

외우기 팁

문제에 "집적도"와 "2년마다 2배"가 나오면 무조건 무어예요. 황은 메모리 쪽이에요.

시험엔 이렇게 써요

집적회로의 반도체 집적도가 2년마다 2배씩 증가한다는 것을 무어의 법칙이라고 한다. (2023 기출 1번 빈칸 정답)

잠깐 확인 — "집적도가 2년마다 2배"는 무어의 법칙과 황의 법칙 중 무엇인가요?

무어의 법칙이에요. 황의 법칙은 메모리 쪽 법칙이라서 구분해야 해요.

1-7. 클럭, 온도, 오버클럭 ★★

클럭(clock)은 CPU가 계산 신호를 바꾸는 박자예요. 단위는 헤르츠(Hz)이고 G(기가)는 10억을 뜻해요.

그래서 3GHz는 1초에 약 30억 번을 뜻해요. 사람은 1초 단위로 생각하지만 CPU는 약 30억분의 1초 단위로 생각해요. 다만 이것은 최대 속도이고 매번 계산을 다 하지는 못해요.

(녹취에는 "35번, 35분의 1초"로 적혀 있지만, 음성 인식 오류예요. 30억이 맞아요.)

CPU의 성능은 이 클럭을 높일수록 좋아졌어요. 그런데 클럭을 높이면 문제가 생겨요.

  • CPU 안의 수십억 개 트랜지스터가 초당 수십억 번 움직이니 전류가 많이 흐르고 전력 소모와 열이 커져요.
  • CPU 칩은 보통 100도 아래에서 동작하도록 만들어져요. 쿨러를 달아도 100도를 넘으면 회로가 탈 수 있어요.
  • 그래서 2000년대 초에 클럭을 계속 올리는 경쟁이 끝났어요. 가장 큰 원인이 온도예요.
비유 — 전력 질주

100미터 달리기는 빨라도 오래 전력 질주하면 몸에 열이 나고 숨이 차서 멈춰야 해요. 클럭을 높이는 것은 CPU를 더 빨리 뛰게 하는 것이라서 열이 나고, 쿨러는 땀을 식혀 주는 부채질이에요.

오버클럭(overclock)은 제조사가 정한 것보다 클럭을 억지로 더 높여서 쓰는 일이에요. 성능은 올라가지만 발열과 전력이 크게 늘어서 고장 위험이 커져요. 교수님이 따로 설명하지는 않았고 2023 기출 1번 보기에 있어서 뜻만 알아 두면 돼요.

그래서 CPU의 발전은 2000년대 초에 방향을 바꿨어요. 클럭을 올리는 대신 계산 장치를 여러 개 넣는 멀티코어로 갔어요. 다음 소단원에서 이어져요.

시험엔 이렇게 써요

CPU 클럭이 높아질수록 일반적으로 전력 소모와 발열이 증가하여 CPU의 온도가 상승하며, 이것은 CPU 클럭을 무한정 높일 수 없게 하는 주요 요인이다. (2023 기출 1번 빈칸 정답은 "온도")

잠깐 확인 — 클럭을 무한정 높이지 못하는 가장 큰 이유는 무엇인가요?

온도(발열)예요. 클럭이 오르면 전력 소모와 열이 늘어 칩이 버틸 수 없게 돼요.

1-8. 싱글코어, 멀티코어, 하이퍼스레딩 ★★

CPU 안에는 실제로 계산을 하는 연산 장치(ALU)가 들어 있어요. 이 연산 장치 하나를 코어(core)라고 불러요. 코어가 몇 개 들어 있느냐로 CPU를 나눠요.

종류뜻시기
싱글코어하나의 CPU 안에 연산 장치가 1개2000년대 초까지
멀티코어하나의 CPU 안에 연산 장치가 여러 개 (듀얼 2, 쿼드 4, 옥타 8 …)2000년대 초반부터 지금
비유 — 주방의 요리사

싱글코어는 요리사 1명이 일하는 주방이에요. 더 빨리 만들려고 요리사를 더 빠르게 움직이게 했더니(클럭) 몸이 달아올라서 한계에 부딪혔어요. 그래서 요리사를 4명, 8명으로 늘렸어요. 이것이 멀티코어예요.

멀티코어가 더해진 아이디어가 하이퍼스레딩(hyper-threading)이에요. 파이프라인이라는 기술로 코어 하나가 명령 2개를 동시에 처리하게 해서, 코어를 가상으로 두 배로 늘려 줘요. 이렇게 늘어난 가상 코어를 스레드(쓰레드)라고 해요.

  • 코어 : 실제로 있는 물리적 연산 장치예요.
  • 스레드 : 하이퍼스레딩으로 만든 가상의 코어 수예요. 보통 코어 수의 2배예요.
  • 요즘 노트북은 8코어 16스레드가 흔하고, 서버용은 64코어 128스레드까지 나온다고 교수님이 말했어요 (대략적인 수치예요).

왜 코어를 여러 개 두면 좋을까요? 클럭을 못 올려도 일을 나눠서 동시에 처리하면 전체 속도가 올라가기 때문이에요. 노트북 사양에서 보이는 "코어"와 "스레드"는 바로 이 숫자예요.

시험엔 이렇게 써요

싱글 코어는 하나의 CPU 안에 연산 장치가 1개 있는 것이며, 멀티 코어는 하나의 CPU 안에 연산 장치가 여러 개 있는 것이다. (2023 기출 1번 빈칸 정답)

잠깐 확인 — "4코어 8쓰레드" CPU에서 실제 물리적 연산 장치는 몇 개인가요?

4개예요. 하이퍼스레딩으로 8개처럼 동작하지만 실제 연산 장치는 4개예요.

1-9. 프로그램과 프로세스 ★★★

1번 문제의 빈칸 중 헷갈리는 쌍이에요. 기준은 하나예요. 어디에 있는가예요.

프로그램 (program)프로세스 (process)
상태저장장치에 보관된 코드 (정적)실행되어 메모리에 올라온 것 (동적)
위치보조기억장치(SSD·HDD)주기억장치(RAM)
예설치만 해 둔 팟플레이어, 워드더블클릭으로 실행해 작업 중인 팟플레이어, 워드
비유레시피(요리법)요리를 하는 중인 일 (조리 후 요리)
한 줄 정의

프로그램 = 보조기억장치에 보관된 코드, 프로세스 = 그 코드가 실행되어 메모리에 적재된 것. 운영체제도 실행 중이면 프로세스 하나예요.

같은 프로그램을 두 번 실행하면 프로세스는 두 개가 돼요. 메모장을 세 번 켜면 프로그램은 하나지만 프로세스는 세 개예요. 윈도우의 작업 관리자 화면에 보이는 것들이 지금 돌고 있는 프로세스예요.

헷갈리는 세 단어

프로그램은 저장된 코드, 프로세스는 실행 중인 소프트웨어, 프로세서는 CPU(하드웨어)예요. 글자 한 글자 차이라서 시험에서 헷갈리게 내요. "프로세서(서)는 장치, 프로세스(스)는 실행 중 소프트웨어"로 외우세요.

시험엔 이렇게 써요

어떤 응용 프로그램의 코드가 보조기억장치에 보관되어 있으면 프로그램이라 하고, 그것이 실행되어 메모리에 적재되어 있으면 프로세스라고 한다. (2023 기출 1번 빈칸 정답)

잠깐 확인 — 워드를 SSD에 설치만 했을 때와 더블클릭해서 실행했을 때, 각각 무엇으로 부르나요?

설치만 했을 때는 프로그램, 실행하면 프로세스예요.

1-10. 멀티태스킹, 멀티프로그래밍, 멀티프로세싱, 멀티쓰레딩 ★★★

이름이 모두 "멀티"로 시작해서 헷갈려요. 먼저 옛날이야기부터 알아 봐요. 아주 옛날 컴퓨터는 한 번에 프로그램 하나만 실행할 수 있었어요(일괄 처리 방식).

불편해서 시분할 방식이 나왔어요. 여러 프로세스가 CPU를 아주 짧은 시간씩 번갈아 쓰게 한 거예요.

CPU는 30억분의 1초 단위로 일하기 때문에, 계산기와 파워포인트를 번갈아 돌려도 사람 눈에는 동시에 도는 것처럼 보여요. 이렇게 짧게 번갈아 바꾸는 일을 컨텍스트 스위치(전환)라고 해요.

multitasking		여러 서로 다른 프로그램(프로세스)이 동시에 실행되는 것처럼 만드는 운영체제의 기술. 싱글코어에서는 시분할로, 멀티코어에서는 코어별로 나눠 맡겨요게임을 켜 놓고 크롬으로 검색하고 녹화 프로그램도 켜 두기
멀티프로그래밍
multiprogramming		여러 프로그램을 메모리에 동시에 올려 두고 CPU가 놀지 않게 번갈아 실행하는 방식. 멀티태스킹의 바탕이 되는 개념이에요책상에 여러 과목 책을 펴 놓고 번갈아 공부
멀티프로세싱
multiprocessing		하나의 일을 여러 개의 프로세스로 나눠 병렬로 실행크롬 창을 여러 개 따로 띄우기
멀티쓰레딩
multithreading		프로세스는 하나만 두고 그 안에서 여러 흐름(스레드)을 병렬로 실행크롬 한 창 안에 탭을 여러 개 띄우기

교수님은 멀티태스킹과 멀티프로그래밍은 "크게 안 써도 될 것 같다"고 했어요. 다만 2023 기출 1번의 보기에 있었으니 뜻만 한 줄씩 알아 두세요. 정말 중요한 것은 멀티프로세싱과 멀티쓰레딩의 차이예요.

교수님이 든 크롬 예시는 이래요. 크롬 창 2개를 띄우고 한 창에 탭 6개, 다른 창에 탭 4개가 있으면, 프로세스는 2개이고 스레드는 총 10개예요.

왜 이런 걸 따질까요? 빅데이터를 처리할 때 병렬 처리를 해야 시간을 줄일 수 있기 때문이에요. 예를 들어 400GB 자료를 40GB씩 10조각으로 나눠 동시에 처리하면, 순서대로 40시간 걸릴 일이 4시간으로 줄어요(교수님이 든 예시 숫자예요).

이때 조각마다 프로세스를 만들면 멀티프로세싱이고, 프로세스 하나 안에서 흐름을 나누면 멀티쓰레딩이에요. 교수님은 파이썬에서는 병렬 처리에 보통 멀티프로세싱을 쓴다고 말했어요.

외우기 팁

"프로세스 개수를 늘리면 멀티프로세싱, 프로세스 하나 안에서 흐름을 늘리면 멀티쓰레딩"이에요. 창 여러 개 = 프로세싱, 탭 여러 개 = 쓰레딩으로 그림을 떠올리세요.

시험엔 이렇게 써요

병렬처리 기법 중에서 하나의 프로그램을 여러 개의 프로세스로 병렬 실행시키는 것을 멀티 프로세싱이라고 하며, 하나의 프로세스 안에서 여러 흐름으로 병렬 실행하는 것을 멀티 쓰레딩이라고 한다. (2023 기출 1번 빈칸 정답)

잠깐 확인 — 크롬 창 하나 안에 탭을 여러 개 띄우는 것은 멀티프로세싱과 멀티쓰레딩 중 무엇에 가까운가요?

멀티쓰레딩이에요. 프로세스(창)는 하나이고 그 안에서 탭(스레드)이 여러 개 돌아가기 때문이에요.

1-11. 운영체제(OS) ★★

컴퓨터를 켜면 가장 먼저 실행되는 프로그램이 운영체제(OS, Operating System)예요. 운영체제는 SSD에 설치돼 있다가 전원을 켜면 RAM에 올라와서, 이후에 실행하는 모든 응용 프로그램과 부품을 관리해요. 종류는 윈도우, 리눅스, macOS가 대표적이에요.

한 줄 정의

운영체제 = 컴퓨터 전원이 켜지면 가장 먼저 시작되며, 컴퓨터 자원을 관리하고 여러 응용 프로그램의 실행을 관리하는 프로그램.

강의자료가 정리한 운영체제의 주요 관리 일은 아래와 같아요. 이 중 프로세스 관리, 주기억장치(메모리) 관리가 교수님이 강조한 두 가지예요.

관리 대상하는 일
프로세스 관리프로세스를 만들고, 없애고, 잠시 멈추고, 계속하게 해요
작업 관리작업의 순서와 우선순위를 정해요
주기억장치 관리프로세스마다 RAM 공간을 나눠 주고(할당), 끝나면 거둬들여요(회수)
보조기억장치 관리저장장치를 효율적으로 쓰게 해요
입출력장치·파일·보안 관리키보드, 모니터 같은 장치와 파일, 보안을 관리해요
비유 — 카페의 바리스타

강의자료의 비유예요. 손님이 커피 머신을 직접 만지면 사용법도 알아야 하고 기계가 망가질 수 있어요. 그래서 바리스타(운영체제)에게 부탁해요. 응용 프로그램도 부품(하드웨어)을 직접 만지지 않고 운영체제에 부탁해서 쓰고, 운영체제는 여러 손님의 주문이 뒤엉키지 않게 순서를 정해 줘요.

왜 운영체제가 메모리를 관리해야 할까요? 컴퓨터마다 RAM 용량이 4GB, 8GB, 16GB로 다 다르고, 한꺼번에 프로세스 여러 개가 RAM을 나눠 써야 하기 때문이에요. 서로의 공간을 침범하면 오류가 나니까 운영체제가 정리해 줘요.

그래서 프로그램을 만드는 사람은 "RAM이 거의 무한한 것처럼" 코드를 짜요. 이것이 가상 메모리의 아이디어이고, 실제 RAM에 맞춰 배치하는 일은 운영체제가 맡아요. RAM이 모자라면 저장장치(SSD)의 일부를 임시 공간으로 쓰는데, 이 영역이 스왑(swap) 영역이에요. 자세한 내용은 메모리 장에서 이어져요.

시험엔 이렇게 써요

컴퓨터 전원이 켜지면 가장 먼저 시작되며, 컴퓨터 자원을 관리하고 여러 응용 프로그램의 실행을 관리하는 프로그램을 운영체제라고 한다. (2023 기출 1번 빈칸 정답)

잠깐 확인 — 컴퓨터를 켜면 가장 먼저 실행되는 소프트웨어는 무엇인가요?

운영체제예요. 운영체제가 올라온 뒤에야 워드나 게임 같은 응용 프로그램을 실행할 수 있어요.

이 장 3줄 요약
  • 폰노이만 구조는 프로그램과 데이터를 RAM에 저장하고 명령어를 한 줄씩 CPU로 가져와 실행하는 구조이고, sum.py는 SSD → RAM → (인터프리터가 기계어로 번역) → CPU → RAM 순으로 돌아요.
  • 6대 부품은 CPU(계산), RAM(휘발성·실행 중), 보조기억장치(비휘발성·영구 저장), GPU(병렬 행렬 연산), 메인보드(통로), 전원공급장치(교류→직류)예요.
  • 무어의 법칙(집적도 2년마다 2배)과 클럭·온도 한계 때문에 멀티코어가 되었고, 프로그램은 보관 중, 프로세스는 실행 중이며, 멀티프로세싱은 프로세스를 여러 개, 멀티쓰레딩은 프로세스 하나 안에서 흐름을 여러 개로 나눠요.
