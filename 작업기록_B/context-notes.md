# 결정과 이유 (계속 추가)

- 2023 기출에는 캐시 적중률·평균 접근 시간 같은 계산 문제가 없다. 그래서 계산은 자료에 있는 것(주소 변환 10,000=2x4096+1808, 디스크 예제 7-2, 7200rpm 회전지연, RAID 용량, 16비트 1주소 명령 2^5·2^11)만 "손계산 요령"으로 쓰고, 평균 접근 시간은 "참고(자료에 없음)"로 표시했다.
- 기계어 주소 CC/CD는 기출 정답과 교수 설명(C=1100, D=1101)을 따라 CC=1100 1100, CD=1100 1101로 썼다. 강의자료 12쪽 예시줄(1010 1010 …)은 LOAD/STORE 줄이 규칙과 안 맞아 "암기하지 말고 규칙으로"라고 밝혔다.
- 녹취 번호 확인: 빅데이터플렛폼05=5주차(10/05), 빅데이터플06=6주차(10/12), 빅데이터플07=7주차(10/19). 크기가 녹음파일본/5·6주차_녹취록과 같다.
- 07보조기억장치.pdf는 앞부분이 가상메모리·TLB·멀티프로세싱(7주차 새 내용)이고 28쪽부터 보조기억장치다. 가상메모리·페이징은 c5(메모리)에, 디스크·SSD·RAID는 c6에 나눴다.
- 디스크 접근 시간(탐색·회전지연)은 교수가 "다루지 않아도 된다"고 해서 참고로만 썼다. 지역성의 시간/공간 구분도 수업엔 없어 참고로 표시.
- 프로그램/프로세스/운영체제/멀티프로세싱·쓰레딩은 기출 Q1에 나와 c4(멀티 용어)와 c5(운영체제·프로세스)에 나눠 담았다.
- HW7W 문제: 상태표를 직접 읽어 풀었다. Q1 (1) 1,3,4,5,7,9,10 (2) 1,3,4,6,11,7,9,10 (3) 1,2,7,8 / Q2 BC, E1 / Q3 O X X O X / Q4 RAID, 파티션, HDD, CD-ROM, SSD.
- 비밀정보(서버 주소·계정) 없음. 과제 파일의 이메일·제출 안내는 넣지 않음.
